## 数学-3　计算n!的末尾0的个数

公式如下：
$$ans = \lfloor \frac{n}{5} \rfloor + \lfloor \frac{n}{25} \rfloor + \lfloor \frac{n}{125} \rfloor + ...$$

计算 $n!$ 的末尾 $0$ 的个数，也就是计算 $n! = 1 \times 2 \times 3 \times \cdots \times n$ 中因子 $10$ 的个数

$10 = 2 * 5$ ，且在 $n!$ 中，因子 $2$ 的个数远远多于因子 $5$ 的个数 ，所以只需要统计 $n!$ 中所有因子 $5$ 的个数即可

已知 $1$ 到 $n$ 中 $5$ 的倍数的个数为 $\lfloor \frac{n}{5} \rfloor$，但如果直接将 $\lfloor \frac{n}{5} \rfloor$ 当作答案会漏掉 $5$ 的个数
因为 $25 = 5 * 5$ 贡献了 $2$ 个 $5$ , $125 = 5 * 5 * 5$ 贡献了 $3$ 个 $5$ ...

可以通过重复计数来补上这些漏掉的 $5$
- $\lfloor \frac{n}{5} \rfloor$ 统计所有 $5$ 的倍数贡献的第一个 $5$
- $\lfloor \frac{n}{25} \rfloor$ 统计所有 $25$ 的倍数贡献的第二个 $5$
- $\lfloor \frac{n}{125} \rfloor$ 统计所有 $125$ 的倍数贡献的第三个 $5$
- ......

这样一来就可以完整地统计出 $n!$ 中所有因子 $5$ 的个数了

## 数学-5　平方和展开恒等式

基于**平方和**与**和平方**之间的恒等式
$$
(\sum_{i=1}^ns_i)^2=\sum_{i=1}^ns_i^2+\sum_{i\neq j}s_is_j
$$

容易发现：
$$
\sum_{i\neq j}s_is_j=2\sum_{1\le i<j\le n}s_is_j
$$

所以有：

$$\sum_{1 \le i < j \le n} s_i s_j = \frac{(\sum_{i=1}^n s_i)^2 - \sum_{i=1}^n s_i^2}{2}$$

应用：数组两两之间的乘积和（$\mathcal{O}(n^2)$ 降为 $\mathcal{O}(n)$）

## 数学-6　二元最大值/最小值计数转化为长度 + 前缀差分

### 区间二元最大值 / 最小值计数转化为长度 + 前缀差分

当一个问题里只有两类东西，并且它们互补时，常常可以设：

$$A+B=L$$

这里 $L$ 往往是区间长度、前缀长度、路径长度之类的“总量”。

这时候如果题目要求的是两者中的较大值或较小值，就可以直接改写：

$$max(A,B)=\frac{A+B+|A-B|}{2}=\frac{L+|A-B|}{2}$$

$$min(A,B)=\frac{A+B-|A-B|}{2}=\frac{L-|A-B|}{2}$$

于是，一个看起来不好处理的二元最大值 / 最小值问题，就被拆成了两部分：

$$\text{答案}=\text{长度项} \pm \text{差分绝对值项}$$

其中：

- 长度项 $L$ 是很好算的总量；
- 真正需要处理的核心，变成了 $|A-B|$。

而对于后者，我们常见的做法就是将二元中的其中一个视为 $+1$ ，另一个视为 $-1$ ，于是我们就可以利用前缀和记录 $A - B$ 这个式子，那么消掉绝对值的办法自然就是排序，接下来计算贡献就只需要邻项做差然后对左右算贡献即可

最后的最后要记得对答案除以 $2$ ！

## 数学-13　异或的各种性质可以使用按位拆分，使用 mod 2 加法的方式得出

异或的各种性质可以使用按位拆分，使用 mod 2 加法的方式得出。

比如说这个分配律。

$$c_1 P_1 \oplus c_2(P_1 \oplus P_2) \oplus c_3(P_2 \oplus P_3) \oplus \dots \oplus c_k(P_{k-1} \oplus P_k) = 0$$

$$(c_1 \oplus c_2)P_1 \oplus (c_2 \oplus c_3)P_2 \oplus (c_3 \oplus c_4)P_3 \oplus \dots \oplus (c_{k-1} \oplus c_k)P_{k-1} \oplus c_k P_k = 0$$

对于二进制中的任意一位 $x$，都有

$$c_1 P_{1,x} + c_2(P_{1,x} + P_{2,x}) + \dots + c_k(P_{k-1,x} + P_{k,x}) \equiv 0 \pmod 2$$

$$(c_1 + c_2)P_{1,x} + (c_2 + c_3)P_{2,x} + \dots + (c_{k-1} + c_k)P_{k-1,x} + c_k P_{k,x} \equiv 0 \pmod 2$$

那么不难得出上面的结论。

## 数学-14　斐波那契数列常用二级结论

### 适用场景

遇到斐波那契数列相关的计数、整除、区间加、递推表示时，可以先考虑斐波那契的常用恒等式，而不是只按定义递推。

### 常用结论

设 $F_0=0,F_1=1$，则有：

$$
\gcd(F_n,F_m)=F_{\gcd(n,m)}.
$$

$$
F_{n+m}=F_{n+1}F_m+F_nF_{m-1}.
$$

$$
F_{2n}=F_{n+1}^2-F_{n-1}^2.
$$

$$
F_{2n+1}=F_{n+1}^2+F_n^2.
$$

$$
\sum_{i=1}^n F_i=F_{n+2}-1.
$$

对于广义斐波那契数列 $G_0=a,G_1=b,G_n=G_{n-1}+G_{n-2}$，也可以用普通斐波那契表示：

$$
G_n=F_{n-1}G_1+F_{n-2}G_2.
$$

### 常见用途

- 枚举 $n$，把 $F_na+F_{n+1}b=k$ 转成线性丢番图方程。
- 区间加斐波那契数列时，把 $F_{i-l+1}$ 拆成 $F_i$ 和 $F_{i+1}$ 的线性组合，在线段树上维护两个懒标记。

### 易错点

- 不同题目对 $F_0,F_1$ 的定义可能不同。
- 使用负下标或平移公式时要先统一定义。
- 取模时除法、逆元、矩阵形式都要按模数处理。

```cpp
        }
    }
}
```

## 数学-20　逆序对与正序对的总和不变

### 核心结论

对于任意一个长度为 $n$ 的排列（允许重复元素），如果我们考虑所有 $n!$ 种排列方式，那么：

**所有排列中逆序对的总数 = 所有排列中顺序对的总数**

这是因为对于任意两个值不同的位置 $i, j$，在所有排列中：

- 它们构成正序对和逆序对的概率各占 $1/2$
- 由对称性可知，正序对总数 = 逆序对总数

### 公式推导

设数组中有 $cnt_x$ 个值为 $x$ 的元素。

- 任意选取两个位置，共有 $C(n,2)$ 种选法
- 减去值相同的情况：$\sum C(cnt_x, 2)$
- 得到值不同的位置对数量：$C(n,2) - \sum C(cnt_x, 2)$

对于每一对值不同的位置，在所有排列中，正序和逆序各占一半。

因此：

$$
\text{逆序对总数} = \frac{n!}{2} \times \left( C(n,2) - \sum C(cnt_x, 2) \right)
$$

### 总结

对于全排列的统计问题，当正序和逆序具有对称性时，可以利用"总对数固定"这一性质简化计算，避免复杂的分情况讨论。

## 数学-21　求连续 111..1 段的个数

给定一个数，求有多少个连续全 1 段，比如 11...1 0...0 111..1，`cnt[ 连续全 1 段 ] = 3` 
这个问题，等价于问**对每一位考虑，有多少个相邻的 `01`**

这很重要，因为这可以转化成**状态机**，相邻位就只有 `(00, 01, 10, 11)`，可以用这四种状态来表示

比如给你一个序列，然后若干次操作，每次操作$\ \&, \oplus , |$ 上一个随便的数，比如说 $x$
然后统计每个数**连续全 1 段**的**和**，怎么做呢？
总不能对每个询问挨个去暴力加吧，会超时
考虑**维护整体的和，以及操作之后每一位的状态变化**

- 你只需要维护每一个位的`(00, 01, 10, 11)`四种状态
比如 `cnt(k, "00")`表示第 `(k+1, k)` 位的状态是 `00` 的数有多少个？

- 比如位运算，$\oplus x$，你只要拿 $x$ 去对齐第 $k$ 位，看看 $x$ 的 `(k+1, k)` 位组成的状态是多少？
那么是 `mask =  x >> k & 3`，是吧？

于是令 `ncnt[nsta] = cnt[k, sta]`，四个状态都枚举之后
更新 `cnt[k] = ncnt`，继续考虑更高的位

## 数学-22　交换次数奇偶性

对于一个排列，交换相邻两项必定会使得逆序对个数+1或者-1，那么对于一个排列，它的交换1<=i,j<=n，两个下标使得有序的排序次数的奇偶性取决于逆序对的奇偶性；
同理也有一个性质，对于一个区间循环左移一次，是将第一个元素通过相邻交换r-l将其移动道最后一个位置，那么交换次数就是r-l次，那么循环左移d次就是交换(r-l)*d次相邻元素，对于左右边界外的逆序对个数没有变化，但是对于区间内的进行了(r-l)*d次相邻交换，因为一次相邻交换一定会导致逆序对个数+1或者-1，有因为+1和-1操作在模2意义下相等，所以此时逆序对个数的奇偶性变成(sum+(r-l)*d)%2；

## 数学-23　最大化多重集异或和的求和

给定一个序列，两个多重集（初始是空的），把每个数划分到两个**多重集**中，使得两个多重集的`xor 和` 再相加，结果最大

根据 $A + B = (A \oplus B) + 2(A \textbf{ and } B) = S + 2 \cdot (A \textbf{ and } B)$
实际上，考虑 $S = \bigoplus_{i = 1}^{n} a_n$，这是基础值，是确定的，只需要最大化 $A \textbf{ and } B$

- 选出一个子集 $A$，最大化 $A \textbf{ and } B$，而 $S = A \oplus B$
- 注意到 $S$ 为 `1` 的位一定形如 `(a(i), b(i)) = (1, 0)`，它的 $\&$  运算结果一定是 `0` 
  而 $S$ 为 `0` 的位呢，形如 `(1, 1) or (0, 0)`，它的 $\&$ 运算结果取决于 $a$ 这一位的值

**综上所述**，若 $A \oplus B = S$，那么 $A \ \& \ B = A \ \& \ (\sim S)$

这个问题就转化成，给定 $S$ ，给定 $a[1\sim n]$，选一个子集构成 $A$，使得 $A \textbf{ and } (\sim S)$  最大
实际上就是最大化 $\bigoplus_{i = 1}^{m} (a_i \textbf{ and } (\sim S))$

这个让每个数 $a_i = a_i \ \& (\sim S)$，是标准的**选取一个子集，使其异或和最大**的问题，这就成了线性基模版题了

## 数学-24　构造排列的和，对 n 取模

给定一个排列，$a[0\cdots n-1]$，排列中的数是 $\{0, 1, \cdots, n - 1\}$
定义$f(a) = \sum_{0 \leqslant i < j \leqslant n} (a_j - a_i)$
现在要构造一个排列 $p$，使得$f(p) \equiv f(a) (\bmod n)$

- **排列的每个数，如果有涉及到差分形式，比如**$f = p_j - p_i$，那么对排列所有的数都加上一个值，比如说$+d$，$f$不会改变
- 另外，对一个排列的所有数都$+d$，相当于循环移位
- 排列发生循环移位，那么$\sum p'_i \equiv \sum p_i (\bmod n)$，循环移位相当于排列的每个数都加上`d`，求和，就是$+nd, \Rightarrow nd \equiv 0(\bmod n)$

## 数学-25　三个有关位运算的有用性质

1. **加法等式**：`a + b = (a ^ b) + 2 * (a & b)`
   > *`a ^ b` 是不带进位的按位加法，`a & b` 找出均是1的位，乘以2代表进位左移1位*
2. **按位或等式**：`a | b = (a ^ b) + (a & b)`
   > *按位或等于“两数不同的位”加上“两数同为1的位”*
3. **由等式1、2可以推得** `a + b = (a & b) + (a | b)`
   > *证明：*
*将等式 (1) 中的 `2 * (a & b)` 拆开：*
*`a + b = [(a ^ b) + (a & b)] + (a & b)`*
*把等式 (2) 代入方括号中，直接得到：*
*`a + b = (a | b) + (a & b)`*

由于二进制运算独立作用于每一位，我们只需要证明在任意单个比特位上，上述等式成立即可，因此也可以在固定的一位上枚举四种情况证明上述三种性质，在此不再列出。

```cpp
__builtin_popcount(x & y) = (__builtin_popcount(x) + __builtin_popcount(y) - __builtin_popcount(x ^ y)) / 2
```
因为$2 \times \text{popcount}(x \mathbin{\&} y)$ 必然是偶数，所以 $x \oplus y$ 中 1 的个数的奇偶性，完全取决于 $x$ 和 $y$ 中 1 的个数之和。
如果两者同奇偶，那么 $x \oplus y$ 结果中 1 的个数必为偶数；否则为奇数。

## 数学-30　取整与按位运算的不同值常为对数级

### 适用场景

固定一端枚举区间时，若维护的是下取整、gcd、按位与、按位或等会单调变化的值，不同取值通常很少。

### 核心思路

随着区间扩大，按位与只会从 $1$ 变 $0$，gcd 只会变成更小因子，下取整也只有 $O(\sqrt n)$ 或 $O(\log V)$ 段。可以把相同值的区间压缩成若干段维护。

### 易错点

不同运算的复杂度界不同：gcd/and 常见 $O(\log V)$，整除分块常见 $O(\sqrt n)$。

## 数学-33　光速幂用平方根分块预处理

### 适用场景

## 数学-34　连续上取整可以合并分母

### 适用场景

## 数学-36　多维绝对值枚举符号展开

### 适用场景

求多维点之间绝对值和的最大值、最小值或动态维护时，可以枚举每一维的正负号。

### 核心思路

## 数学-38　绝对众数可用摩尔投票信息维护

### 适用场景

当题目涉及绝对众数，即出现次数严格大于区间长度一半的元素时，可以考虑使用摩尔投票信息维护候选值。

### 核心性质

1. 一个序列至多有一个绝对众数。
2. 摩尔投票信息可以用二元组 $(val,cnt)$ 表示，并且可以合并。
3. 若一个区间存在绝对众数，则摩尔投票得到的候选值一定是它。

合并两个信息 $(x,a)$ 和 $(y,b)$：

$$
(x,a)+(y,b)=
\begin{cases}
(x,a+b),&x=y,\\
(x,a-b),&x\ne y, a>b,\\
(y,b-a),&x\ne y, b>a,\\
(0,0),&x\ne y, a=b.
\end{cases}
$$

### 使用方式

数据结构中维护摩尔投票二元组，查询区间时先得到候选值，再额外统计候选值真实出现次数，判断是否超过区间长度一半。

### 易错点

- 摩尔投票只能给候选值，不能直接证明它一定是众数。
- 最后必须再查一次出现次数验证。
- 合并顺序不影响结果的候选正确性，适合线段树、平衡树等维护。

## 数学-39　再一个矩形统计覆盖特定单元格的子正方形数量

对于一个长度为 $N$ 的线段，包含坐标 $i$ 且长度为 $k$ 的子线段，其合法左端点的方案数为：$$X_k = \min(k, i, N - i + 1, N - k + 1)$$
这四个限制分别代表：线段长度本身的限制、左边界距离、右边界距离、以及滑动空间的收缩限制。
同理，列方向上的方案数为：$$Y_k = \min(k, j, M - j + 1, M - k + 1)$$根据乘法原理，边长为 $k$ 且包含 $(i, j)$ 的正方形总数为 $X_k \times Y_k$。因此，包含该单元格的所有正方形总数为：$$\sum_{k=1}^{\min(N, M)} (X_k \times Y_k)$$
公式推导基于 $1$-based 索引（即行号 $1 \sim N$，列号 $1 \sim M$）。如果题目是 $0$-based，需要先将坐标 $+1$ 转化为 $1$-based 再套用公式。

## 数学-42　Raney 引理（循环引理 Cycle Lemma）

**陈述**

- 标准（Raney）：整数序列 $a_1,\dots,a_n$，若 $\sum a_i = 1$，则**恰好存在一个**循环移位使所有前缀和 $>0$。
- 推广（Dvoretzky–Motzkin 循环引理）：若 $\sum a_i = k>0$，则**恰好有 $k$ 个**循环移位使所有前缀和 $>0$。

**证明（前缀和定位）**

设 $S_0=0,\ S_j=\sum_{i=1}^j a_i$，取 $S$ 最小值**首次出现**的位置 $j_0$，以 $j_0+1$ 为起点旋转即满足所有前缀和 $>0$（旋转后任一前缀 $=S_t-S_{j_0}>0$）。唯一性反证：若两个不同起点都合法，中间会出现前缀和 $\le 0$，矛盾。推广情形同理：最小值每出现一次给出一个合法起点，恰出现 $k$ 次。

**应用 1：推卡特兰数（核心）**

$n{+}1$ 个 $+1$、$n$ 个 $-1$（和 $=1$，长 $2n+1$）。全体 $\binom{2n+1}{n}$ 个序列按循环移位分组（总和 $\ne0$ ⇒ 无周期，每组 $2n+1$ 个），由 Raney 每组恰 $1$ 个好序列，故好序列数 $=\dfrac{\binom{2n+1}{n}}{2n+1}$。好序列首项必为 $+1$，删去首项 ⇔ $n$ 对合法括号序列（前缀和 $\ge0$），于是

$$\text{Cat}(n)=\frac{\binom{2n+1}{n}}{2n+1}=\frac{\binom{2n}{n}}{n+1}$$

**应用 2：Ballot 定理**

A 得 $a$ 票、B 得 $b$ 票（$a>b$），A 全程**严格领先**的计票顺序数为 $\dfrac{a-b}{a+b}\binom{a+b}{a}$（$+1/-1$ 各 $a/b$ 个，循环引理下每个轨道恰 $a-b$ 个好序列）。

**应用 3：环上找合法起点**

环上元素 $\pm1$ 且总和 $>0$，求多少个起点能走完全程且前缀和恒正：由循环引理恰有「总和」个，一次 $O(n)$ 扫前缀和最小值定位。

**易错点**

- 别混淆两种条件：Raney（和 $=1$，前缀和 $>0$）vs 括号序列（和 $=0$，前缀和 $\ge0$）；后者**加一个 $+1$** 归一到 Raney 情形。
- 总和 $\le0$ 时不存在前缀和全正的循环移位。
- 计数时警惕循环同构（轨道）去重，先确认序列无周期。

## 数学-43　异或和为零的 n 个正整数的最小和

$n$ 为偶数：全为 $1$，和为 $n$。

$n$ 为奇数：一个 $2$、一个 $3$，剩下全为 $1$，和为 $n+3$。

（$n$ 个正整数异或和为 $0$，求其和的最小值；奇数情形无法全取 $1$，最小的不同取值组合即 $2\oplus3=1$。）
