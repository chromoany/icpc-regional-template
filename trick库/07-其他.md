## 其他-1　判断可重集合是否相等

### 定义

**可重集合（Multiset）：是指允许同一元素出现多次的集合。**

### 问题描述

> 给定数组 $a$，多次询问：
>
> 判断区间 $[L_1,R_1]$ 与 $[L_2,R_2]$ 所对应的可重集合是否相等。

设每次询问的两个可重集合分别为 $S$ 和 $T$。

### 朴素做法

直接的做法包括：

- 将两个区间内的元素排序逐一比较。
- 使用哈希表统计元素出现次数。

设 $|S|\le|T|$，以上方法，单次询问的时间复杂度为：
$$
{\cal O}(|S|\cdot\log|S|)
$$

### 随机化做法（随机赋权哈希）

#### 定理

如果两个可重集合相等，那么两个集合的元素和相等。

那么通过比较两个集合的元素和是否能完成问题？

#### 反例

$$
S=\{2,4\},\quad T=\{3,3\}
$$

#### 改进思路

为每一种元素 $x$ 随机赋予一个权值 $w(x)$，定义集合的哈希值为：
$$
H(S)=\sum_{x\in S}w(x)
$$
判断两个集合是否相等，只需比较：$H(S)$ 和 $H(T)$。

#### 正确性分析

- 若 $S=T$，则显然有 $H(S)=H(T)$。

- 若 $S\neq T$，设 $cnt_S(x),cnt_T(x)$ 分别表示元素 $x$ 在集合中的出现次数，则：

  $$
  \sum(cnt_S(x)-cnt_T(x))\cdot w(x)=0
  $$

  这是一个关于随机变量 $w(x)$ 的线性组合。

  在 $w(x)$ 独立随机且值域足够大的情况下，上式成立的概率极低。

#### 其他哈希形式

也可以定义：
$$
H(S)=\prod_{x\in S}w(x)
$$

同样可以用于判定可重集合相等（本质仍为随机映射）。

#### 区间查询实现

- 不带修，使用前缀和维护，单次查询时间复杂度：${\cal O}(1)$ 。
- 待修，使用数据结构（如树状数组/线段树）维护区间和，单次查询时间复杂度：${\cal O}(\log n)$ 。

### ✦ 扩展问题

> 给定数组 $a$，多次询问：
>
> 判断区间 $[L_1,R_1]$ 中所有元素加上 $k$ 后，是否与区间 $[L_2,R_2]$ 的可重集合相等。

设常数 $B$，定义哈希函数：
$$
H(S)=\sum B^{a_i}
$$
则有：
$$
H([L,R])=\sum_{i=L}^{R}B^{a_i}
$$
区间整体加上 $k$ 后：
$$
H'([L,R])=\sum_{i=L}^{R}B^{a_i+k}=B^k\cdot\sum_{i=L}^{R}B^{a_i}=B^k\cdot H([L,R])
$$
所以仅需要判断 $B^k\cdot H([L_1,R_1])$ 与 $H([L_2,R_2])$ 的关系即可。

## 其他-2　约数小诈骗

一个数的约数个数是奇数等价于这个数是完全平方数。

简单证明

对于任意正整数 $n$，若 $d$ 为其约数，则 $\dfrac{n}{d}$ 也是其约数。

而完全平方数有特例 $d=\sqrt{n}$ 时，$d=\dfrac{n}{d}$。

除此之外，约数成对出现。

## 其他-5　快速求 n个数的 popcount 和

# 快速求 popcount 和

一种以 $O(\log n)$ 求 $\sum_{i=1}^{n} \operatorname{popcount}(i)$ 的方法

摆结论：

$$
\sum_{i=1}^{n} \operatorname{popcount}(i) = \sum_{i=1}^{\lceil \log_2(n) \rceil - 1} \big[((n \gg (i-1)) \& 1) == 1\big] \times \left( i \times 2^{i-1} + 2^{i} \times \operatorname{popcount}(n \gg i) \right)
$$

其中 $\big[((n \gg (i-1)) \& 1) == 1\big]$ 表示条件判断（满足时为 1，否则为 0）。

### 原理

首先，我们可以想到一种 $O(1)$ 求 $\sum_{i=0}^{2^k-1} \operatorname{popcount}(i)$ 的方法。

以 $[0, 2^5-1]$ 为例：

我们首先将所有数字列出来，然后逐二进制位来看。

- 最低位的规律是 $01010101\dots$
- 第二位的规律是 $00110011\dots$
- 第三位的规律是 $00001111\dots$

之后的规律也显然：每一位中都有一半是 $0$，另一半是 $1$。

于是我们就可以得出公式：

$$
\sum_{i=0}^{2^k-1} \operatorname{popcount}(i) = k \times 2^{k-1}
$$

然后我们将给定的 $n$ 以 $(11010110)_2 = (214)_{10}$ 为例（下面指的第几位都是从高向低数的）：

- 其第一位是 $1$： $[00000000]_2 \sim [01111111]_2 \rightarrow 0 \times 2^7 + 7 \times 2^6$
- 其第二位是 $1$： $[10000000]_2 \sim [10111111]_2 \rightarrow 1 \times 2^6 + 6 \times 2^5$
- 其第三位是 $0$
- 其第四位是 $1$： $[11000000]_2 \sim [11001111]_2 \rightarrow 2 \times 2^4 + 4 \times 2^3$
- 其第五位是 $0$
- 其第六位是 $1$： $[11010000]_2 \sim [11010011]_2 \rightarrow 3 \times 2^2 + 2 \times 2^1$
- 其第七位是 $1$： $[11010100]_2 \sim [11010101]_2 \rightarrow 4 \times 2^1 + 1 \times 2^0$
- 其第八位是 $0$

但其实不管有没有贡献我们都不算他了，因为我们只需要将 $[0, n)$ 范围内的数加起来。最后再加上 $\operatorname{popcount}((11010110)_2) = 5$。

最终结果就是：

$$
\begin{aligned}
& 0 \times 2^7 + 7 \times 2^6 \\
+& 1 \times 2^6 + 6 \times 2^5 \\
+& 2 \times 2^4 + 4 \times 2^3 \\
+& 3 \times 2^2 + 2 \times 2^1 \\
+& 4 \times 2^1 + 1 \times 2^0 \\
+& \operatorname{popcount}((11010110)_2) \\
=&\ 448 + 256 + 64 + 16 + 9 + 5 \\
=&\ 798
\end{aligned}
$$

因为 $\operatorname{popcount}(0) = 0$。

### 代码实现

示例如下：

```c
scanf("%d", &n);
long long tot = 0;
int cnt = 0;
int x = n;
while (x) {
    if (x & 1)
        tot += (cnt * (1 << (cnt - 1))) + (1 << cnt) * __builtin_popcount(x >> 1);
    x >>= 1;
    cnt++;
}
tot += __builtin_popcount(n);
printf("%lld ", tot);

---

## 其他-6　数组区间加等差数列

对一个数组 $a$ 进行 $q \left ( q\leqslant 10^{5} \right )$ 次区间 $\left [ l,r \right ]$ 加以 $x$ 为首项，$d$ 为公差的等差数列，相当于对于 $i\in \left [ l,r \right ]$ 加 $x+\left ( i-1 \right )d$, 即 $id+x-ld$ 。因此可以额外维护俩个差分数组  $b$ 和 $c$ , 数组  $b$ 区间加  $d$ , 数组  $c$  区间加 $\left ( x-ld \right )$ 。求前缀和后新数组的 $a_{i}^{'}$ 为 $a_{i}^{'}=a_{i}+ib_{i}+c_{i}$ 。

## 其他-7　无精度误差判断线段穿过圆

#### 判断一条穿过点 $A$ 和点 $B$ 的直线是否穿过圆心为 $C$、半径为 $r$ 的圆，本质上就是计算**圆心 $C$ 到直线 $AB$ 的最短距离 $d$**，并判断 $d$ 与 $r$ 的大小关系。

##### 根据题目要求，不能切到菠萝（但边缘相切是可以的，因为交集面积为 0），因此合法的切线必须满足：

###### $$d \ge r$$

##### 由向量 $\vec{AB}$ 和 $\vec{AC}$ 构成的平行四边形的面积，有两种计算方式：

1. 面积 $S = |\vec{AB} \times \vec{AC}|$ (叉积的绝对值)
    
2. 面积 $S = 底 \times 高 = |\vec{AB}| \cdot d$

##### 联立两式，就可以得到点到直线的距离公式：

###### $$d = \frac{|\vec{AB} \times \vec{AC}|}{|\vec{AB}|}$$

##### 我们要判断 $d \ge r$。代入公式：

###### $$\frac{|\vec{AB} \times \vec{AC}|}{|\vec{AB}|} \ge r$$

###### $$|\vec{AB} \times \vec{AC}| \ge r \cdot |\vec{AB}|$$

##### 此时 $|\vec{AB}|$ 中包含平方根（即 $\sqrt{(B_x - A_x)^2 + (B_y - A_y)^2}$）。为了消除根号，我们将不等式**两边同时平方**：

###### $$(\vec{AB} \times \vec{AC})^2 \ge r^2 \cdot |\vec{AB}|^2$$

## 其他-9　树上点集直径合并

树上两个点集的直径可以合并，令$S$的直径端点为$(a,b)$，令$T$的直径端点为$(c,d)$，那么集合$S$并上$T$的直径端点为$\{a,b,c,d\}$中的一对端点；
所以可以用线段树来维护，每个节点存管辖区间的点集的直径端点，每个叶子节点代表一个节点，初始化为$\{i,i\}$，之后树内节点通过左右儿子合并。

## 其他-10　区间翻转排列只影响少量断点

### 适用场景

维护排列的连续性、段数或相邻关系时，区间翻转不一定需要重算整段。

### 核心思路

翻转区间内部相邻关系的集合不变，只是方向反过来；真正改变的是区间左右边界附近的连接关系。因此不连续位置数量通常只会在边界处变化，最多影响常数个断点。

### 易错点

该技巧维护的是相邻值关系或断点，不是所有区间统计都只受边界影响。

---

## 其他-11　最大化集合最小值时从大到小扫描

### 适用场景

当目标是最大化某个集合内的最小值，可以枚举或扫描答案阈值。

### 核心思路

从大到小加入权值不小于当前阈值的对象，维护它们能否形成合法集合。第一次满足条件的阈值就是最大可能的最小值。

### 易错点

需要合法性随阈值降低单调变强。否则不能直接扫描。

## 其他-12　离线后动态维护当前状态

### 适用场景

多组询问直接在线处理困难时，可以离线排序，让状态按某个维度单调变化。

### 核心思路

把询问按右端点、阈值、时间或权值排序。扫描过程中只做单调加入或删除，数据结构维护当前状态并回答询问。这样常能把二维或三维问题降成一维动态问题。

### 易错点

离线会改变回答顺序，最后要按原编号输出。若题目强制在线则不能使用。

## 其他-13　二进制分组应对强制在线

### 适用场景

如果对象不断在线加入，某种静态结构能批量处理但不支持单次插入，可以用二进制分组。

### 核心思路

维护若干大小为 $2^k$ 的块。新元素作为大小 1 的块加入，若同大小块已存在就合并，类似二进制进位。每个元素参与 $O(\log n)$ 次重建。

### 易错点

查询时需要合并所有块的答案，因此单块查询复杂度也要可接受。

## 其他-14　操作可逆时寻找标准中间状态

### 适用场景

如果操作可逆，直接从起点变到终点很难，可以考虑都变到某个标准状态。

### 核心思路

由于操作可逆，$A\to B$ 等价于 $A\to C$ 后把 $B\to C$ 的操作逆序反向执行。常见标准状态包括排序后状态、全零状态、规范形。

### 易错点

需要确保所有合法状态都能到达同一个标准状态，否则要按连通分量分类。

## 其他-15　折半搜索处理 n 约 40 的状压

### 适用场景

当 $n\approx 40$，直接 $2^n$ 枚举不可行，但每半 $2^{n/2}$ 可接受时，使用折半搜索。

### 核心思路

把元素分成两半，分别枚举所有状态并记录信息，再通过排序、哈希、双指针或数据结构合并两边答案。

### 易错点

折半后的合并方式决定复杂度。不要只枚举两边后再笛卡尔积合并，否则仍是 $2^n$。

## 其他-16　前 k 大方案用堆维护后继状态

### 适用场景

如果要输出多个序列、多个状态或多个分组中的前 $k$ 大值，可以为每组维护“下一个候选”。

### 核心思路

先把每组最大状态放入堆。每次弹出当前最大状态 $S$，再把它的少量后继状态 $trans(S)$ 放回堆。只要所有状态都能由后继关系到达，就能按顺序生成前 $k$ 大。

### 易错点

要避免同一状态被重复入堆。后继数量过多时，可把多个后继排成链降低出度。

---

## 其他-17　随意交换抽象成置换环

### 适用场景

当题目允许在一个集合内任意交换元素，或者问把一个排列变成另一个排列的代价时，可以看置换环。

### 核心思路

把目标位置映射成置换。一个长度为 $k$ 的环通常需要 $k-1$ 次交换才能归位；某些问题的奇偶性、最少操作数也由环数决定。

### 易错点

如果交换代价和位置或元素权值有关，不能只看环长，还要在环内做最优化。

---

## 其他-18　减法变换尝试扩展为取模变换

### 适用场景

如果操作允许反复执行 $x\leftarrow x-y$，且 $y$ 不变或变化较慢，可以考虑直接扩展为 $x\leftarrow x\bmod y$。

### 核心思路

连续减去 $y$ 直到小于 $y$ 的结果等价于取模。把多次重复操作压缩为一次取模，常能把复杂度从值域级降低到对数级，类似欧几里得算法。

### 易错点

只有当中间每次减法都不影响其他状态时才能合并成取模。

## 其他-19　删除困难时维护前后缀结构

### 适用场景

如果某种结构支持加入但不支持删除，例如线性基删除、非质数模除法、某些哈希逆操作，可以考虑前后缀分解。

### 核心思路

对静态序列预处理前缀结构 $pre_i$ 和后缀结构 $suf_i$。删除区间或单点时，用删除部分左右两侧的信息合并得到答案。

### 易错点

结构的合并操作要可行。若删除位置在线修改变化频繁，纯前后缀预处理不够。

## 其他-20　反悔贪心处理动态选择

### 适用场景

当贪心过程中当前选择未来可能被更优选择替换时，可以允许先选，再用数据结构反悔。

### 核心思路

维护已选集合的最差元素。当遇到更优候选且违反数量或容量限制时，用当前候选替换已选集合中代价最大的元素。优先队列常用于支持这种“后悔”操作。

### 易错点

必须证明每次替换不会让未来变差，通常依赖 matroid、排序后单调约束或交换论证。

## 其他-21　大 k 的第 k 小查询用随机二分

### 适用场景

如果有一个 $O(k\operatorname{polylog} n)$ 的求第 $k$ 小算法，但 $k$ 可能很大，可以尝试随机二分值域。

### 核心思路

随机选择候选值或随机抽样估计答案所在范围，再通过排名查询缩小值域。把直接枚举前 $k$ 个，改成对值域做若干次判定。

### 易错点

随机只用于缩小范围，最终答案仍应通过精确排名或候选检验确定。

## 其他-22　出现次数问题优先考虑根号分治

### 适用场景

当问题围绕某个值出现了多少次、出现位置间距、按频率统计时，常可按出现次数大小分类。

### 核心思路

设阈值 $B$。出现次数少的值直接枚举其出现位置，总复杂度受 $B$ 控制；出现次数多的值个数不超过 $n/B$，可以为它们预处理答案或单独维护。

### 易错点

阈值一般取 $\sqrt n$ 附近，但要根据转移复杂度调整。多组数据时注意清空重频值表。

## 其他-23　二维限制排序后一维维护

### 适用场景

查询或统计形如 $i\in[l,r]$ 且 $v\ge x$ 的二维限制时，常可按其中一维排序，另一维用数据结构维护。

### 核心思路

把询问和元素按阈值 $x$ 排序扫描。扫描过程中把满足值域条件的元素插入树状数组或线段树，然后在位置维上查询区间。二维问题因此变为一维动态查询。

### 易错点

离线排序时要注意 $<$、$\le$ 的边界和同值顺序。

## 其他-24　树拓扑序最优化用邻项交换

### 适用场景

在树形依赖下要求选择一个满足父子先后关系的线性序，并最小化某个代价时，可以考虑邻项交换。

### 核心思路

先假设两个相邻且互不为祖先后代的块可以交换。比较交换前后的代价差，得到一个排序关键字。若任意逆序交换都不劣，就可以按该关键字合并子树或维护优先队列。

### 易错点

邻项交换需要保证交换不会破坏拓扑序，所以通常只交换无祖先关系的相邻块。

## 其他-25　合法性判定同时维护增减方向

### 适用场景

有些问题不只要判断某个参数是否合法，还能在判定时看出答案应该增大还是减小。

### 核心思路

对参数 $x$ 做判定时，同时计算“不足量”和“超出量”。如果不足说明 $x$ 太小，超出说明 $x$ 太大，就可以二分出合法区间或唯一答案。该技巧常见于分数规划、构造后修正、平衡约束。

### 易错点

只有方向具有单调性时才能二分。若可行集合不是连续区间，单纯二分会错。

---

<a id="misc-26"></a>

## 其他-26　NFA 状态集合转 DFA 计数

### 适用场景

对于“有多少种方案使得存在一条合法路径”的问题，如果合法性可以用非确定自动机描述，可以把可达状态集合当作 DP 状态。

### 核心思路

设当前 NFA 中能到达的状态集合为 $S$。读入一个字符或执行一步操作后，$S$ 会转移到新的集合 $T$。于是可以在状态集合上建 DFA，再做计数或最短路。很多题中理论状态数是 $2^n$，但实际可达状态很少。

### 易错点

需要先从初始集合做可达性搜索，不要暴力枚举全部子集。转移时要处理 $\epsilon$ 转移或闭包。

---

<a id="misc-27"></a>

## 其他-27　不少于一半类条件用随机候选

### 适用场景

当题目保证答案对象在某个集合中出现比例不低，例如不少于一半、不少于三分之一，可以随机抽取候选再检验。

### 核心思路

随机选取若干个位置作为候选。若真实答案覆盖比例为 $p$，抽 $t$ 次都没抽到的概率为 $(1-p)^t$。当 $p\ge 1/2$ 时，几十次随机通常就能把失败概率压得很低。

### 易错点

随机只负责找候选，最后必须有确定性检验候选是否合法。不要把随机结果直接当答案。

---

<a id="misc-28"></a>

## 其他-28　大值域互异限制映射到小值域

### 适用场景

如果题目值域很大，但约束只关心元素是否相同、大小类关系或少量相对关系，可以尝试把值映射到较小集合。

### 核心思路

只保留会影响答案的等价类。例如只关心互不相同，可以将实际值按出现顺序离散化；只关心是否落在若干阈值区间，可以按阈值划分值域。这样能把大值域状态变成小值域 DP 或图论问题。

### 易错点

映射必须保持题目需要的全部关系。若题目同时关心大小和差值，普通离散化可能破坏差值信息。

---

<a id="misc-29"></a>

## 其他-29　三维偏序判定降为二维偏序

### 适用场景

当题目要求判断三维点 $(a,b,c)$ 之间是否存在支配关系，或者判断某个三元组是否被另一个三元组完全支配时，可以尝试先固定一维。

### 核心思路

将其中一维排序，排序后只需要在前缀中维护另外二维的信息。例如按 $a$ 从小到大扫描，问题就变成：之前是否存在某个点满足 $b$ 与 $c$ 的二维限制。这样可以用树状数组、线段树、set 或扫描线维护。

### 易错点

注意同一第一维下的点不能互相非法影响，通常要分组处理。若要求严格小于，需要区分 $<$ 与 $\le$。

---

<a id="misc-30"></a>

## 其他-30　将动态可行决策转为随机排列决策

### 适用场景

当一个随机过程每一步都从“当前仍可行”的决策中随机选择，而决策可行性会随着过程变化时，可以尝试改为：先随机排列所有初始决策，再按顺序执行当前仍可行的决策。

### 核心思路

很多过程中，某个决策是否最终被执行，只取决于它在相关决策中的相对顺序，而不取决于无关决策。因此可以先生成一个所有决策的随机排列，然后依次扫描：

- 当前决策若仍合法，则执行；
- 当前决策若已无效，则跳过。

这样动态随机过程就转化为排列上的概率问题。

### 常见用途

利用期望线性性：

$$
E[\text{执行次数}]=\sum_x P(x\text{ 被执行}).
$$

然后分别计算每个决策被执行的概率。

### 易错点

- 必须证明“先随机排列再跳过无效决策”和原随机过程等价。
- 只适合决策之间主要由相对顺序决定的过程。
- 概率常化成 $\frac1{k+1}$ 或组合数形式，要注意边界。

---

<a id="misc-31"></a>

## 其他-31　模糊答案可按二的幂压缩值域

### 适用场景

如果题目不要求精确答案，只要求输出值 $x$ 满足：

$$
ans\le x\le 2ans,
$$

或类似的常数倍近似限制，可以考虑按二的幂压缩值域。

### 核心思路

将每个值 $a$ 映射到某个不小于它、且不超过 $2a$ 的二进制分组代表值。例如把区间：

$$
[2^{k-1},2^k-1]
$$

内的值统一替换成 $2^k-1$ 或相邻的二进制边界值。

这样得到的新答案通常不小于原答案，且不超过原答案的常数倍。同时，值域从 $O(n)$ 降为 $O(\log n)$。

### 作用

压缩后可以枚举值域类别，用原本无法承受的算法处理每一类。

### 易错点

- 只能用于允许近似答案的题，不能用于精确题。
- 映射后的值必须保证答案方向正确，例如不能小于真实答案。
- 要证明整体答案也保持在允许倍率内，而不仅是单个元素。

<a id="misc-32"></a>

## 其他-32　钦定不再操作的元素简化序列过程

### 适用场景

当序列操作会不断移动、删除或重排元素，直接描述整个序列状态过大时，可以考虑钦定一部分元素从某一时刻起不再被操作。

### 核心思路

与其记录完整排列，不如记录“已经固定下来、以后不再动”的元素数量或结构。

如果这些元素在合法过程中会形成某种简单形态，例如递增后缀、已确定前缀、已归位集合，那么 DP 状态就可以从排列降维为数量。

### 例子

对一个排列反复把第一个元素插入到某个位置后，如果钦定最后 $j$ 个元素以后不再操作，并且它们必须形成递增后缀，则状态可以设为：

$$
f_{i,j}=\text{操作 }i\text{ 次后，已经钦定 }j\text{ 个后缀元素的方案数}。
$$

转移时只需讨论当前第一个元素是否是最后一次被操作。

### 易错点

- “不再操作”是人为钦定的辅助条件，不一定是题面显式条件。
- 需要证明被钦定的元素确实形成简单结构。
- 统计时要避免同一操作序列被多次钦定导致重复计数。

---

<a id="misc-33"></a>

## 其他-33　用前缀和或差分重解释操作

### 适用场景

当原操作直接看很复杂时，可以对序列或树上边权做前缀和、前缀异或或差分，观察操作在新变量上的含义。

### 核心思路

设原数组为 $a$，差分为：

$$
d_i=a_i-a_{i-1}.
$$

许多区间操作会在差分数组上变成端点操作。反过来，一些局部操作在前缀变量中可能变成交换、单点修改或多重集比较。

树上也类似。若令点权为根到该点路径上的边权异或和，那么对边的某些操作可能变成相邻点权的交换或整体异或。

### 常见用途

- 区间修改转端点修改；
- 树边权转根到点的前缀异或；
- 数组操作转差分数组上的相邻交换；
- 判断可达状态时比较变换后的多重集合。

### 易错点

- 前缀/差分变换通常需要固定根或固定起点。
- 异或和加法差分性质不同，不能混用。
- 变换后要重新翻译初态、终态和边界条件。

<a id="misc-34"></a>

## 其他-34　用抽屉原理转化比例上界构造

### 适用场景

当题目要求构造一个方案，并限制方案大小不超过某个总量的 $\frac1k$ 时，可以尝试构造 $k$ 个方案，使它们的大小总和恰好不超过该总量。

### 核心思路

如果能构造 $k$ 个合法方案 $S_1,S_2,\ldots,S_k$，并证明：

$$
\sum_{i=1}^k |S_i|\le T,
$$

那么由抽屉原理，至少存在一个方案满足：

$$
|S_i|\le \frac{T}{k}.
$$

于是原本难以直接构造“小方案”的问题，变成了构造 $k$ 个覆盖方式良好的方案。

### 常见用途

- 网格染色构造；
- 支配集或覆盖集构造；
- 把奇怪的 $\frac15$、$\frac13$ 等限制转化为模意义下的若干类方案。

### 易错点

- 必须保证每个 $S_i$ 都是合法方案。
- 要证明大小总和确实不超过目标总量 $T$。
- 最后输出最小的那个方案，而不是随便输出一个。

---

<a id="misc-35"></a>

## 其他-35　枚举区间最值时只枚举较短一侧

### 适用场景

当需要枚举每个位置作为区间最大值或最小值时，它能控制一个极长区间 $[L_i,R_i]$。若直接枚举所有包含 $i$ 的子区间会退化为 $O(n^2)$，可以只枚举较短的一侧。

### 核心结论

对于每个位置 $i$，设它作为区间最值的最大控制区间为 $[L_i,R_i]$。枚举包含 $i$ 的区间时，只枚举 $[L_i,i]$ 和 $[i,R_i]$ 中较短的一侧，则总枚举量为：

$$
O(n\log n).
$$

### 直观证明

全局最值所在位置最多贡献 $n/2$ 个枚举量。它把序列分成左右两段后，每段内的最值又分别最多贡献该段长度的一半。逐层递归，总和为：

$$
\frac n2+2\cdot\frac n4+4\cdot\frac n8+\cdots=O(n\log n).
$$

### 常见用途

- 单调栈求每个元素作为最大值/最小值的控制区间。
- 枚举较短侧，用 Trie、哈希表、前缀信息查询另一侧。

### 易错点

- 控制区间的边界要处理相等元素，避免重复或漏算。
- 较短侧枚举后，另一侧通常要有数据结构支持查询。
- 复杂度是总枚举量 $O(n\log n)$，不是每个点 $O(\log n)$。

---

<a id="misc-36"></a>

## 其他-36　先模拟到稳定阶段再换做法

### 适用场景

有些过程一开始状态复杂，直接套某种算法不成立；但经过有限步模拟后，系统会进入具有单调性、稳定性或可 DP 的阶段。这时可以分阶段处理。

### 核心思路

将过程拆成两部分：

1. 前若干步直接模拟或暴力 DP；
2. 当状态满足某种稳定性质后，改用更高效的算法。

例如在 DAG 上流动点权，前若干时刻某些点可能反复变成 $0$ 又变为正数。但经过不超过最长路径长度的时间后，影响已经沿 DAG 传播完，此后可以用拓扑 DP 计算。

### 常见形式

- 先模拟 $O(n)$ 步，之后 DP。
- 小范围用 DP，大范围用贪心。
- 小参数部分精确计算，大参数部分按稳定规律处理。

### 易错点

- 必须证明进入稳定阶段的步数上界。
- 两个阶段的状态要能无缝衔接。
- 不能只凭感觉截断，截断条件必须由题目性质保证。

---

<a id="misc-37"></a>

## 其他-37　将权值减下标消去连续递增限制

### 适用场景

当题目中出现形如 $a_{i+1}=a_i+1$ 的连续递增条件，或者需要把一段位置变成 $x,x+1,x+2,\ldots$ 时，可以考虑令：

$$
b_i=a_i-i.
$$

### 核心结论

若一段序列满足：

$$
a_{i+1}=a_i+1,
$$

则：

$$
a_{i+1}-(i+1)=a_i-i.
$$

也就是说，连续递增一的段在 $b_i=a_i-i$ 后会变成相等的一段。

### 常见用途

- 判断区间能否变成连续递增段。
- 将“覆盖为等差数列”转化为“覆盖为常数”。
- 把复杂的线段树等差标记变成普通区间赋值或区间统计。

### 易错点

- 下标从 $0$ 还是 $1$ 开始会影响 $a_i-i$ 的值，但不影响相等关系。
- 若递增公差不是 $1$，应改为 $a_i-d\cdot i$。
- 该技巧只消去和位置线性相关的部分。

<a id="misc-38"></a>

## 其他-38　将操作离线倒序处理

### 适用场景

当正向操作是删除、覆盖、破坏结构，难以维护；而反向操作变成添加、确定答案或合并时，可以把操作离线后倒序处理。

### 核心思路

很多操作正着做很难，反着做很简单：

- 删除点 $\to$ 加入点；
- 删除边 $\to$ 加入边；
- 区间覆盖 $\to$ 最后一次覆盖先确定答案；
- 断开连通性 $\to$ 合并连通块。

倒序处理时，已经确定的部分无需再访问，可以用并查集、链表、set 等维护“下一个未处理位置”。

### 典型例子

若有多次区间赋值，要求最终数组。倒序枚举操作，某个位置第一次被覆盖时，这个值就是最终答案；之后再遇到它可以跳过。

### 易错点

- 只有所有询问都能离线时才能倒序。
- 反向操作要和正向操作严格对应。
- 如果正向有查询，倒序时要把答案存下来，最后按原顺序输出。

---

<a id="misc-39"></a>

## 其他-39　循环区间滑动时用连续性保证取等

### 适用场景

当题目要在环形序列或循环区间中选一段，使某个计数恰好等于目标值时，可以考虑滑动窗口的连续变化。

### 核心思路

在 01 串中，固定窗口长度 $m$，令 $f(l)$ 表示从 $l$ 开始长度为 $m$ 的循环区间中 $1$ 的个数。

当窗口右移一格时，只会删除一个字符并加入一个字符，因此：

$$
|f(l+1)-f(l)|\le 1.
$$

如果某些位置的窗口值大于目标 $c$，另一些位置的窗口值小于目标 $c$，那么在循环滑动过程中一定会经过 $f(l)=c$。

### 常见用途

- 构造满足比例的子串。
- 证明答案段数不超过某个小常数。
- 在环上通过滑动找到恰好满足计数的区间。

### 易错点

- 需要保证滑动过程是连续的，值每次只改变 $-1,0,1$。
- 如果整个序列总量不满足整除条件，目标值可能根本不是整数。
- 环形区间要处理跨越末尾的情况。

<a id="misc-40"></a>

## 其他-40　按阈值将序列值域转为 01

### 适用场景

当题目中的操作只关心一个数是否 $\le x$ 或 $>x$，而不是关心具体值时，可以按阈值 $x$ 把序列转成 01 序列。

### 核心思路

给定一个待判断答案 $x$，定义：

$$
b_i=[a_i>x].
$$

这样，原序列中的升序/降序排序、区间统计等操作，可能会变成对 01 序列的简单覆盖操作。

例如区间升序排序时，只需要统计区间内 $0$ 的个数 $cnt_0$，然后把前 $cnt_0$ 个位置覆盖成 $0$，剩余位置覆盖成 $1$。

### 常见套路

如果最终只询问某个位置的值，可以二分答案 $x$：

- 将 $a_i\le x$ 视为 $0$，$a_i>x$ 视为 $1$；
- 模拟全部操作；
- 根据目标位置最终是 $0$ 还是 $1$ 判断答案方向。

### 易错点

- 01 转化通常需要配合二分答案。
- 升序和降序排序对应的覆盖方向相反。
- 判断条件中 $\le x$ 和 $>x$ 的边界不能写反。

---

<a id="misc-41"></a>

## 其他-41　用补集转化子集限制

### 适用场景

当题目限制某个子集难以直接处理时，可以考虑研究它的补集。图论中最常见的是独立集和点覆盖互补。

### 核心结论

在无向图 $G=(V,E)$ 中，点集 $S$ 是独立集，当且仅当 $V\setminus S$ 是点覆盖。

也就是说：

$$
S\text{ 是独立集}\iff \forall (u,v)\in E,\ u\in V\setminus S\text{ 或 }v\in V\setminus S.
$$

因此，求大小为 $n-k$ 的独立集数量，可以转化为求大小为 $k$ 的点覆盖数量。

### 作用

如果 $k$ 很小，补集大小小，就可以围绕点覆盖进行搜索、剪枝或参数化处理。

例如：若某个点度数大于 $k$，那么它必须在点覆盖中；否则需要选择它的所有邻点，数量会超过 $k$。

### 易错点

- 独立集和点覆盖是互补关系，但只在同一个点集全集 $V$ 下成立。
- 最小点覆盖、最大独立集与“指定大小计数”是不同问题。
- 有重边时覆盖关系不变，但计数实现中要避免重复处理边。

---

<a id="misc-42"></a>

## 其他-42　合法括号串拼接产生 `)(` 断点

### 适用场景

处理合法括号串的分解、拼接、连通性或段数统计时，可以观察相邻合法块之间的边界。

### 核心结论

两个非空合法括号串 $A$ 和 $B$ 拼接成 $AB$ 时，拼接处一定会出现形如：

```text
)(
```

的相邻字符。

原因是合法括号串一定以 `(` 开头、以 `)` 结尾。于是 $A$ 的最后一个字符是 `)`，$B$ 的第一个字符是 `(`。

### 作用

如果一个问题中，每次把两个合法括号块拼接会让答案发生一次变化，那么可以直接统计原串中的 `)(` 数量。

例如一个长度为 $2n$ 的合法括号串，如果每个基本括号对初始贡献为 $n$，每出现一次合法块拼接就减少一个连通块，那么答案可以写成：

$$
ans=n-\#\{i\mid s_i=')',s_{i+1}='('\}.
$$

### 易错点

- 这里要求参与拼接的两段都是合法括号串。
- 统计的是相邻子串 `)(`，不是所有逆序括号对。
- 空串是否允许要看题意，通常分解中不考虑空块。

## 其他-43　将二元组约束转化为图上连边

### 适用场景

当题目给出大量二元组 $(a,b)$，并且每个二元组表达的是两者之间的约束、影响、依赖或操作关系时，可以考虑把元素看成点，把二元组看成边。

### 核心思路

二元组常常不是“两个数字”，而是一条关系：

- $(l,r)$ 可以表示区间差分后的两个端点；
- $(a,b)$ 可以表示 $b$ 对 $a$ 的限制；
- 一次操作影响两个状态，可以表示为选择一条边。

建图后，问题可能变成：

- 图上选边改变两个端点状态；
- BFS/DFS 求最长或最短约束链；
- 在生成树上自底向上构造方案；
- 判断连通块内约束是否可满足。

### 典型例子

对 01 序列做区间取反，可以先做异或差分。区间 $[l,r]$ 取反会变成只修改两个端点，于是可以把一次操作看成连接两个端点的一条边。

### 易错点

- 建图前要确认二元组是有向还是无向。
- 如果坐标很大，通常要先离散化。
- 差分后端点可能包含 $r+1$，不要漏掉边界。

## 其他-44　倍增优化区间并查集合并

### 适用场景

当题目要求多次把两个等长区间逐位合并，例如要求 $[l_1,r_1]$ 和 $[l_2,r_2]$ 对应位置相等时，直接逐点合并会退化为 $O(nm)$。这时可以用倍增思想优化。

### 核心思路

类似 ST 表，将长度为 $2^k$ 的区间作为一个整体节点。

令 $fa[k][i]$ 表示区间 $[i,i+2^k-1]$ 所属的并查集代表元。若要合并两个等长区间 $[l_1,r_1]$ 和 $[l_2,r_2]$，令 $k=\lfloor\log_2(r_1-l_1+1)\rfloor$，只需合并：

$$
[l_1,l_1+2^k-1]\leftrightarrow [l_2,l_2+2^k-1],
$$

以及

$$
[r_1-2^k+1,r_1]\leftrightarrow [r_2-2^k+1,r_2].
$$

最后再从大长度向小长度下传合并关系，把 $2^k$ 的区间拆成两个 $2^{k-1}$ 的区间。

### 复杂度

预处理和下传共 $O(n\log n\alpha(n))$，每次区间约束只需要 $O(\alpha(n))$ 次合并。

### 易错点

- 倍增区间的合并只是记录约束，最终必须从高层向低层拆分传播。
- 区间长度不是 $2^k$ 时，要用左右两个 $2^k$ 区间覆盖。
- 只适合“对应位置相等/合并”这类满足可拆分性的约束。

## 其他-45　奇偶位取反转化相邻同项操作

### 适用场景

当题目中有二元字符串，并且操作和相邻两个字符“相同/不同”有关时，可以尝试对所有奇数位或所有偶数位取反。

### 核心结论

设原串为 $s$，将某一种奇偶性的下标统一取反得到 $t$。对于相邻位置 $i,i+1$，由于二者奇偶性不同，恰好只有一个位置被取反，因此：

$$
s_i=s_{i+1}\iff t_i\ne t_{i+1},
$$

$$
s_i\ne s_{i+1}\iff t_i=t_{i+1}.
$$

于是，原串中对相邻同项 `00`、`11` 的操作，常常可以转化为新串中对相邻异项 `01`、`10` 的操作。

### 常见用途

- 将“删除相邻相同字符”转化为“删除相邻不同字符”。
- 将“翻转相邻相同字符”转化为“交换或处理相邻不同字符”。
- 将字符串操作问题转化为计数差、不变量或相邻交换距离问题。

### 易错点

- 只能统一取反一种奇偶性，不能根据操作动态改变取反规则。
- 初始串和目标串都要做同样的变换后再比较。
- 该技巧通常要求字符集是二元的，或者题目能先压成二元关系。

## 其他-46　事件差分 + 坐标离散化：静态区间覆盖次数统计

**模型**

给定若干闭区间 $[l,r]$（坐标可达 $10^{18}$，无法开数组），问：恰好被覆盖 $k$ 次的点数、被覆盖位置上的最小/最大覆盖次数、覆盖总点数。做法：每条区间产生事件 $(l,+1)$、$(r+1,-1)$；排序后同一坐标的事件先合并，从最小坐标扫起——处理完 $pos$ 处全部事件后的 `cur`，就是段 $[pos,\text{下一事件坐标})$ 内每个点的覆盖次数，把段长累加进 `len[cur]` 即可。排序合并端点即完成离散化。

复杂度 $O(m\log m)$，空间 $O(m)$（覆盖次数上限 = 区间数 $m$）。

**口径与坑（写代码前先定死）**

- 闭区间语义：$r$ 本身仍被覆盖，到 $r+1$ 才减一。
- min 有两种问法，答案不同：
  - 只问被覆盖过的位置：取 `len[1..m]` 中第一个/最后一个非零下标（$mn/mx$）；
  - 问任意位置（含没被覆盖的 0）：全局最小 $=\begin{cases}0,&len[0]>0\\ mn,&\text{否则}\end{cases}$。
- `len[0]` 只统计区间与区间之间的空隙段；开放前缀/后缀（第一个左端点之前、最后一个右端点之后）不统计，所以不能用它推断"全坐标域"的 0 覆盖。
- 环形区间（坐标域 $1..R$）：$[l,r]$ 且 $l>r$ 表示跨过 $R$，拆成 $[l,R]$ 与 $[1,r]$ 两条再跑；环无空隙，跑完 `len[0]` 应为 0，可当正确性校验。

**应用锚点（典题）**

- CF 1000C Covered Points Count：输出 $ans[k]=len[k]$（$k=1..m$）。
- 洛谷 P1496：覆盖总长 $=\sum_{k\ge1} len[k]$。

**演示代码（输入：$m$ + $m$ 行 $l\ r$，输出恰好被覆盖 $1..m$ 次的点数）**

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int N = 300005;
int m;
ll cur, pos, sum;
ll len[N];
vector<pair<ll, ll>> ev;

int main()
{
    scanf("%d", &m);
    for (int i = 1; i <= m; i++)
    {
        ll l, r;
        scanf("%lld%lld", &l, &r);
        ev.push_back({l, 1});
        ev.push_back({r + 1, -1});
    }
    sort(ev.begin(), ev.end());
    cur = 0;
    for (int i = 0; i < (int)ev.size();)
    {
        pos = ev[i].first;
        sum = 0;
        while (i < (int)ev.size() && ev[i].first == pos)
        {
            sum += ev[i].second;
            i++;
        }
        cur += sum;
        if (i < (int)ev.size())
        {
            len[cur] += ev[i].first - pos;
        }
    }
    for (int k = 1; k <= m; k++)
    {
        printf("%lld%c", len[k], k == m ? '\n' : ' ');
    }
    return 0;
}
```

**不能套用（重要反例）**

圆环上"往返滚动 / 折线运动"导致的接触次数最值（如 QOJ 17269 Jolly Wheel 欢乐轮：轮周每点接触地面次数的 min/max）**不是**静态区间覆盖：残余弧的两个端点要拆成"折点事件"（起点、每次换向、终点各计一次），整圈数与"恰好回到折点余数"的点耦合，段内计数用的是开区间；把每次操作当成静态区间硬套本 trick 会连样例都错（min/max 各挂一种）。这类题的关键是先把滚动模型转成"圆环上的折线路径 mod 环长"，再谈扫描。
