## 使用说明

- 每个模板是独立章节，代码块自带头文件，复制后补 `main` 即可提交。
- 用法、边界与反例写在 Markdown 正文里，代码块内保持无注释。
- 公式为 LaTeX（行内 `$...$` / 独立 `$$...$$`），用支持数学渲染的预览器查看（如 VS Code 的 Markdown Preview Enhanced）。
