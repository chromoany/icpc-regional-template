# ICPC 区域赛算法模板

个人自用的算法竞赛模板库，面向 ICPC 亚洲区域赛 / 国赛 / 杭电多校。
全部内容为 Markdown 笔记，代码是可直接复制提交的纯净 C++。

## 目录结构

### `算法模板/` · 按专题分文件

入口是 **[`算法模板/00-索引.md`](算法模板/00-索引.md)**，含完整模板清单与「合并注意」（多模板拼进同一份代码时的全局变量重名表）。

| 文件 | 专题 |
|---|---|
| `01-基础工具.md` | 快读 read / readll |
| `02-数据结构.md` | 树状数组 / 线段树 / 并查集 / ST表 / 主席树 / 莫队 / 分块 |
| `03-图论.md` | 最短路 / MST / LCA / 树链剖分 / Tarjan / 网络流 / 二分图 / 拓扑 / 差分约束 |
| `04-数论.md` | 快速幂 / 线性筛 / 扩欧 / 逆元 / CRT / 组合数 / Lucas / 数论分块 / FFT / NTT / 矩阵快速幂 |
| `05-字符串.md` | 字符串哈希 / KMP / AC自动机 / Manacher / Trie / 后缀数组 |
| `06-计算几何.md` | 基础运算 / 凸包 / 多边形 / 刺穿直线 / 位置关系与距离 |
| `07-动态规划.md` | 记忆化搜索 / LIS / LCS / 背包 / 区间DP / 树形DP / 数位DP / 斜率优化 / 状压 |
| `08-杂项.md` | SG函数与博弈 / 三分 / bitset / 德州扑克比牌 |
| `09-常用STL.md` | 注释式用法速查：哈希 / 对顶堆 / multiset / 单调队列 / 离散化 / 二分 等 |

### `板题/` · 从具体题目提炼的套路板子

每个板子固定六段：适用模型 / 核心推导 / 复杂度 / 板子代码 / 使用说明 / 变体（含不能套用的情形）。

### `trick合集.md` · 零散结论与技巧

Raney 循环引理、Dilworth 定理、异或和规律、事件差分 + 坐标离散化等。

## 使用说明

- 每个模板是独立章节，代码块自带头文件，复制后补 `main` 即可提交。
- 用法、边界与反例写在 Markdown 正文里，代码块内保持无注释。
- 公式为 LaTeX（行内 `$...$` / 独立 `$$...$$`），用支持数学渲染的预览器查看（如 VS Code 的 Markdown Preview Enhanced）。
