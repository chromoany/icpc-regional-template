# 后缀密度约束 + 前缀大根堆 板子

## 适用模型
给定长度为 `m` 的序列 `a[1..m]`，选出若干元素，使得 **任意后缀 $i$ 个位置中被选元素不超过 $\lfloor i/2\rfloor$ 个**，求被选元素权重和的最大值（或按题意改目标函数）。

## 核心推导
1. 最极端的可行方案：全选奇数下标 `1,3,5,…`，恰 $\lfloor m/2\rfloor$ 个，说明密度上限可以被取满。
2. 任一合法方案中元素整体前移（下标减小）后仍合法，所以约束只与"第 i 个被选元素的位置上限"有关。
3. **等价转化**：从前到后第 $i$ 个被选元素的下标 $s_i$ 必须满足 $s_i \le 2i-1$。
   - 反证：若 $s_i \ge 2i$，则后缀 $s_i..m$ 内只有 $m-s_i+1 \le m-2i+1$ 个位置，却要容纳 $m-i+1$ 个被选元素，超过该后缀一半，矛盾。
4. **贪心策略**：从左到右扫描，维护前缀大根堆。每扫到奇数下标 $j$（配额 +1），若已选总数仍 $<\lfloor m/2\rfloor$，就取当前堆顶（前缀中最大元素）作为下一个被选元素。
   - 第 $i$ 个被选元素必然出自前 $2i-1$ 个位置，且在该范围内取到最大值。
   - 正确性：后缀族构成一条链（laminar family），该约束是 laminar matroid 的独立集，贪心取到最优基。

## 复杂度
- 时间：$O(m\log m)$
- 空间：$O(m)$

## 板子代码
```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 2000005;

int m;
ll a[MAXN], ans;
priority_queue<ll> pq;

int main()
{
    scanf("%d", &m);
    for (int i = 1; i <= m; i++)
    {
        scanf("%lld", &a[i]);
    }
    int cnt = 0;
    for (int i = 1; i <= m; i++)
    {
        pq.push(a[i]);
        if ((i & 1) && cnt < m / 2)
        {
            ans += pq.top();
            pq.pop();
            cnt++;
        }
    }
    printf("%lld\n", ans);
    return 0;
}
```

## 使用说明
- `m` 为数组长度，`m / 2` 即 $\lfloor m/2\rfloor$（总配额）。若题目保证 `m` 为偶数（如原题数组长 $2n$），`cnt < m/2` 恒成立，等价于每个奇数下标直接弹堆顶。
- 目标改为取最小值 → 换小根堆。
- 必须保持原序扫描，先排序再套用会破坏后缀约束。

## 变体
- 要求"恰好选 $k$ 个" → 把弹出门槛改为 `cnt < k`，并确认 $k \le \lfloor m/2\rfloor$。
- 约束换成"任意区间（不只是后缀）至多一半" → 为相邻不重复选，等价最大权不相邻子集，改用路径 DP，不能套本板子。
