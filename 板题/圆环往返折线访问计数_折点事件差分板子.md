# 圆环往返折线访问计数 + 折点事件差分 板子

## 适用模型
圆周长 $k$ 的轮子沿直线交替正反滚动 $n$ 次，第 $i$ 次恰好滚动 $a_i$ 米（$a_i$ 可为 $k$ 的倍数），问轮周上任意一点接触地面的最少 / 最多接触次数。一般化：给定分段单调折线 $P_0=0,\ P_i=P_{i-1}\pm a_i$，对每个实数点 $u\in[0,k)$ 统计折线命中同余类 $\{u+mk\}$ 的时刻数，求 $u$ 上的最值。接触口径（由样例确定）：**初始放置、每次换向、终点瞬间各算一次**，且 $u$ 可一次都没被接触（min 可为 0）。

## 核心推导
1. 无滑动滚动 ⇒ 圆周参数化：轮上点用弧长坐标 $u\in[0,k)$ 表示，累计带符号位移 $s$ 时点 $u$ 恰在接触点 ⇔ $s\equiv u\pmod k$。故"接触次数"= 折线穿过同余类 $\{u+mk\}$ 的时刻数。
2. **折点事件**：初始 $P_0$、每次换向 $P_i$（$1\le i<n$）、终点 $P_n$ 是孤立的单时刻，对 $u$ 计数当且仅当 $P_j\equiv u\pmod k$，记为 $F(u)=\#\{j:P_j\equiv u\pmod k\}$。
3. **段内计数**：第 $i$ 段内部（开区间）穿过 $\{u+mk\}$ 的次数 = 满足 $u+mk$ 严格落在 $(\min P_{i-1}P_i,\ \max P_{i-1}P_i)$ 的整数 $m$ 个数。整圈（$a_i\ge k$）的贡献已含在开区间计数里，**不要再给每个点统一加 $\lfloor a_i/k\rfloor$**——整圈回绕与"恰好回到折点余数"的点耦合：该点在折点处多一个事件、却少一个段内交点，简单均分会重算/漏算。
4. **余数压缩扫描**：计数只随 $u$ 经过某折点余数 $r=P_j\bmod k$ 而变。记 $F(r)$、$L(r)=\#$段的下端点（$\min$ 端点）$\equiv r$、$H(r)=\#$段的上端点（$\max$ 端点）$\equiv r$。$u$ 增向扫过 $r$ 时：
   - 弧（段）值变化 $\mathrm{step}(r)=L(r)-H(r)$（一段的上下端点同余数时相消）；
   - 恰在点 $u=r$ 处的计数 $=\mathrm{prev}-H(r)+F(r)$：$u=r$ 时压在上端点的那个交点不再算段内（$-H$），叠加折点事件（$+F$）；$\mathrm{prev}$ 是紧贴 $r$ 左侧弧上的值。
   - 锚点取 $u_0=(r_{\max}+k)/2$（落在最大余数到 $k$ 的空弧内），用开区间公式直接算出弧值后沿余数绕一圈；$\sum_r(L-H)=0$ 保证闭合。绕圈时对**弧值与点值都**取 min/max 即答案。

## 复杂度
- 时间：每用例 $O(n\log n)$（折点余数排序去重），总 $O(\sum n\log n)$。
- 空间：$O(n)$。
- 数值：$P_i$ 可达 $\pm 3\times10^{17}$、$k\le10^{18}$，开区间计数的分子分母用 `__int128`，负数除法需向下/向上取整。

## 板子代码
```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

const int MAXN = 300005;

int n, m;
ll k;
ll P[MAXN];
vector<ll> rv;
int cntF[MAXN], cntL[MAXN], cntH[MAXN];

ll norm(ll x)
{
    x %= k;
    if (x < 0) x += k;
    return x;
}

__int128 fl128(__int128 a, __int128 b)
{
    __int128 q = a / b, r = a % b;
    if (r && ((a < 0) != (b < 0))) --q;
    return q;
}

__int128 ce128(__int128 a, __int128 b)
{
    return -fl128(-a, b);
}

ll openCount(ll Lo, ll Hi, ll num, ll den)
{
    __int128 D = (__int128)den * k;
    __int128 A = (__int128)Lo * den - num;
    __int128 B = (__int128)Hi * den - num;
    __int128 c = ce128(B, D) - fl128(A, D) - 1;
    if (c < 0) c = 0;
    return (ll)c;
}

int id(ll r)
{
    return (int)(lower_bound(rv.begin(), rv.end(), r) - rv.begin());
}

int main()
{
    int T;
    scanf("%d", &T);
    while (T--)
    {
        scanf("%d%lld", &n, &k);
        P[0] = 0;
        for (int i = 1; i <= n; i++)
        {
            ll a;
            scanf("%lld", &a);
            P[i] = P[i - 1] + (i & 1 ? a : -a);
        }
        rv.clear();
        for (int j = 0; j <= n; j++) rv.push_back(norm(P[j]));
        sort(rv.begin(), rv.end());
        rv.erase(unique(rv.begin(), rv.end()), rv.end());
        m = (int)rv.size();
        for (int j = 0; j < m; j++) cntF[j] = cntL[j] = cntH[j] = 0;
        for (int j = 0; j <= n; j++) cntF[id(norm(P[j]))]++;
        for (int i = 1; i <= n; i++)
        {
            ll Lo = min(P[i - 1], P[i]);
            ll Hi = max(P[i - 1], P[i]);
            cntL[id(norm(Lo))]++;
            cntH[id(norm(Hi))]++;
        }
        ll num0 = rv[m - 1] + k;
        ll den0 = 2;
        ll prev = 0;
        for (int i = 1; i <= n; i++)
        {
            ll Lo = min(P[i - 1], P[i]);
            ll Hi = max(P[i - 1], P[i]);
            prev += openCount(Lo, Hi, num0, den0);
        }
        ll mn = prev, mx = prev;
        for (int j = 0; j < m; j++)
        {
            ll pv = prev - cntH[j] + cntF[j];
            if (pv < mn) mn = pv;
            if (pv > mx) mx = pv;
            prev += (ll)cntL[j] - cntH[j];
            if (prev < mn) mn = prev;
            if (prev > mx) mx = prev;
        }
        printf("%lld %lld\n", mn, mx);
    }
    return 0;
}
```

## 使用说明
- 输入：$t$，每个用例 `n k` 与 $n$ 个 $a_i$。代码约定第 1、3、5… 次正向；全体方向取反只是 $u\mapsto k-u$ 的镜像，min/max 不变，故任意起始方向都成立。
- 压缩对象是折点余数 $P_j\bmod k$；段的端点必是折点，所以只压折点余数即可。
- 折点事件 $F$ 已含初始 $P_0$ 与终点 $P_n$（样例口径）。若题目口径不含初始/终点接触，把 $j=0$ 与 $j=n$ 从 $F$ 计数中剔除即可——**先手算样例定死口径再提交**。
- `openCount` 统计满足 $Lo<u_0+mk<Hi$ 的整数 $m$ 个数，等价于 $\lceil(Hi-u_0)/k\rceil-\lfloor(Lo-u_0)/k\rfloor-1$（负数取 0）；锚点 $u_0$ 是分数 $(r_{\max}+k)/2$，以分子 `num0`、分母 `den0` 传入，避免浮点。
- 扫圈时弧值与点值都要更新 min/max（min/max 可能落在空隙弧上，也可能恰在折点余数处）。
- $a_i$ 为 $k$ 的倍数、$k=1$、$k$ 巨大等退化情形天然覆盖，无需特判。

## 变体
- 只问指定点 $u$ 的接触次数：$F(u)$ + 各段 `openCount(Lo, Hi, u, 1)` 求和。
- 方向序列不要求交替（任意 $\pm$）：公式不变，前缀按给定符号累计即可。
- 口径改"不算初始 / 不算终点"：$F$ 中删去对应下标。
- **不能套用**：静态"区间集合覆盖次数"统计（区间彼此独立、没有折线连续性，只需 $(l,+1),(r+1,-1)$ 事件差分）不需要折点事件与开区间端点耦合——见 `trick合集.md`「事件差分 + 坐标离散化」，两类别混；把本题每次滚动误当静态弧硬套会连样例的 min/max 都错。
