# 01 · 基础工具（公共头）

> 通用 IO 与基础工具，不属于任何专题，作为整份模板的公共头。任何提交代码第一件事就是复制本文件内容。

## 快读模板（read / readll）

适用：大数据量输入必备，比 cin 快数倍。整份模板通用，复制到任意代码顶部。

复杂度：$O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

inline int read()
{
    int x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9')
    {
        if (c == '-') f = -1;
        c = getchar();
    }
    while (c >= '0' && c <= '9')
    {
        x = x * 10 + c - '0';
        c = getchar();
    }
    return x * f;
}

inline ll readll()
{
    ll x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9')
    {
        if (c == '-') f = -1;
        c = getchar();
    }
    while (c >= '0' && c <= '9')
    {
        x = x * 10 + c - '0';
        c = getchar();
    }
    return x * f;
}
```

使用说明：
- `read()` 读 int，`readll()` 读 ll，均支持负数。
- 只处理十进制整数；需要读 char/string 时仍用 `scanf` 或 `cin`。

变体：
- 改为读无符号/大数只需去掉 f 分支。

## 128 位整数 IO（read128 / write128）

适用：数值超出 ll 范围（$10^{18}$ 级连加 / 相乘），或需要 $\text{ll}\times\text{ll}$ 的精确中间结果时。`__int128` 是 GCC 扩展，支持四则与比较，但 `scanf/printf` 都不能直接读写，必须自己写。需要时把本段拼在快读 read/readll 之后一起复制。

复杂度：$O(n)$。

```cpp
#define i128 __int128

inline i128 read128()
{
    i128 x = 0, f = 1;
    char c = getchar();
    while (c < '0' || c > '9')
    {
        if (c == '-') f = -1;
        c = getchar();
    }
    while (c >= '0' && c <= '9')
    {
        x = x * 10 + c - '0';
        c = getchar();
    }
    return x * f;
}

inline void write128(i128 x)
{
    if (x < 0)
    {
        putchar('-');
        x = -x;
    }
    if (x > 9) write128(x / 10);
    putchar(x % 10 + '0');
}
```

使用说明：
- `read128()` 读入、`write128(x)` 输出，均支持负数；`write128` 不自动换行，要换行时手动 `putchar('\n')`。
- 乘法防溢出必须先显式转一侧：`(i128)a * b`；直接 `a * b` 会在 ll 下先溢出再提升，结果已错。
- 比较、加减、取模原生支持；结果若确认在 ll 内可存回 ll，输出仍用 `write128`。

使用模板：

```cpp
ll a = readll(), b = readll();
i128 c = (i128)a * b;
write128(c);
putchar('\n');
```

变体：
- 只做中间量不输出时可只留 `read128` 一段。
- 无负数场景去掉 f 分支可省常数额外判断。

## 常用宏与常量（公共头补充）

适用：任何提交的头部，压缩码量、统一常量。与快读一起粘贴。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long
#define ull unsigned long long
#define pb push_back
#define all(x) (x).begin(), (x).end()
#define fi first
#define se second
#define pii pair<int, int>
#define pll pair<ll, ll>
#define rep(i, a, b) for (int i = (a); i <= (b); i++)
#define per(i, a, b) for (int i = (a); i >= (b); i--)
#define mem(x, v) memset(x, v, sizeof(x))

const int INF = 0x3f3f3f3f;
const ll LINF = 0x3f3f3f3f3f3f3f3fLL;
const int MOD = 1000000007;
const int MOD998 = 998244353;

void io_init()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cout.tie(nullptr);
}
```

使用说明：
- `INF` 用 `0x3f3f3f3f`：两倍不溢出，且 `memset` 出来就是它，做最短路初始值最方便；`ll` 用 `0x3f3f3f3f3f3f3f3fLL`。
- `io_init()` 与快读 `getchar()` **不能同时用**：`sync_with_stdio(false)` 后 `cin` 与 `getchar` 的缓冲区独立，混用会读到错误数据。二选一。
- `mem(x, v)` 只能填 0 / -1 / `0x3f` 这类字节模式，填其他整数会得到错误值。

变体：
- 常用模数：$10^9+7$（最常见）、$998244353$（NTT 原根 3）、$10^9+9$（配 $10^9+7$ 双哈希）。
- 慎用 `#define int long long`：会让 `sort` 比较变慢、`%` 与位运算语义变化，且 `printf("%d")` 崩溃，弊大于利。
- 需要更大栈时用编译选项 `-Wl,--stack=268435456`（Windows）/ `ulimit -s unlimited`（Linux），不要靠宏。
- 位运算常用宏：`#define lowbit(x) ((x) & -(x))`、`#define bit(x, i) (((x) >> (i)) & 1)`。

## 快写（write / writell）

适用：大数据量输出，配合快读一起用；`printf` 在 $10^6$ 级以上输出时明显偏慢。

复杂度：$O(\text{位数})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

inline void write(int x)
{
    if (x < 0)
    {
        putchar('-');
        x = -x;
    }
    if (x > 9) write(x / 10);
    putchar(x % 10 + '0');
}

inline void writell(ll x)
{
    if (x < 0)
    {
        putchar('-');
        x = -x;
    }
    if (x > 9) writell(x / 10);
    putchar(x % 10 + '0');
}
```

使用说明：
- `write(x)` 输出 int，`writell(x)` 输出 ll，均不自动换行，需要换行时 `putchar('\n')`。
- 与快读 `read()/readll()` 配套使用同一套 `getchar/putchar` 缓冲，不要和 `cin` 混用。
- 输出量不大（$< 10^5$）时直接用 `printf` 更省事，别过度优化。

变体：
- 需要输出 `__int128` 时用 `01` 文件上半部分的 `write128`。
- 数组输出模板：`for (int i = 1; i <= n; i++) { write(a[i]); putchar(" \n"[i == n]); }`。
