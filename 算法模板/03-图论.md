## 1. Dijkstra 堆优化（单源最短路）

适用：正权图单源最短路。稠密图可换朴素版。

复杂度：$O((n+m)\log n)$，空间 $O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
vector<pair<int, int>> g[MAXN];
ll dis[MAXN];
int vis[MAXN];
int n, m;

void add_edge(int u, int v, int ww)
{
    g[u].push_back({v, ww});
}

void dijkstra(int s)
{
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    for (int i = 1; i <= n; i++)
    {
        dis[i] = INF;
        vis[i] = 0;
    }
    dis[s] = 0;
    pq.push({0, s});
    while (!pq.empty())
    {
        int u = pq.top().second;
        pq.pop();
        if (vis[u]) continue;
        vis[u] = 1;
        for (auto ed : g[u])
        {
            int v = ed.first;
            int w = ed.second;
            if (dis[v] > dis[u] + w)
            {
                dis[v] = dis[u] + w;
                pq.push({dis[v], v});
            }
        }
    }
}
```

使用说明：
- 加边：`add_edge(u,v,w)` 加一条有向边；无向图再加 `add_edge(v,u,w)`。
- 结果存 `dis[]`，不可达为 INF。
- 求路径：加全局 `pre[v]` 记录松弛来源点，从 t 反向回溯。

变体：
- 求第 k 短路：A*（估价函数用反图最短路）或可持久化左偏树。
- 分层图最短路：拆点 (u, 层)，层内同权、跨层走特殊边，仍 Dijkstra。
- 稠密图 $n\le 2000$：朴素 $O(n^2)$ 更快。

## 2. SPFA（负权 / 判负环）

适用：存在负权边时 Bellman-Ford 的队列优化，或需要判负环。

复杂度：平均 $O(m)$，最坏 $O(nm)$。判负环用入队次数。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int INF = 0x3f3f3f3f;
vector<pair<int, int>> g[MAXN];
int dis[MAXN];
int cnt[MAXN];
int inq[MAXN];
int n, m;

void add_edge(int u, int v, int ww)
{
    g[u].push_back({v, ww});
}

bool spfa(int s)
{
    queue<int> q;
    for (int i = 1; i <= n; i++)
    {
        dis[i] = INF;
        cnt[i] = 0;
        inq[i] = 0;
    }
    dis[s] = 0;
    q.push(s);
    inq[s] = 1;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (auto ed : g[u])
        {
            int v = ed.first;
            int w = ed.second;
            if (dis[v] > dis[u] + w)
            {
                dis[v] = dis[u] + w;
                if (!inq[v])
                {
                    q.push(v);
                    inq[v] = 1;
                    if (++cnt[v] > n) return true;
                }
            }
        }
    }
    return false;
}
```

使用说明：
- 返回 true 表示存在从 s 可达的负环。
- 求差分约束：`dis[v] <= dis[u] + w` 对应约束 `x_v - x_u <= w`，加边 u→v 权 w。

变体：
- 判全图负环：先给所有点入队（或建虚拟源点连 0 权边），再跑。
- 负环检测可用 `dfs` 版更早返回，但可能爆栈。

## 3. Floyd（全源最短路）

适用：$n\le 500$ 的全源最短路、传递闭包、最小环。

复杂度：$O(n^3)$，空间 $O(n^2)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 505;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
ll dis[MAXN][MAXN];
int n, m;

void floyd()
{
    for (int k = 1; k <= n; k++)
        for (int i = 1; i <= n; i++)
            for (int j = 1; j <= n; j++)
                if (dis[i][j] > dis[i][k] + dis[k][j]) dis[i][j] = dis[i][k] + dis[k][j];
}
```

使用说明：
- 初始化 `dis[i][j] = INF`（$i\ne j$）、`dis[i][i] = 0`，再读边取 min。
- 传递闭包：权换成布尔可达，`dis[i][j] |= dis[i][k] && dis[k][j]`（可用 bitset 优化到 $O(n^3/64)$）。

变体：
- 最小环：在 Floyd 第 k 层更新前，枚举 i,j 用 `dis[i][j] + w[i][k] + w[k][j]` 更新答案。
- 保存路径：加 `mid[i][j]` 记录中转点递归输出。

## 4. Kruskal 最小生成树

适用：无向带权图求 MST / 最小瓶颈生成树。

复杂度：$O(m\log m)$，空间 $O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int MAXM = 200005;
int fa[MAXN];
int eu[MAXM], ev[MAXM], ew[MAXM], eid[MAXM];
int n, m;

int find(int x)
{
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

bool cmp_edge(int x, int y)
{
    return ew[x] < ew[y];
}

ll kruskal()
{
    for (int i = 1; i <= n; i++) fa[i] = i;
    for (int i = 1; i <= m; i++) eid[i] = i;
    sort(eid + 1, eid + m + 1, cmp_edge);
    ll ans = 0;
    int cnt = 0;
    for (int i = 1; i <= m; i++)
    {
        int e = eid[i];
        int u = find(eu[e]);
        int v = find(ev[e]);
        if (u != v)
        {
            fa[u] = v;
            ans += ew[e];
            cnt++;
        }
    }
    if (cnt != n - 1) return -1;
    return ans;
}
```

使用说明：
- 边数组 `eu/ev/ew` 存第 i 条边，返回 -1 表示图不连通。
- 需要存 MST 边集时，合并成功时把 `e` 记录到 `in_tree[]`。

变体：
- 次小生成树：Kruskal 后对每条非树边求路径上最大边（树剖 / 倍增），`ans = MST + w - 路径最大边` 取 min。
- 最小瓶颈路：MST 上任意两点路径的最大边即最小瓶颈。
- 优先用 Kruskal 重构树：克鲁斯卡尔树，支持离线"边权 $\le x$ 的连通性/最大值"。

## 5. LCA 倍增

适用：静态树求 LCA、两点距离、路径第 k 个点。可与差分等组合。

复杂度：预处理 $O(n\log n)$，查询 $O(\log n)$，空间 $O(n\log n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int LOG = 18;
vector<int> g[MAXN];
int dep[MAXN];
int fa[MAXN][LOG];
int n, q;

void add_edge(int u, int v)
{
    g[u].push_back(v);
}

void dfs(int u, int f)
{
    fa[u][0] = f;
    dep[u] = dep[f] + 1;
    for (int j = 1; j < LOG; j++) fa[u][j] = fa[fa[u][j - 1]][j - 1];
    for (int v : g[u])
    {
        if (v != f) dfs(v, u);
    }
}

int lca(int u, int v)
{
    if (dep[u] < dep[v]) swap(u, v);
    int d = dep[u] - dep[v];
    for (int j = 0; j < LOG; j++) if (d & (1 << j)) u = fa[u][j];
    if (u == v) return u;
    for (int j = LOG - 1; j >= 0; j--)
    {
        if (fa[u][j] != fa[v][j])
        {
            u = fa[u][j];
            v = fa[v][j];
        }
    }
    return fa[u][0];
}

int dist(int u, int v)
{
    int w = lca(u, v);
    return dep[u] + dep[v] - 2 * dep[w];
}
```

使用说明：
- 调用 `dfs(1, 0)`（根的父亲为 0，dep[0]=0）。
- 无向边双向 `add_edge`。
- 路径点权差分：`val[u]++, val[v]++, val[lca]--, val[fa[lca][0]]--`，二次 dfs 收集。

变体：
- 在线 LCA 也可用欧拉序 + ST 表，查询 $O(1)$。
- 动态树（边权修改 / 换根）用树链剖分或 Link-Cut Tree。
- 两点间第 k 个点：跳到 `dep[u]-k` 深度。

## 6. 树链剖分 + 线段树（路径加 / 路径和 / 子树操作）

适用：树上的路径修改 + 路径查询、子树修改 + 子树查询（如路径加、路径和、子树和、子树最值）。

复杂度：预处理 $O(n\log n)$，单次操作 $O(\log^2 n)$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
vector<int> g[MAXN];
int fa[MAXN], dep[MAXN], sz[MAXN], son[MAXN];
int top[MAXN], dfn[MAXN], rnk[MAXN], timer;
ll sum[MAXN << 2];
ll lazy[MAXN << 2];
int n, m;

void add_edge(int u, int v)
{
    g[u].push_back(v);
}

void dfs1(int u, int f)
{
    fa[u] = f;
    dep[u] = dep[f] + 1;
    sz[u] = 1;
    son[u] = 0;
    for (int v : g[u])
    {
        if (v == f) continue;
        dfs1(v, u);
        sz[u] += sz[v];
        if (sz[v] > sz[son[u]]) son[u] = v;
    }
}

void dfs2(int u, int tp)
{
    top[u] = tp;
    dfn[u] = ++timer;
    rnk[timer] = u;
    if (son[u]) dfs2(son[u], tp);
    for (int v : g[u])
    {
        if (v != fa[u] && v != son[u]) dfs2(v, v);
    }
}

void push_up(int rt)
{
    sum[rt] = sum[rt << 1] + sum[rt << 1 | 1];
}

void push_down(int rt, int l, int r)
{
    if (lazy[rt])
    {
        int mid = (l + r) >> 1;
        sum[rt << 1] += lazy[rt] * (mid - l + 1);
        sum[rt << 1 | 1] += lazy[rt] * (r - mid);
        lazy[rt << 1] += lazy[rt];
        lazy[rt << 1 | 1] += lazy[rt];
        lazy[rt] = 0;
    }
}

void build(int rt, int l, int r, ll *a)
{
    lazy[rt] = 0;
    if (l == r)
    {
        sum[rt] = a[rnk[l]];
        return;
    }
    int mid = (l + r) >> 1;
    build(rt << 1, l, mid, a);
    build(rt << 1 | 1, mid + 1, r, a);
    push_up(rt);
}

void update(int rt, int l, int r, int ql, int qr, ll v)
{
    if (ql <= l && r <= qr)
    {
        sum[rt] += v * (r - l + 1);
        lazy[rt] += v;
        return;
    }
    push_down(rt, l, r);
    int mid = (l + r) >> 1;
    if (ql <= mid) update(rt << 1, l, mid, ql, qr, v);
    if (qr > mid) update(rt << 1 | 1, mid + 1, r, ql, qr, v);
    push_up(rt);
}

ll query(int rt, int l, int r, int ql, int qr)
{
    if (ql <= l && r <= qr) return sum[rt];
    push_down(rt, l, r);
    int mid = (l + r) >> 1;
    ll res = 0;
    if (ql <= mid) res += query(rt << 1, l, mid, ql, qr);
    if (qr > mid) res += query(rt << 1 | 1, mid + 1, r, ql, qr);
    return res;
}

void path_update(int u, int v, ll w)
{
    while (top[u] != top[v])
    {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        update(1, 1, n, dfn[top[u]], dfn[u], w);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    update(1, 1, n, dfn[u], dfn[v], w);
}

ll path_query(int u, int v)
{
    ll res = 0;
    while (top[u] != top[v])
    {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        res += query(1, 1, n, dfn[top[u]], dfn[u]);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    res += query(1, 1, n, dfn[u], dfn[v]);
    return res;
}

void subtree_update(int u, ll w)
{
    update(1, 1, n, dfn[u], dfn[u] + sz[u] - 1, w);
}

ll subtree_query(int u)
{
    return query(1, 1, n, dfn[u], dfn[u] + sz[u] - 1);
}
```

使用说明：
- 预处理：`dfs1(1, 0); dfs2(1, 1); build(1, 1, n, val);`，val[i] 为点权数组。
- `path_update/path_query` 操作点权路径；`subtree_*` 操作子树（dfs 序连续）。
- 若为边权：把边权下沉到儿子点，路径查询时排除 LCA（`dfn[son[lca]]` 起查）。

变体：
- 换根操作：换根后子树区间需分类讨论（根在子树外/内）。
- 可配合可持久化 / 动态开点线段树做历史版本。
- 路径最大值 / 最小值：线段树 `push_up` 改取 max/min。

## 7. Tarjan 强连通分量（缩点）

适用：有向图求 SCC，缩点后为 DAG（可用于拓扑、最短路、可达性）。

复杂度：$O(n+m)$，空间 $O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
vector<int> g[MAXN];
int dfn[MAXN], low[MAXN], stk[MAXN], ins[MAXN], scc[MAXN];
int timer, top, scnt;

void tarjan(int u)
{
    dfn[u] = low[u] = ++timer;
    stk[++top] = u;
    ins[u] = 1;
    for (int v : g[u])
    {
        if (!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        }
        else if (ins[v]) low[u] = min(low[u], dfn[v]);
    }
    if (low[u] == dfn[u])
    {
        scnt++;
        int v;
        do
        {
            v = stk[top--];
            ins[v] = 0;
            scc[v] = scnt;
        } while (v != u);
    }
}
```

使用说明：
- 对每个未访问点调用 `tarjan(i)`。
- 缩点后 `scc[u]` 为所属分量编号，遍历原边建新 DAG。
- 判定：`low[v] >= dfn[u]`（u 为割点条件之一，见模板 8）。

变体：
- 缩点 + 拓扑排序求 DAG 最长链 / 方案数。
- 2-SAT：矛盾关系建边，SCC 判断可行性（`x 与 !x 同 SCC` 则无解）。

## 8. Tarjan 割点 / 桥

适用：无向图求割点（删去后连通分量数增加）与桥（割边）。

复杂度：$O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
vector<int> g[MAXN];
int dfn[MAXN], low[MAXN], timer;
int pa[MAXN];
int cut[MAXN];

void tarjan_cut(int u)
{
    dfn[u] = low[u] = ++timer;
    int child = 0;
    for (int v : g[u])
    {
        if (v == pa[u]) continue;
        if (!dfn[v])
        {
            pa[v] = u;
            child++;
            tarjan_cut(v);
            low[u] = min(low[u], low[v]);
            if (pa[u] == 0 && child > 1) cut[u] = 1;
            if (pa[u] != 0 && low[v] >= dfn[u]) cut[u] = 1;
        }
        else low[u] = min(low[u], dfn[v]);
    }
}
```

使用说明：
- 根判断用 `pa[u] == 0`（根节点 pa 为 0），对每个未访问点调用。
- `cut[u]=1` 表示 u 是割点。重边不影响割点判定。

桥（割边）——用边编号判重：

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
int head[MAXN], to[MAXN * 2], nxt[MAXN * 2], ecnt;
int dfn[MAXN], low[MAXN], timer;
int bridge[MAXN * 2];

void add_edge(int u, int v)
{
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

void tarjan_bridge(int u, int fe)
{
    dfn[u] = low[u] = ++timer;
    for (int e = head[u]; e; e = nxt[e])
    {
        int v = to[e];
        if ((e ^ 1) == fe) continue;
        if (!dfn[v])
        {
            tarjan_bridge(v, e);
            low[u] = min(low[u], low[v]);
            if (low[v] > dfn[u]) bridge[e] = bridge[e ^ 1] = 1;
        }
        else low[u] = min(low[u], dfn[v]);
    }
}
```

使用说明：
- 无向边按 `add_edge(u,v); add_edge(v,u);` 成对加，`ecnt` 从 0 开始（`e^1` 是反向边）。
- 桥条件 `low[v] > dfn[u]`（不含等号，区别于割点）。
- 边双连通缩点：删桥后剩余连通块。

变体：
- 点双连通分量：栈维护边，`low[v] >= dfn[u]` 时弹出分量。
- 圆方树：点双建方点，可处理无向图任意两点路径问题。

## 9. Dinic 最大流

适用：网络最大流、二分图多重匹配、拆点建模（点容量）。

复杂度：$O(n^2m)$（一般图），二分图等特殊图更快。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXM = 200005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
int head[MAXN], to[MAXM], nxt[MAXM], ecnt;
ll cap[MAXM];
int dis[MAXN], cur[MAXN];
int n, m, S, T;

void add_edge(int u, int v, ll c)
{
    to[++ecnt] = v;
    cap[ecnt] = c;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
    to[++ecnt] = u;
    cap[ecnt] = 0;
    nxt[ecnt] = head[v];
    head[v] = ecnt;
}

bool bfs()
{
    memset(dis, -1, sizeof(dis));
    queue<int> q;
    q.push(S);
    dis[S] = 0;
    cur[S] = head[S];
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (int e = head[u]; e; e = nxt[e])
        {
            int v = to[e];
            if (cap[e] > 0 && dis[v] == -1)
            {
                dis[v] = dis[u] + 1;
                cur[v] = head[v];
                if (v == T) return true;
                q.push(v);
            }
        }
    }
    return false;
}

ll dfs(int u, ll f)
{
    if (u == T) return f;
    ll used = 0;
    for (int &e = cur[u]; e; e = nxt[e])
    {
        int v = to[e];
        if (cap[e] > 0 && dis[v] == dis[u] + 1)
        {
            ll d = dfs(v, min(f - used, cap[e]));
            if (d > 0)
            {
                cap[e] -= d;
                cap[e ^ 1] += d;
                used += d;
                if (used == f) break;
            }
        }
    }
    if (!used) dis[u] = -1;
    return used;
}

ll dinic()
{
    ll flow = 0;
    while (bfs())
    {
        flow += dfs(S, INF);
    }
    return flow;
}
```

使用说明：
- `ecnt` 从 0 开始，反向边用 `e^1` 自动配对。
- `S` 源点、`T` 汇点须在调用前设置，节点编号 1..n。
- 点容量：拆点 u → u'，中间连容量为点容量，其余边容量为 INF。

变体：
- 最大流最小割定理：最大流 = 最小割容量，`bfs` 后从 S 可达的点为割集一侧。
- 二分图最大匹配可建超级源汇跑 Dinic（比匈牙利稳）。
- 最大权闭合子图：正权连 S、负权连 T，答案 = 正权和 - 最小割。

## 10. 最小费用最大流（SPFA 版）

适用：每条边带费用的最大流，求最小总费用（如最小费用分配）。

复杂度：$O(Fnm)$（$F$ 为流量），数据小时够用；大流量换 Dinic+势能版。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXM = 200005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
int head[MAXN], to[MAXM], nxt[MAXM], ecnt;
ll cap[MAXM], cost[MAXM];
ll dis[MAXN];
int pre[MAXN], pree[MAXN], inq[MAXN];
int n, m, S, T;

void add_edge(int u, int v, ll c, ll w)
{
    to[++ecnt] = v;
    cap[ecnt] = c;
    cost[ecnt] = w;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
    to[++ecnt] = u;
    cap[ecnt] = 0;
    cost[ecnt] = -w;
    nxt[ecnt] = head[v];
    head[v] = ecnt;
}

bool spfa()
{
    for (int i = 1; i <= n; i++)
    {
        dis[i] = INF;
        inq[i] = 0;
        pre[i] = 0;
    }
    dis[S] = 0;
    queue<int> q;
    q.push(S);
    inq[S] = 1;
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (int e = head[u]; e; e = nxt[e])
        {
            int v = to[e];
            if (cap[e] > 0 && dis[v] > dis[u] + cost[e])
            {
                dis[v] = dis[u] + cost[e];
                pre[v] = u;
                pree[v] = e;
                if (!inq[v])
                {
                    q.push(v);
                    inq[v] = 1;
                }
            }
        }
    }
    return dis[T] != INF;
}

pair<ll, ll> mcmf()
{
    ll flow = 0, mincost = 0;
    while (spfa())
    {
        ll f = INF;
        for (int v = T; v != S; v = pre[v]) f = min(f, cap[pree[v]]);
        for (int v = T; v != S; v = pre[v])
        {
            cap[pree[v]] -= f;
            cap[pree[v] ^ 1] += f;
        }
        flow += f;
        mincost += f * dis[T];
    }
    return {flow, mincost};
}
```

使用说明：
- 边成对加，反向边费用取负。`ecnt` 从 0 开始。
- 返回 `(最大流, 最小费用)`。
- 含负费用环时 SPFA 仍可跑（允许负边），但存在负权环会死循环，需预处理消环。

变体：
- 最大费用最大流：费用取负再跑，答案取负。
- 上 / 下界费用流：先处理下界（超级源汇），再跑。
- 流量限定：二分流量或加汇点边容量。

## 11. 匈牙利二分图最大匹配

适用：二分图最大匹配（n 较小），求最大匹配数 / 最小点覆盖 / 最大独立集。

复杂度：$O(nm)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 505;
vector<int> g[MAXN];
int match[MAXN];
int vis[MAXN];

bool dfs(int u)
{
    for (int v : g[u])
    {
        if (vis[v]) continue;
        vis[v] = 1;
        if (match[v] == 0 || dfs(match[v]))
        {
            match[v] = u;
            return true;
        }
    }
    return false;
}

int hungarian(int n)
{
    int res = 0;
    for (int i = 1; i <= n; i++)
    {
        memset(vis, 0, sizeof(vis));
        if (dfs(i)) res++;
    }
    return res;
}
```

使用说明：
- 左部点编号 1..n，右部点编号任意；`g[u]` 存左部点 u 可匹配的右部点。
- `match[v]` 记录右部 v 匹配的左部点。
- 二分图最大匹配 = 最小点覆盖 = n - 最大独立集（König 定理）。

变体：
- 多重匹配：右部拆点（每个右部点容量 k）。
- 带权匹配（Kuhn-Munkres）用小数据 / 费用流替代。

## 12. 拓扑排序

适用：DAG 判环、按依赖顺序处理任务、求 DAG 最长路 / 字典序最小拓扑序。

复杂度：$O(n+m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
vector<int> g[MAXN];
int indeg[MAXN];
int ans[MAXN];
int n, m, tot;

bool toposort()
{
    queue<int> q;
    for (int i = 1; i <= n; i++) if (indeg[i] == 0) q.push(i);
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        ans[++tot] = u;
        for (int v : g[u])
        {
            indeg[v]--;
            if (indeg[v] == 0) q.push(v);
        }
    }
    return tot == n;
}
```

使用说明：
- 返回 true 表示无环，`ans[1..n]` 为拓扑序；否则存在环。
- 字典序最小：把 queue 换成 priority_queue（小根堆）。

变体：
- 求 DAG 最长路：拓扑序上 DP，`dp[v] = max(dp[v], dp[u] + w)`。
- 反向拓扑可求"到达它的任务数"。

## 13. 差分约束系统

适用：形如 `x_v - x_u <= w` 的一组不等式，判断是否有解 / 求最大最小值。

复杂度：SPFA 判负环 $O(nm)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int INF = 0x3f3f3f3f;
vector<pair<int, int>> g[MAXN];
int dis[MAXN], cnt[MAXN], inq[MAXN];
int n, m;

void add_edge(int u, int v, int ww)
{
    g[u].push_back({v, ww});
}

bool diff_constraint()
{
    queue<int> q;
    for (int i = 1; i <= n; i++)
    {
        dis[i] = INF;
        cnt[i] = 0;
        inq[i] = 0;
    }
    for (int i = 1; i <= n; i++)
    {
        add_edge(0, i, 0);
        q.push(i);
        inq[i] = 1;
    }
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        inq[u] = 0;
        for (auto ed : g[u])
        {
            int v = ed.first;
            int w = ed.second;
            if (dis[v] > dis[u] + w)
            {
                dis[v] = dis[u] + w;
                if (!inq[v])
                {
                    q.push(v);
                    inq[v] = 1;
                    if (++cnt[v] > n + 1) return false;
                }
            }
        }
    }
    return true;
}
```

使用说明：
- 约束 `x_v - x_u <= w` 加边 u→v 权 w；`x_v - x_u >= w` 转成 u→v 权 -w。
- 建虚拟源点 0 连所有点权 0，保证全图连通。返回 false 表示无解（存在负环）。
- 求 `x_n - x_1` 最大值即 `dis[n]`（跑最短路）。

变体：
- 相等关系 `x_v - x_u = w`：拆成 `<= w` 和 `>= w` 两条。
- 严格小于 `x_v < x_u`：整数变量转 `x_v - x_u <= -1`。

## 14. 2-SAT（含布尔变量取值）

适用：每个变量取真/假两种值，条件形如"$x$ 取 $a$ 或 $y$ 取 $b$"（含"至少一个""不能同时"），判断可行性并给出一组解。

复杂度：$O(n + m)$。

约定：变量编号 $1..n$，节点 $i$ 表示 $x_i$ 为真、$i+n$ 表示 $x_i$ 为假；`add_clause(u, bu, v, bv)` 表示"$x_u$ 取 $bu$ **或** $x_v$ 取 $bv$"。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 200005;
const int MAXM = 400005;
int head[MAXN], to[MAXM], nxt[MAXM], ecnt;
int dfn[MAXN], low[MAXN], stk[MAXN], ins[MAXN], scc[MAXN];
int idx, top, scnt;
int n, m;

void add_edge(int u, int v)
{
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

void add_clause(int u, int bu, int v, int bv)
{
    int mu = bu ? u + n : u;
    int mv = bv ? v + n : v;
    int nu = bu ? u : u + n;
    int nv = bv ? v : v + n;
    add_edge(mu, nv);
    add_edge(mv, nu);
}

void tarjan(int u)
{
    dfn[u] = low[u] = ++idx;
    stk[++top] = u;
    ins[u] = 1;
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
        }
        else if (ins[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u])
    {
        scnt++;
        int v;
        do
        {
            v = stk[top--];
            ins[v] = 0;
            scc[v] = scnt;
        } while (v != u);
    }
}

bool solve_2sat()
{
    for (int i = 1; i <= 2 * n; i++) if (!dfn[i]) tarjan(i);
    for (int i = 1; i <= n; i++) if (scc[i] == scc[i + n]) return false;
    return true;
}
```

使用说明：
- 建图规则：条件 "$x_u$ 取 $bu$ 或 $x_v$ 取 $bv$" 即 $\lnot(u{=}bu) \to (v{=}bv)$ 与 $\lnot(v{=}bv)\to(u{=}bu)$ 两条边，`add_clause` 内部已处理。
- 判定：$x_i$ 与 $\lnot x_i$ 是否在同一 SCC；同则无解。
- 取值：Tarjan 的 SCC 编号是**逆拓扑序**，故 `x_i 取真` 当且仅当 `scc[i] > scc[i+n]`。
- 常见条件改写：`x` 必须为真 → `add_clause(x, 1, x, 1)`；`x` 与 `y` 不能同时真 → `add_clause(x, 0, y, 0)`；`x` 与 `y` 必须相同 → `add_clause(x, 1, y, 0)` + `add_clause(x, 0, y, 1)`。

变体：
- 求字典序最小解：不用 SCC，改用染色法（对每个变量从小到大尝试取假，DFS 染色回溯），复杂度 $O(nm)$，只适合 $n$ 很小。
- 条件含"恰好一个为真"：拆成"至少一个"+"不能同时"两组子句。
- 带权/带代价的 2-SAT：转成最小割（最大权闭合子图）模型。

## 15. KM 算法（二分图最大权完美匹配）

适用：二分图两侧各 $n$ 个点，边有边权（可负），求权值和最大的完美匹配；指派问题、最小代价配对（权取负）。

复杂度：$O(n^3)$。

约定：`w[i][j]` 为左 $i$ 到右 $j$ 的边权，无边置 `-INF` 或极小值；`km()` 返回最大权值，`match[j]` 为右部匹配对象。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 505;
const ll INF = (ll)4e18;

ll w[MAXN][MAXN];
ll lx[MAXN], ly[MAXN], slack[MAXN];
int match[MAXN], pre[MAXN];
bool visy[MAXN];
int n;

void bfs(int u)
{
    for (int i = 0; i <= n; i++)
    {
        visy[i] = false;
        pre[i] = 0;
        slack[i] = INF;
    }
    int y = 0;
    match[0] = u;
    do
    {
        visy[y] = true;
        int x = match[y], ny = 0;
        ll d = INF;
        for (int i = 1; i <= n; i++)
        {
            if (visy[i]) continue;
            ll t = lx[x] + ly[i] - w[x][i];
            if (t < slack[i])
            {
                slack[i] = t;
                pre[i] = y;
            }
            if (slack[i] < d)
            {
                d = slack[i];
                ny = i;
            }
        }
        for (int i = 0; i <= n; i++)
        {
            if (visy[i])
            {
                lx[match[i]] -= d;
                ly[i] += d;
            }
            else slack[i] -= d;
        }
        y = ny;
    } while (match[y]);
    while (y)
    {
        int py = pre[y];
        match[y] = match[py];
        y = py;
    }
}

ll km()
{
    for (int i = 0; i <= n; i++)
    {
        lx[i] = ly[i] = 0;
        match[i] = 0;
    }
    for (int i = 1; i <= n; i++) for (int j = 1; j <= n; j++) lx[i] = max(lx[i], w[i][j]);
    for (int i = 1; i <= n; i++) bfs(i);
    ll res = 0;
    for (int i = 1; i <= n; i++) if (match[i]) res += w[match[i]][i];
    return res;
}
```

使用说明：
- 要求**完全匹配**（两侧点数相同）；左侧点数多于右侧时补 0 权虚点，或改成"最大权匹配"版。
- `w` 有负权也能跑（顶标会自适应），但**不存在**的边必须置一个足够小的值而不是 0，否则会被当成 0 权边匹配。
- 求最小权完美匹配：$w_{ij} \gets -w_{ij}$ 后取负。

变体：
- 最大权（不要求完美）匹配：给每条边加上大常数 $C$（大于最大权差的绝对值），最后答案减去匹配边数 $\times C$。
- 稀疏图（$m \ll n^2$）用费用流可能更快；$n \le 500$ 时 KM 稳定。
- 带权二分图最小顶点覆盖 / 最大权独立集：由 KM 的解与顶标直接读出。

## 16. 最小树形图（朱刘算法 / Edmonds）

适用：**有向图**的最小生成树（从固定根出发能到达所有点且总权最小的边集），如单向道路铺设、依赖建立、有根最小代价连通。

复杂度：$O(nm)$。

约定：边 `e[i] = {u, v, w}`，`root` 为指定根；返回最小总权，不可达返回 -1。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 105;
const int MAXM = 10005;
const ll INF = (ll)4e18;

struct Edge
{
    int u, v;
    ll w;
} e[MAXM];
int pre[MAXN], id[MAXN], vis[MAXN];
ll inw[MAXN];
int n, m, root;

ll zhuliu()
{
    ll res = 0;
    while (1)
    {
        for (int i = 1; i <= n; i++)
        {
            inw[i] = INF;
            pre[i] = 0;
        }
        for (int i = 1; i <= m; i++)
        {
            if (e[i].u != e[i].v && e[i].w < inw[e[i].v])
            {
                inw[e[i].v] = e[i].w;
                pre[e[i].v] = e[i].u;
            }
        }
        for (int i = 1; i <= n; i++) if (i != root && inw[i] == INF) return -1;
        int cnt = 0;
        for (int i = 1; i <= n; i++) id[i] = vis[i] = 0;
        inw[root] = 0;
        for (int i = 1; i <= n; i++)
        {
            res += inw[i];
            int v = i;
            while (vis[v] != i && !id[v] && v != root)
            {
                vis[v] = i;
                v = pre[v];
            }
            if (v != root && !id[v])
            {
                cnt++;
                for (int u = pre[v]; u != v; u = pre[u]) id[u] = cnt;
                id[v] = cnt;
            }
        }
        if (!cnt) break;
        for (int i = 1; i <= n; i++) if (!id[i]) id[i] = ++cnt;
        for (int i = 1; i <= m; i++)
        {
            int u = e[i].u, v = e[i].v;
            e[i].u = id[u];
            e[i].v = id[v];
            if (e[i].u != e[i].v) e[i].w -= inw[v];
        }
        root = id[root];
        n = cnt;
    }
    return res;
}
```

使用说明：
- 自环边直接在建图时跳过（代码内已 `e[i].u != e[i].v` 过滤）。
- 缩环后 `n` 会变小、边权会减去 `inw`，这是标准流程，不要在循环外再用原 `n`。
- 无可行树形图返回 -1（存在除根外入度为 0 的点）。

变体：
- 不定根最小树形图：加一个超级源点向所有点连 INF 权边，跑完后减掉 INF，同时可判断是否有解（用了多于一条 INF 边则无解）。
- 求最大树形图：边权取负。
- 需要输出方案：记录每轮选择入边，缩环时回代。

## 17. 欧拉路 / 欧拉回路（Hierholzer 迭代版）

适用：一笔画问题（每条边恰好走一次），邮递员路线、字符串接龙、棋盘覆盖判定。

复杂度：$O(n + m)$。

约定：无向图，边按 $i$ 与 $i \oplus 1$ 成对存储（`add_edge` 保证从偶数下标开始）；`ans[1..anscnt]` 为**逆序**路径点序列。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int MAXM = 200005;
int head[MAXN], to[MAXM * 2], nxt[MAXM * 2], ecnt = 1;
bool used[MAXM * 2];
int deg[MAXN];
int fa[MAXN];
int stk[MAXN * 2], ans[MAXM];
int anscnt;
int n, m;

int find(int x)
{
    return fa[x] == x ? x : fa[x] = find(fa[x]);
}

void add_edge(int u, int v)
{
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
    to[++ecnt] = u;
    nxt[ecnt] = head[v];
    head[v] = ecnt;
    deg[u]++;
    deg[v]++;
}

bool judge_euler(int n, int m)
{
    for (int i = 1; i <= n; i++) fa[i] = i;
    for (int u = 1; u <= n; u++)
    {
        for (int i = head[u]; i; i = nxt[i])
        {
            int a = find(u), b = find(to[i]);
            if (a != b) fa[a] = b;
        }
    }
    int comp = 0, odd = 0;
    for (int i = 1; i <= n; i++) if (deg[i] && find(i) == i) comp++;
    if (comp > 1) return false;
    for (int i = 1; i <= n; i++) if (deg[i] & 1) odd++;
    return odd == 0 || odd == 2;
}

void euler(int s)
{
    int top = 0;
    stk[++top] = s;
    while (top)
    {
        int u = stk[top];
        int i = head[u];
        while (i && used[i]) i = nxt[i];
        head[u] = i;
        if (i)
        {
            used[i] = used[i ^ 1] = true;
            stk[++top] = to[i];
        }
        else
        {
            ans[++anscnt] = u;
            top--;
        }
    }
}
```

使用说明：
- 判定：连通（忽略孤立点）且奇度点数为 0（欧拉回路）或 2（欧拉路）。
- 起点：有奇度点则从任一奇度点出发，否则从任一有边的点出发。
- `ans[]` 是**逆序**的（弹出顺序），输出时倒着遍历 `ans[anscnt] → ans[1]`；边数应等于 `anscnt - 1`。
- 有重边时成对存储仍成立；自环会加两条边（`u==v`），一般题目无自环。

变体：
- 有向图：`add_edge` 只加单向边，判定改为"所有点入度 = 出度"（回路）或"恰一点出度 - 入度 = 1、恰一点入度 - 出度 = 1、其余相等"（路径），连通性看弱连通。
- 混合图欧拉路：无向边先任意定向，再对偏差用网络流调整（每个点入出度差为偶数才可能）。
- 输出字典序最小的欧拉路：把邻接表按终点排序（或每次取最小可走边），再跑 Hierholzer。

## 18. 上下界网络流（可行流 / 有源汇最大流）

适用：每条边流量有下界 $low$ 上界 $high$ 的网络流问题（任务调度、供需平衡、循环流）。

复杂度：同 Dinic，$O(V^2E)$ 量级。

约定：`add_edge(u, v, low, high)` 建边；`S/T` 为原源汇，`SS/TT` 为超级源汇。返回可行流流量，-1 表示不可行。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 205;
const int MAXM = 20005;
const ll INF = (ll)1e18;

struct Edge
{
    int to, nxt;
    ll cap;
} e[MAXM * 2];
int head[MAXN], ecnt = 1;
int dep[MAXN], cur[MAXN];
ll din[MAXN];
ll low_of[MAXM];
int S, T, SS, TT;
int n, m;

void add_e(int u, int v, ll c)
{
    e[++ecnt] = {v, head[u], c};
    head[u] = ecnt;
    e[++ecnt] = {u, head[v], 0};
    head[v] = ecnt;
}

bool bfs(int s, int t)
{
    for (int i = 1; i <= n + 2; i++) dep[i] = -1;
    queue<int> qq;
    qq.push(s);
    dep[s] = 0;
    while (!qq.empty())
    {
        int u = qq.front();
        qq.pop();
        for (int i = head[u]; i; i = e[i].nxt)
        {
            int v = e[i].to;
            if (e[i].cap > 0 && dep[v] < 0)
            {
                dep[v] = dep[u] + 1;
                qq.push(v);
            }
        }
    }
    return dep[t] >= 0;
}

ll dfs(int u, int t, ll f)
{
    if (u == t) return f;
    for (int &i = cur[u]; i; i = e[i].nxt)
    {
        int v = e[i].to;
        if (e[i].cap > 0 && dep[v] == dep[u] + 1)
        {
            ll d = dfs(v, t, min(f, e[i].cap));
            if (d > 0)
            {
                e[i].cap -= d;
                e[i ^ 1].cap += d;
                return d;
            }
        }
    }
    return 0;
}

ll maxflow(int s, int t)
{
    ll res = 0;
    while (bfs(s, t))
    {
        for (int i = 1; i <= n + 2; i++) cur[i] = head[i];
        ll d;
        while ((d = dfs(s, t, INF)) > 0) res += d;
    }
    return res;
}

void add_edge(int u, int v, ll low, ll high)
{
    add_e(u, v, high - low);
    din[v] += low;
    din[u] -= low;
}

ll feasible_flow()
{
    ll need = 0;
    for (int i = 1; i <= n; i++)
    {
        if (din[i] > 0)
        {
            add_e(SS, i, din[i]);
            need += din[i];
        }
        else if (din[i] < 0) add_e(i, TT, -din[i]);
    }
    ll got = maxflow(SS, TT);
    if (got < need) return -1;
    return got - need;
}
```

使用说明：
- 无源汇可行流：不连 $T \to S$，直接调 `feasible_flow()`，返回 $\ge 0$ 即存在循环流（返回值无意义，只看是否为 -1）。
- 有源汇最大流：先 `add_e(T, S, INF)` 记下这条边的编号，跑 `feasible_flow()` 判可行；可行后删掉 $T \to S$ 的边（把正反两条容量清零），再 `maxflow(S, T)` 加上前面已经流过的量即为答案。
- `din[v] += low; din[u] -= low;` 是"下界造成的供需失衡"，超级源补正、超级汇消负。
- `n` 为原图点数，超级源汇用 `n+1`、`n+2`，数组开够。

变体：
- 有源汇最小流：可行流之后，改为从 $T$ 向 $S$ 跑最大流（最大能退掉的流量），答案 = 可行流量 − 退流量。
- 费用流上下界：把 Dinic 换成 MCMF，先求可行流再调费用。
- 只判可行不看流量：把 `need` 与 `got` 比较即可。

## 19. DAG 最小路径覆盖 / 最小点覆盖

适用：DAG 上用最少的不相交路径覆盖所有点；二分图最小点覆盖 $=$ 最大匹配；这两个都靠"拆点 + 匹配"。

复杂度：$O(VE)$（匈牙利）。

约定：原图 $n$ 个点，把每个点 $u$ 拆成出点 $u$ 与入点 $u+n$；`match[v]` 记录右部（入点）匹配的左部（出点）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 2005;
const int MAXM = 200005;
int head[MAXN], to[MAXM], nxt[MAXM], ecnt;
int match[MAXN], vis[MAXN];
int n, m, tag;

void add_edge(int u, int v)
{
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

bool dfs(int u)
{
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (vis[v] == tag) continue;
        vis[v] = tag;
        if (!match[v] || dfs(match[v]))
        {
            match[v] = u;
            return true;
        }
    }
    return false;
}

int min_path_cover()
{
    int cnt = 0;
    for (int u = 1; u <= n; u++)
    {
        tag++;
        if (dfs(u)) cnt++;
    }
    return n - cnt;
}
```

使用说明：
- 建图：对 DAG 的每条边 $u \to v$，连 `u → v + n`（左出点连右入点）。
- 答案 $= n - $ 最大匹配数；含义是"每个匹配把两条路径接起来，路径数减一"。
- **最小点覆盖**：二分图里直接跑最大匹配，`ans = 最大匹配数`（König 定理）；输出方案时从左侧未匹配点出发在交错树上标记。
- `tag` 每次 DFS 前自增，替代 `memset(vis)`，省常数。

变体：
- 最小边覆盖（无孤立点）：$n - $ 最大匹配。
- 最大独立集：$n - $ 最大匹配（König 对偶）。
- 路径**可以相交**的最小路径覆盖：先对 DAG 求传递闭包（bitset / Floyd）再按上面拆点匹配。
- 带权最小路径覆盖：改成最小费用最大流。

## 20. 点分治（树上路径统计）

适用：树上"满足条件的路径条数 / 是否存在"（路径长度 $\le K$、距离为 $k$、路径权值和），$n$ 可达 $10^5$。

复杂度：$O(n\log^2 n)$（每层 $O(n\log n)$ 排序，共 $O(\log n)$ 层）。

约定：`solve_centroid(root)` 为主入口，`K` 为阈值；统计"距离和 $\le K$ 的点对数量"。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int MAXM = 200005;
int head[MAXN], to[MAXM], wt[MAXM], nxt[MAXM], ecnt;
int sz[MAXN], mx[MAXN], dead[MAXN], dis[MAXN];
int root, dc;
ll ans;
int n, K;

void add_edge(int u, int v, int w)
{
    to[++ecnt] = v;
    wt[ecnt] = w;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
}

void get_size(int u, int fa)
{
    sz[u] = 1;
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (v == fa || dead[v]) continue;
        get_size(v, u);
        sz[u] += sz[v];
    }
}

void find_root(int u, int fa, int all)
{
    mx[u] = all - sz[u];
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (v == fa || dead[v]) continue;
        find_root(v, u, all);
        mx[u] = max(mx[u], sz[v]);
    }
    if (mx[u] < mx[root]) root = u;
}

void get_dis(int u, int fa, int d)
{
    dis[++dc] = d;
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (v == fa || dead[v]) continue;
        get_dis(v, u, d + wt[i]);
    }
}

ll calc(int u, int d0)
{
    dc = 0;
    get_dis(u, 0, d0);
    sort(dis + 1, dis + dc + 1);
    ll res = 0;
    int l = 1, r = dc;
    while (l < r)
    {
        if (dis[l] + dis[r] <= K)
        {
            res += r - l;
            l++;
        }
        else r--;
    }
    return res;
}

void solve_centroid(int u)
{
    dead[u] = true;
    ans += calc(u, 0);
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (dead[v]) continue;
        ans -= calc(v, wt[i]);
        get_size(v, 0);
        root = 0;
        mx[0] = n;
        find_root(v, 0, sz[v]);
        solve_centroid(root);
    }
}
```

使用说明：
- 初始化：`mx[0] = n;`（`mx[0]` 作为无穷大哨兵），`ans = 0`，`dead[]` 全 0；入口为 `get_size(1,0); root = 0; mx[0] = n; find_root(1,0,sz[1]); solve_centroid(root);`。
- 容斥是关键：`calc(u,0)` 统计经过 $u$ 的路径（含端点在同一子树内的非法路径），对每个儿子再减 `calc(v, w)` 去掉子树内部重复。
- 距离可能超 `K` 时先剪枝：`get_dis` 里若 `d > K` 直接 return（本模板未剪，数据大时加上）。
- 单次遍历 $O(n\log n)$（排序主导），总 $O(n\log^2 n)$。

变体：
- 计数"距离恰好为 $k$"：把双指针换成桶 / 二分查找。
- 求"最短的满足条件路径"：把答案换成最小值，分治时维护最优。
- 树形 DP 能做的（如直径、部分带权路径）优先用 DP，点分治是带权路径统计的通用兜底。

## 21. 一般图最大匹配（带花树）

适用：**非二分图**（存在奇环）的最大匹配，如"朋友配对""棋盘覆盖带约束"，二分图请用匈牙利。

复杂度：$O(n^3)$。

约定：邻接矩阵 `g[u][v]` 存边；`max_match()` 返回匹配数，`match[]` 给出配对（0 表示未匹配）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 505;
int g[MAXN][MAXN];
int match[MAXN], pre[MAXN], base[MAXN], vis[MAXN], qq[MAXN];
int n, m, qh, qt, tag;

int find_base(int x)
{
    return base[x] == x ? x : base[x] = find_base(base[x]);
}

int lca(int u, int v)
{
    tag++;
    while (1)
    {
        u = find_base(u);
        vis[u] = tag;
        if (!match[u]) break;
        u = pre[match[u]];
    }
    while (1)
    {
        v = find_base(v);
        if (vis[v] == tag) return v;
        v = pre[match[v]];
    }
}

void blossom(int u, int v, int b)
{
    while (find_base(u) != b)
    {
        pre[u] = v;
        v = match[u];
        if (vis[v] == 2)
        {
            vis[v] = 1;
            qq[++qt] = v;
        }
        base[find_base(u)] = b;
        base[find_base(v)] = b;
        u = pre[v];
    }
}

int augment(int s)
{
    for (int i = 1; i <= n; i++)
    {
        vis[i] = 0;
        base[i] = i;
        pre[i] = 0;
    }
    qh = 1;
    qt = 0;
    qq[++qt] = s;
    vis[s] = 1;
    while (qh <= qt)
    {
        int u = qq[qh++];
        for (int v = 1; v <= n; v++)
        {
            if (!g[u][v] || find_base(u) == find_base(v) || match[u] == v) continue;
            if (vis[v] == 2) continue;
            if (!vis[v])
            {
                vis[v] = 2;
                pre[v] = u;
                if (!match[v])
                {
                    while (v)
                    {
                        int pv = pre[v], nv = match[pv];
                        match[v] = pv;
                        match[pv] = v;
                        v = nv;
                    }
                    return 1;
                }
                vis[match[v]] = 1;
                qq[++qt] = match[v];
            }
            else
            {
                int b = lca(u, v);
                blossom(u, v, b);
                blossom(v, u, b);
            }
        }
    }
    return 0;
}

int max_match()
{
    int res = 0;
    for (int i = 1; i <= n; i++) match[i] = 0;
    for (int i = 1; i <= n; i++) if (!match[i] && augment(i)) res++;
    return res;
}
```

使用说明：
- 邻接矩阵存双向边（`g[u][v] = g[v][u] = 1`）；`n \le 500$ 时矩阵版最快最省心。
- `tag` 是时间戳，替代每轮 `memset(vis)`；`vis` 取值 1（外层点）/ 2（内层点）/ 0（未访问）。
- 要求"必须有完美匹配"时判 `max_match() * 2 == n`。

变体：
- 稀疏图（$n$ 大 $m$ 小）：改用邻接表 + 并查集缩花，避免 $O(n^2)$ 扫描。
- 二分图务必用匈牙利 / Hopcroft–Karp，带花树在二分图上虽正确但慢。
- 一般图最大权匹配（带花树加权版）实现复杂，竞赛中多用费用流近似或转成整数规划。

## 22. 树的重心 / 直径 / 基环树处理

适用：树上找重心（点分治前置、树形 DP 的根）、直径（两次 DFS / 树形 DP）、基环树（每个点有唯一出边的功能图）拆环后 DP。

复杂度：$O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int MAXM = 200005;
int head[MAXN], to[MAXM], nxt[MAXM], ecnt;
int sz[MAXN], mx_son[MAXN], dep[MAXN];
int centroid, c1, c2;
int n;

void add_edge(int u, int v)
{
    to[++ecnt] = v;
    nxt[ecnt] = head[u];
    head[u] = ecnt;
    to[++ecnt] = u;
    nxt[ecnt] = head[v];
    head[v] = ecnt;
}

void get_centroid(int u, int fa)
{
    sz[u] = 1;
    mx_son[u] = 0;
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (v == fa) continue;
        get_centroid(v, u);
        sz[u] += sz[v];
        mx_son[u] = max(mx_son[u], sz[v]);
    }
    int rest = n - sz[u];
    int cur = max(mx_son[u], rest);
    if (cur < mx_son[centroid] || centroid == 0) centroid = u;
}

void get_diameter_dfs(int u, int fa, int d, int &far, int &best)
{
    if (d > best)
    {
        best = d;
        far = u;
    }
    for (int i = head[u]; i; i = nxt[i])
    {
        int v = to[i];
        if (v == fa) continue;
        get_diameter_dfs(v, u, d + 1, far, best);
    }
}

int get_diameter()
{
    int a = 1, b = 1, best = -1;
    get_diameter_dfs(1, 0, 0, a, best);
    best = -1;
    get_diameter_dfs(a, 0, 0, b, best);
    return best;
}
```

使用说明：
- 重心：使"最大子树大小"最小的点，`get_centroid(1,0)` 后读 `centroid`；树的**两个**重心可由该性质再判一次得到（最大子树恰好 $n/2$ 时存在第二个）。
- 直径：两次 DFS（只适用非负边权，带负权要用树形 DP：`d[u] = max(d[v] + w)` 取两条最长链之和）。
- 基环树：先拓扑剥掉叶子找环（入度为 1 的点不断入队删除），环上用单调队列 / 前缀和做"环上路径最优化"，环上挂的子树各自树形 DP。

变体：
- 树形 DP 求直径（带负权）：`res = max(res, d[u] + d[v] + w)` 在遍历子树时维护。
- 基环树 DP：注意"环上不能同时取相邻两个点"要拆成"强制不选第一个 / 强制不选第二个"两次 DP。
- 内向树（每个点出度 1）：从环上每个点出发反向建树后，就是基环树模型。

## 23. 边双连通分量（缩点）

适用：无向图求边双连通分量（e-DCC）并缩点。缩点后得到一棵树 / 森林，边上只可能是桥；"删一条边后两点是否连通 / 加边使图边双连通"类问题。

复杂度：$O(n + m)$。

约定：边从 1 开始成对编号（`e` 与 `e^1` 互为反向边）；`c[u]` 为点 u 所在边双编号（1..dcc）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int n, m, hd[MAXN], nx[MAXN * 2], to[MAXN * 2], ecnt = 1;
int dfn[MAXN], low[MAXN], stk[MAXN], top, ti, dcc, c[MAXN];
int thd[MAXN], tnx[MAXN * 2], tto[MAXN * 2], tcnt;

void add_edge(int u, int v)
{
    to[ecnt] = v;
    nx[ecnt] = hd[u];
    hd[u] = ecnt++;
}

void add_tree(int u, int v)
{
    tto[++tcnt] = v;
    tnx[tcnt] = thd[u];
    thd[u] = tcnt;
}

void tarjan(int u, int ine)
{
    dfn[u] = low[u] = ++ti;
    stk[++top] = u;
    for (int e = hd[u]; e; e = nx[e])
    {
        if (e == (ine ^ 1)) continue;
        int v = to[e];
        if (!dfn[v])
        {
            tarjan(v, e);
            low[u] = min(low[u], low[v]);
        }
        else low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u])
    {
        dcc++;
        while (1)
        {
            int v = stk[top--];
            c[v] = dcc;
            if (v == u) break;
        }
    }
}

void build()
{
    for (int u = 1; u <= n; u++)
        for (int e = hd[u]; e; e = nx[e])
        {
            int v = to[e];
            if (c[u] != c[v]) add_tree(c[u], c[v]);
        }
}
```

使用说明：
- 主流程：建图（无向边 `add_edge(u, v); add_edge(v, u);`）→ 对每个未访问点 `tarjan(u, 0)` → `build()`。
- 桥 = 原图中 `c[u] != c[v]` 的边，不用单独求。
- 缩点图存 `thd / tnx / tto` 链式前向星，是树 / 森林（无向）；重边、自环均安全。

变体：
- "加多少条边使图边双连通"：缩点后统计树中度为 1 的点数 `p`，答案 $\lceil p/2 \rceil$。
- 边双内部性质：任意两点之间两条**边不相交**路径。

## 24. 点双连通分量（圆方树）

适用：无向图求点双连通分量（v-DCC）并建圆方树。处理"删一个点后连通性 / 两点间经过的点双 / 割点判定"类问题。

复杂度：$O(n + m)$。

约定：圆点 = 原图点 1..n；方点 = 点双，编号 n+1..tot。圆方树边存 `ghd / gnx / gto`（双向边）。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int n, m, hd[MAXN], nx[MAXN * 2], to[MAXN * 2], ecnt = 1;
int dfn[MAXN], low[MAXN], stk[MAXN], top, ti, tot;
int ghd[MAXN * 2], gnx[MAXN * 4], gto[MAXN * 4], gcnt;

void add_edge(int u, int v)
{
    to[ecnt] = v;
    nx[ecnt] = hd[u];
    hd[u] = ecnt++;
}

void add_g(int u, int v)
{
    gto[++gcnt] = v;
    gnx[gcnt] = ghd[u];
    ghd[u] = gcnt;
}

void tarjan(int u)
{
    dfn[u] = low[u] = ++ti;
    stk[++top] = u;
    if (hd[u] == 0)
    {
        tot++;
        add_g(tot, u);
        add_g(u, tot);
        return;
    }
    for (int e = hd[u]; e; e = nx[e])
    {
        int v = to[e];
        if (!dfn[v])
        {
            tarjan(v);
            low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u])
            {
                tot++;
                int w;
                do
                {
                    w = stk[top--];
                    add_g(tot, w);
                    add_g(w, tot);
                } while (w != v);
                add_g(tot, u);
                add_g(u, tot);
            }
        }
        else low[u] = min(low[u], dfn[v]);
    }
}
```

使用说明：
- 主流程：`tot = n;` 后对每个未访问点 `tarjan(u)`。
- 割点 ⟺ 该圆点在圆方树上的度数 ≥ 2；单点（孤立点）也自成一个方点。
- 圆方树上两点路径经过的方点 = 原图两点之间所有路径并集经过的点双；DP 时方点取 min/max、圆点取加，是"割点打断信息传递"类问题的标准套路。

变体：
- 点双内点数 = 该方点在圆方树上相邻圆点数；一个点双最多包含割点与普通点的任意组合，两个相邻点双至多共享一个割点。
- 圆方树 + 虚树（03 第 25 节）处理多次询问；圆方树上跑树剖 / 倍增与普通树完全一样。

## 25. 虚树

适用：多次询问"只涉及树上少数关键点"的问题（k 个关键点的路径覆盖、最小化关键点连通代价、关键点间 DP）。把关键点及其 LCA 压成一棵小树再 DP。

复杂度：单次建树 $O(k \log k)$（排序），全程 $O(\sum k \log n)$。

约定：先 `dfs(根, 0)` 与 `init_lca()`；询问时把关键点放进数组 `a[1..m]`（可乱序），调 `vbuild(a, m)`。虚树边（父→子，边权 = 原树路径长度）存 `vhd / vto / vw`，每次 `vbuild` 开头清空 `vcnt`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int n, hd[MAXN], nx[MAXN * 2], to[MAXN * 2], ecnt = 1;
int dep[MAXN], dfn[MAXN], ti, K;
int fa[20][MAXN];
int vhd[MAXN], vnx[MAXN * 2], vto[MAXN * 2], vcnt, vw[MAXN * 2];
int stk[MAXN], top;

void add_edge(int u, int v)
{
    to[ecnt] = v;
    nx[ecnt] = hd[u];
    hd[u] = ecnt++;
}

void vadd(int u, int v, int w)
{
    vto[++vcnt] = v;
    vnx[vcnt] = vhd[u];
    vw[vcnt] = w;
    vhd[u] = vcnt;
}

void dfs(int u, int f)
{
    dfn[u] = ++ti;
    dep[u] = dep[f] + 1;
    fa[0][u] = f;
    for (int e = hd[u]; e; e = nx[e])
    {
        int v = to[e];
        if (v != f) dfs(v, u);
    }
}

void init_lca()
{
    for (K = 0; (1 << (K + 1)) <= n; K++) ;
    for (int j = 1; j <= K; j++)
        for (int i = 1; i <= n; i++)
            fa[j][i] = fa[j - 1][fa[j - 1][i]];
}

int lca(int x, int y)
{
    if (dep[x] < dep[y]) swap(x, y);
    for (int j = K; j >= 0; j--)
        if (dep[x] - (1 << j) >= dep[y]) x = fa[j][x];
    if (x == y) return x;
    for (int j = K; j >= 0; j--)
        if (fa[j][x] != fa[j][y])
        {
            x = fa[j][x];
            y = fa[j][y];
        }
    return fa[0][x];
}

bool cmp_dfn(int a, int b)
{
    return dfn[a] < dfn[b];
}

void vbuild(int *a, int m)
{
    sort(a + 1, a + m + 1, cmp_dfn);
    vcnt = 0;
    top = 0;
    for (int i = 1; i <= m; i++)
    {
        int u = a[i];
        if (top == 0)
        {
            stk[++top] = u;
            continue;
        }
        int l = lca(u, stk[top]);
        while (top > 1 && dep[stk[top - 1]] >= dep[l])
        {
            vadd(stk[top - 1], stk[top], dep[stk[top]] - dep[stk[top - 1]]);
            top--;
        }
        if (dep[stk[top]] > dep[l])
        {
            vadd(l, stk[top], dep[stk[top]] - dep[l]);
            top--;
        }
        if (top == 0 || stk[top] != l) stk[++top] = l;
        stk[++top] = u;
    }
    while (top > 1)
    {
        vadd(stk[top - 1], stk[top], dep[stk[top]] - dep[stk[top - 1]]);
        top--;
    }
}
```

使用说明：
- 虚树里的点 = 关键点 ∪ 相邻关键点的 LCA；边权 = 原树上两点深度差（两点一定是祖先关系）。
- `vadd` 只加了父→子单向边；以最顶上的点为根向下 DP 够用，需要无向遍历就再补反向边。
- 关键点中若包含根或互为祖先，模板自动处理（祖先成为分支点）；**关键点必须互不相同**。
- DP 完后 `memset(vhd, 0, ...)` 只清用过的点更稳，或每次询问前对 `a` 里出现过的点清零。

变体：
- 边权 1 的题（关键点距离）直接用 `dep` 差；需要原树上"路径中间点"信息时在虚树边上挂额外信息。
- 圆方树（03 第 24 节）上建虚树是"图上询问"的完整套路。

## 26. 0-1 BFS（边权只有 0 / 1 的最短路）

适用：边权非负且**只有 0 和 1** 的单源最短路。比 Dijkstra 少一个 log、比 SPFA 稳；"翻转边权 / 免费通行 k 次"拆点后的图基本都是这种形态。

复杂度：$O(n + m)$，空间 $O(n + m)$。

约定：前向星存图，边权只能是 0 或 1，下标从 1 开始；结果在 `dis[]`。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int INF = 0x3f3f3f3f;
int n, m;
int hd[MAXN], nx[MAXN * 2], to[MAXN * 2], w[MAXN * 2], ecnt = 1;
int dis[MAXN];

void add_edge(int u, int v, int ww)
{
    to[ecnt] = v;
    w[ecnt] = ww;
    nx[ecnt] = hd[u];
    hd[u] = ecnt++;
}

void bfs01(int s)
{
    for (int i = 1; i <= n; i++) dis[i] = INF;
    deque<int> dq;
    dis[s] = 0;
    dq.push_back(s);
    while (!dq.empty())
    {
        int u = dq.front();
        dq.pop_front();
        for (int e = hd[u]; e; e = nx[e])
        {
            int v = to[e];
            if (dis[v] > dis[u] + w[e])
            {
                dis[v] = dis[u] + w[e];
                if (w[e] == 0) dq.push_front(v);
                else dq.push_back(v);
            }
        }
    }
}
```

使用说明：
- 每个点可能**多次入队**，不要加 `vis` 判重（这是它和 BFS 最大的区别）；出队时不代表已是最短路，靠 `dis` 松弛保证正确。
- 队列里始终满足"距离相差不超过 1"的单调性（队首 `d`、队尾 `d+1`），所以取队首即当前最小。
- 无向边两条都要 `add_edge`；边权必须非负。

变体：
- 边权只有 0 / 1 / 2：改用 **Dial 算法**——建 3 个桶（或 `vector` 数组）按下标 `dis % 3` 循环取，复杂度仍是 $O(n + m)$。
- "免费走 k 条边"：拆成 $(u, j)$ 两层状态（$j$ 为已用次数），免费边权 0、付费边权 1，直接 0-1 BFS，状态数 $O(nk)$。
- 边权是任意小整数（$\le W$）：桶式 Dijkstra（`vector` 桶 + 当前最小距离指针）。

## 27. 树上差分（点差分 / 边差分）

适用：**多次路径修改、最后统一求值**（每个点/边被多少条路径覆盖、路径加后求点权）。离线，$O((n + q) \log n)$。

复杂度：每次修改 $O(\log n)$（LCA），最后一次 DFS 汇总 $O(n)$，空间 $O(n \log n)$。

约定：边上权值**下放到深度较大的端点**；`dif[]` 是差分数组，`collect(1, 0)` 之后 `dif[u]` 才是点 $u$（或 $u$ 到父边）的最终值。点差分与边差分**不要同时用同一个 `dif`**。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int n, q;
int hd[MAXN], nx[MAXN * 2], to[MAXN * 2], ecnt = 1;
int dep[MAXN], fa[20][MAXN], K;
int dif[MAXN];

void add_edge(int u, int v)
{
    to[ecnt] = v;
    nx[ecnt] = hd[u];
    hd[u] = ecnt++;
}

void dfs(int u, int f)
{
    dep[u] = dep[f] + 1;
    fa[0][u] = f;
    for (int e = hd[u]; e; e = nx[e])
    {
        int v = to[e];
        if (v != f) dfs(v, u);
    }
}

void init_lca()
{
    for (K = 0; (1 << (K + 1)) <= n; K++) ;
    for (int j = 1; j <= K; j++)
        for (int i = 1; i <= n; i++)
            fa[j][i] = fa[j - 1][fa[j - 1][i]];
}

int lca(int x, int y)
{
    if (dep[x] < dep[y]) swap(x, y);
    for (int j = K; j >= 0; j--)
        if (dep[x] - (1 << j) >= dep[y]) x = fa[j][x];
    if (x == y) return x;
    for (int j = K; j >= 0; j--)
        if (fa[j][x] != fa[j][y])
        {
            x = fa[j][x];
            y = fa[j][y];
        }
    return fa[0][x];
}

void add_point(int u, int v, int c)
{
    int l = lca(u, v);
    dif[u] += c;
    dif[v] += c;
    dif[l] -= c;
    if (fa[0][l]) dif[fa[0][l]] -= c;
}

void add_path_edge(int u, int v, int c)
{
    int l = lca(u, v);
    dif[u] += c;
    dif[v] += c;
    dif[l] -= 2 * c;
}

int collect(int u, int f)
{
    int s = dif[u];
    for (int e = hd[u]; e; e = nx[e])
    {
        int v = to[e];
        if (v != f) s += collect(v, u);
    }
    dif[u] = s;
    return s;
}
```

使用说明：
- **点差分**（路径上的点都加 $c$，含两端）：`add_point(u, v, c)`；**边差分**（路径上的边都加 $c$）：`add_path_edge(u, v, c)`。两种各调一种，别混。
- 全部修改做完后调一次 `collect(1, 0)`：之后 `dif[u]` = 点 $u$ 被覆盖的次数（点差分）或 $u$ 到父边被覆盖的次数（边差分）。**根节点没有父边**，边差分时根的值要忽略。
- 多个路径分别计数、再按值分类（如"恰好被 k 条路径覆盖的点数"）：汇总后排序或桶计数即可。
- 单点询问也要先 `collect`；边差分求"每条边覆盖数"用 `dif[v]`（$v$ 是深度较大的端点）。

变体：
- 路径**赋值 / 更复杂运算**不能差分，改用树剖 + 线段树（03 第 6 节）。
- 只改点权、不查路径：直接树上差分 + 一次 DFS；要强制在线就上树剖。
- 子树修改：进 `dfn[u]` 出 `dfn[u] + sz[u] - 1` 的区间，转成序列差分（配合 02 第 1 节树状数组）。

## 28. 次短路（Dijkstra 同时维护最短路与次短路）

适用：求 $s \to t$ 的次短路长度（**允许重复经过点与边**，即"长度严格第二小"的路径）；也可判"是否存在两条长度不同的路径"。比"删边枚举"少一个数量级。

复杂度：$O((n + m)\log n)$，空间 $O(n + m)$。

约定：边权非负；`d1[]` 最短路、`d2[]` 次短路（严格大于 `d1`，不存在为 INF）。每个点最多入队两次（松弛成功时）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
int n, m;
vector<pair<int, ll>> g[MAXN];
ll d1[MAXN], d2[MAXN];

void dijkstra(int s)
{
    for (int i = 1; i <= n; i++)
    {
        d1[i] = INF;
        d2[i] = INF;
    }
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    d1[s] = 0;
    pq.push({0, s});
    while (!pq.empty())
    {
        ll d = pq.top().first;
        int u = pq.top().second;
        pq.pop();
        if (d > d2[u]) continue;
        for (auto ed : g[u])
        {
            int v = ed.first;
            ll nd = d + ed.second;
            if (nd < d1[v])
            {
                d2[v] = d1[v];
                d1[v] = nd;
                pq.push({nd, v});
            }
            else if (nd > d1[v] && nd < d2[v])
            {
                d2[v] = nd;
                pq.push({nd, v});
            }
        }
    }
}
```

使用说明：
- 结果：次短路是 `d2[t]`；`d2[t] == INF` 表示不存在与最短路不同的路径。
- **判重条件必须是 `nd > d1[v]`**：如果把 `nd == d1[v]` 也当松弛，会把"另一条等长路径"塞进次短路，得到的就不是严格次短路。
- 出队时用 `d > d2[u]` 剪枝（过期状态直接跳过），两个数组都会被更新，所以每个点可能入队两次。
- 求"源点到所有点的次短路"一次 Dijkstra 全部拿到；多源同理把多个源 `d1 = 0` 入队。

变体：
- **严格次短路且要求简单路径**（不能重复点）：这张模板不保证，需要"枚举每条边做端点最短路"或改状态为"路径长度 + 已用点数"，规模小时用 $O(m(n+m)\log n)$ 的枚举边做法。
- 第 k 短路：A*（估价函数用反图最短路）或可持久化左偏树。
- 次小生成树：MST 后枚举每条非树边替换环上最大边（配合 LCA）。

## 29. 同余最短路（模意义下的可达性）

适用：给 $n$ 个正整数 $a_1 \sim a_n$，问"用它们（每个可用任意多次）能凑出多少个 $\le h$ 的数"、或"最小能凑出的 $\equiv r \pmod{a_1}$ 的数"。经典模型：跳楼机、墨墨的等式、货币系统计数。

复杂度：$O(a_1 \log a_1 \cdot n)$（Dijkstra 跑在 $a_1$ 个点的图上），空间 $O(a_1 + n)$。

约定：以 $a_1$ 为模（**取最小的那个作为 $a_1$**，否则点数爆炸）；`dis[r]` = 能凑出的最小且 $\equiv r \pmod{a_1}$ 的数。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const ll INF = 0x3f3f3f3f3f3f3f3fLL;
const int MAXN = 1000005;
int n;
ll a[MAXN], h;
ll dis[MAXN];
int vis[MAXN];

ll count_reachable(ll limit)
{
    for (int i = 0; i < a[1]; i++)
    {
        dis[i] = INF;
        vis[i] = 0;
    }
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> pq;
    dis[0] = 0;
    pq.push({0, 0});
    while (!pq.empty())
    {
        int u = pq.top().second;
        pq.pop();
        if (vis[u]) continue;
        vis[u] = 1;
        for (int i = 2; i <= n; i++)
        {
            int v = (u + a[i]) % a[1];
            ll nd = dis[u] + a[i];
            if (nd < dis[v])
            {
                dis[v] = nd;
                pq.push({nd, v});
            }
        }
    }
    ll res = 0;
    for (int i = 0; i < a[1]; i++)
        if (dis[i] <= limit) res += (limit - dis[i]) / a[1] + 1;
    return res;
}
```

使用说明：
- 建图思路：点 = 模 $a_1$ 的余数，从 $r$ 向 $(r + a_i) \bmod a_1$ 连权为 $a_i$ 的边；$dis[r]$ 就是"最小可达的该余数"。之后**每个余数 $r$ 能表示出 $dis[r], dis[r] + a_1, dis[r] + 2a_1, \dots$**，所以 $\le h$ 的个数是 $\lfloor (h - dis[r])/a_1 \rfloor + 1$。
- `count_reachable(h)` **把 0 也算进去了**（$dis[0] = 0$）；题目只要正整数就 `res - 1`（$h \ge 0$ 时）。
- $a_1$ 取最小元素；只要 $a[1] = 1$ 就有 $dis[0..0]$，答案直接是 $h + 1$（所有数都能凑）。
- 求"最小凑出的数"直接用 `dis[]`；求"不能凑出的最大数"要判 $\gcd$ 是否为 1。

变体：
- **每个数有使用次数限制**：把点扩成 $(r, \text{次数})$ 或改成完全背包 + 单调队列（限制小时）。
- 模数很大（$a_1$ 到 $10^9$）但 $n$ 小、且存在两个互质的小数时，改取次小的数当模。
- 求方案数（不是可达个数）：转成生成函数 / 完全背包（$h$ 小时）。

## 30. Stoer–Wagner 全局最小割

适用：**无向图**全局最小割（不指定源汇），$n \le 500$ 的稠密图。最大流做法要枚举 $n-1$ 次源汇，这个是 $O(n^3)$ 一次算完。

复杂度：$O(n^3)$，空间 $O(n^2)$。

约定：邻接矩阵 `g[u][v]` 存边权和（**多重边要累加**），下标从 1 开始，$n \ge 2$；每次调用会破坏 `g`。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 505;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
int n, m;
ll g[MAXN][MAXN];
ll w[MAXN];
int vis[MAXN];
int del[MAXN];

ll stoer_wagner()
{
    ll best = INF;
    for (int i = 1; i <= n; i++) del[i] = 0;
    for (int phase = 1; phase < n; phase++)
    {
        for (int i = 1; i <= n; i++)
        {
            w[i] = 0;
            vis[i] = 0;
        }
        int s = 0;
        for (int step = 1; step <= n - phase + 1; step++)
        {
            int k = 0;
            for (int i = 1; i <= n; i++)
                if (!del[i] && !vis[i] && (!k || w[i] > w[k])) k = i;
            vis[k] = 1;
            if (step == n - phase + 1)
            {
                best = min(best, w[k]);
                for (int i = 1; i <= n; i++)
                    if (!del[i] && i != k)
                    {
                        g[s][i] += g[k][i];
                        g[i][s] += g[i][k];
                    }
                del[k] = 1;
            }
            else
            {
                s = k;
                for (int i = 1; i <= n; i++)
                    if (!del[i] && !vis[i]) w[i] += g[k][i];
            }
        }
    }
    return best;
}
```

使用说明：
- 每轮"最大邻接搜索"：反复取 $w$ 最大的未访问点加入集合，最后一个加入的点 $t$ 的 $w[t]$ 就是"当前集合与剩下部分"的割权；记 $s$ 为第一个加入的点，把 $t$ 合并进 $s$（边权相加），删掉 $t$。
- 答案取所有轮的最小割权；$n = 2$ 时返回两点间边权。
- **必须传对称矩阵**：`g[u][v]` 与 `g[v][u]` 都要填，否则合并时只加一边后续轮次的 $w$ 会错。
- 图不连通时答案是 0（合法：割成两个连通块）。

变体：
- 稀疏图（$m \ll n^2$）：最大流枚举源汇在稀疏图上反而更快（$n-1$ 次 Dinic）。
- 带点权 / 带容量下界：转成边权预处理。
- 全局最小割的**方案**（哪些点在一侧）：需要额外记录合并树（Gomory–Hu 树），赛场少见。

## 31. 最大团（分支限界 + bitset）

适用：无向图最大团（两两相邻的点集最大大小），$n \le 100$ 的稠密图；也可判"是否存在大小 $\ge k$ 的团"（把 `best` 初始化为 $k-1$ 提前收敛）。竞赛里常配合"补图最大独立集 = 原图最大团"使用。

复杂度：最坏 $O(3^{n/3})$（理论），加了剪枝与 bitset 后对 $n \le 100$ 的随机图与多数构造图很快。

约定：`nbr[v]` 是 $v$ 的邻接位集（**不含自己**），点编号 1..n；`cand[depth]` 是第 `depth` 层的候选集合。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
int n, m, best;
bitset<MAXN> nbr[MAXN];
bitset<MAXN> cand[MAXN];

void expand(int depth)
{
    if (depth + (int)cand[depth].count() <= best) return;
    if (cand[depth].none())
    {
        if (depth > best) best = depth;
        return;
    }
    bitset<MAXN> c = cand[depth];
    for (int v = 1; v <= n; v++)
    {
        if (!c[v]) continue;
        if (depth + (int)cand[depth].count() <= best) return;
        cand[depth + 1] = cand[depth] & nbr[v];
        expand(depth + 1);
        cand[depth][v] = 0;
    }
    if (depth > best) best = depth;
}

int max_clique()
{
    best = 0;
    cand[0].reset();
    for (int i = 1; i <= n; i++) cand[0][i] = 1;
    expand(0);
    return best;
}
```

使用说明：
- 加边：`nbr[u][v] = nbr[v][u] = 1;`（**不要**设 `nbr[v][v]`，自环会让候选集无法收缩）。
- 剪枝 `depth + |cand| <= best` 是关键：每轮迭代都重算一次 `cand[depth].count()`，靠"候选集只会变小"提前退出。
- 求"至少 k 个点"时把 `best = k - 1` 起跳（`max_clique` 里改 `best` 初值），找到就直接返回，快很多。
- 最大独立集：在**补图**上求最大团（`nbr` 填反边），或直接对原图求"最大点集两两无边"。
- `depth` 最大为团大小，`cand` 数组要开到 `MAXN`；`bitset<MAXN>` 的 `count()` 是 $O(\text{MAXN}/64)$，常数很小。

变体：
- 难例（如 Mycielski 图、$n$ 上百的稀疏图）会退化：加 **coloring 上界**（把候选点按贪心染色数作为上界替代 $|cand|$）能把 $n \le 200$ 的多数图压下来。
- 最大权团 / 带权独立集：把计数换成权值和，剪枝用"剩余点上界"。
- 极大团枚举（Bron–Kerbosch with pivoting）：输出所有极大团，$O(3^{n/3})$。
