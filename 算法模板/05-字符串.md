# 05 · 字符串

> 约定：字符串下标均从 1 开始（`s[1..n]`），空字符 `s[0]` 不用。

## 1. 字符串双哈希

适用：快速判两个子串是否相等（配合二分可判最长公共前缀）。双哈希防碰撞。

复杂度：预处理 $O(n)$，子串比较 $O(1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
const ll MOD1 = 1000000007;
const ll MOD2 = 1000000009;
const ll BASE = 131;
ll h1[MAXN], h2[MAXN];
ll p1[MAXN], p2[MAXN];

void init_hash(char *s, int n)
{
    p1[0] = p2[0] = 1;
    for (int i = 1; i <= n; i++)
    {
        p1[i] = p1[i - 1] * BASE % MOD1;
        p2[i] = p2[i - 1] * BASE % MOD2;
    }
    for (int i = 1; i <= n; i++)
    {
        h1[i] = (h1[i - 1] * BASE + s[i]) % MOD1;
        h2[i] = (h2[i - 1] * BASE + s[i]) % MOD2;
    }
}

ll get_h1(int l, int r)
{
    return (h1[r] - h1[l - 1] * p1[r - l + 1] % MOD1 + MOD1) % MOD1;
}

ll get_h2(int l, int r)
{
    return (h2[r] - h2[l - 1] * p2[r - l + 1] % MOD2 + MOD2) % MOD2;
}

bool eq(int l1, int r1, int l2, int r2)
{
    return get_h1(l1, r1) == get_h1(l2, r2) && get_h2(l1, r1) == get_h2(l2, r2);
}
```

使用说明：
- 双哈希同时相等才认为子串相等，几乎不碰撞。
- BASE 取 131 / 13331，字符直接按 ASCII 值进入哈希。

变体：
- 带修改的哈希：用线段树 / BIT 维护哈希值区间合并。
- 最长回文二分：对每个中心二分半径，哈希判断两侧相等。

## 2. KMP（失配 / 周期）

适用：主串中找模式串出现位置、次数；求字符串最小循环节。

复杂度：$O(n + m)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
int nxt[MAXN];
int match_pos[MAXN];
int match_cnt;

void get_next(char *p, int m)
{
    nxt[1] = 0;
    for (int i = 2, j = 0; i <= m; i++)
    {
        while (j > 0 && p[i] != p[j + 1])
        {
            j = nxt[j];
        }
        if (p[i] == p[j + 1]) j++;
        nxt[i] = j;
    }
}

void kmp(char *t, int n, char *p, int m)
{
    match_cnt = 0;
    for (int i = 1, j = 0; i <= n; i++)
    {
        while (j > 0 && t[i] != p[j + 1])
        {
            j = nxt[j];
        }
        if (t[i] == p[j + 1]) j++;
        if (j == m)
        {
            match_pos[++match_cnt] = i - m + 1;
            j = nxt[j];
        }
    }
}
```

使用说明：
- `get_next(p, m)` 先算失配表；`kmp(t, n, p, m)` 后 `match_pos[1..match_cnt]` 为所有匹配起点。
- 最小循环节：长度 `len = m - nxt[m]`，若 `m % len == 0` 则循环节为 len，否则无完整循环。
- 求出现次数（可重叠）即 match_cnt。

变体：
- 扩展 KMP（Z 函数）：求每个后缀与模式串的最长公共前缀，$O(n)$。
- 前缀函数可做"最小表示法"。

## 3. AC 自动机（多模式匹配）

适用：一个文本串同时匹配多个模式串（关键词计数、出现位置）。

复杂度：构建 $O(\sum|\text{模式}|)$，匹配 $O(\text{文本长度})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 500005;
int ch[MAXN][26];
int fail[MAXN];
int cnt[MAXN];
int tot;

void insert(char *s)
{
    int u = 0;
    for (int i = 0; s[i]; i++)
    {
        int c = s[i] - 'a';
        if (!ch[u][c]) ch[u][c] = ++tot;
        u = ch[u][c];
    }
    cnt[u]++;
}

void build_ac()
{
    queue<int> q;
    for (int c = 0; c < 26; c++) if (ch[0][c]) q.push(ch[0][c]);
    while (!q.empty())
    {
        int u = q.front();
        q.pop();
        for (int c = 0; c < 26; c++)
        {
            if (ch[u][c])
            {
                fail[ch[u][c]] = ch[fail[u]][c];
                q.push(ch[u][c]);
            }
            else ch[u][c] = ch[fail[u]][c];
        }
    }
}

int query(char *s)
{
    int u = 0, res = 0;
    for (int i = 0; s[i]; i++)
    {
        u = ch[u][s[i] - 'a'];
        for (int v = u; v && cnt[v] != -1; v = fail[v])
        {
            res += cnt[v];
            cnt[v] = -1;
        }
    }
    return res;
}
```

使用说明：
- 先对每个模式串 `insert`，再 `build_ac()`，最后 `query(文本)` 返回命中次数总和。
- `cnt[v] = -1` 表示已统计过（去重）。若需计数每个模式串出现次数，用 `cnt` 数组统计不置 -1，配合拓扑累加。
- 字符集 26 可改（换字符集大小与映射）。

变体：
- 每个模式串出现次数：query 时只 `res += cnt[v]` 且不置 -1，`cnt` 改为记录进入次数，按 fail 树拓扑累加。
- AC 自动机 + DP（禁止串计数）、AC 自动机 + 矩阵快速幂（有限状态转移）。

## 4. Manacher（最长回文）

适用：$O(n)$ 求每个位置为中心的最长回文半径、最长回文子串长度。

复杂度：$O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
char s[MAXN * 2];
int p[MAXN * 2];

int manacher(char *str)
{
    int n = 0;
    s[n++] = '^';
    s[n++] = '#';
    for (int i = 0; str[i]; i++)
    {
        s[n++] = str[i];
        s[n++] = '#';
    }
    s[n++] = '$';
    int mx = 0, id = 0, ans = 0;
    for (int i = 1; i < n; i++)
    {
        p[i] = mx > i ? min(p[2 * id - i], mx - i) : 1;
        while (s[i - p[i]] == s[i + p[i]])
        {
            p[i]++;
        }
        if (i + p[i] > mx)
        {
            mx = i + p[i];
            id = i;
        }
        ans = max(ans, p[i] - 1);
    }
    return ans;
}
```

使用说明：
- 传入原始字符串（0 下标），返回最长回文子串长度。
- 构造后的 `s` 用 `#` 分隔，`p[i]` 为半径；原串中以 i 为中心的回文串长 `p[i]-1`。

变体：
- 统计回文串个数：$\sum (p[i]/2)$（按奇偶中心分开算）。
- 回文自动机（PAM）用于更复杂的回文计数。

## 5. Trie（字典树）

适用：前缀统计、字符串集合存储、异或最大（01 Trie）。

复杂度：插入 / 查询 $O(\text{长度})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 500005;
int ch[MAXN][26];
int val[MAXN];
int tot;

void insert(char *s)
{
    int u = 0;
    for (int i = 0; s[i]; i++)
    {
        int c = s[i] - 'a';
        if (!ch[u][c]) ch[u][c] = ++tot;
        u = ch[u][c];
    }
    val[u]++;
}

int query_prefix(char *s)
{
    int u = 0;
    for (int i = 0; s[i]; i++)
    {
        int c = s[i] - 'a';
        if (!ch[u][c]) return 0;
        u = ch[u][c];
    }
    return val[u];
}
```

使用说明：
- `val[u]` 记录以该节点结尾的字符串数量（插入重复串计数）。
- 求"以 s 为前缀的串个数"：需在插入时对路径上每个节点 `val[u]++`（前缀计数），此处 `val[u]` 改存子树串数。

变体：
- 01 Trie：字符集 {0,1}，配合贪心求最大异或对。
- 可持久化 Trie：区间内最大异或。
- 自动补全 / 排序（Trie 序即字典序）。

## 6. 后缀数组 SA（倍增 + 基数排序）

适用：所有后缀排序，配合 height 数组求最长公共前缀 / 子串、本质不同子串数等。

复杂度：$O(n\log n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
char s[MAXN];
int sa[MAXN], rk[MAXN * 2], ht[MAXN];
int tmp[MAXN], cnt[MAXN];
int n;

void build_sa()
{
    int m = 300;
    for (int i = 1; i <= n; i++) rk[i] = s[i];
    memset(cnt, 0, sizeof(cnt));
    for (int i = 1; i <= n; i++) cnt[rk[i]]++;
    for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
    for (int i = n; i >= 1; i--) sa[cnt[rk[i]]--] = i;
    for (int w = 1; w < n; w <<= 1)
    {
        int p = 0;
        for (int i = n - w + 1; i <= n; i++) tmp[++p] = i;
        for (int i = 1; i <= n; i++) if (sa[i] > w) tmp[++p] = sa[i] - w;
        memset(cnt, 0, sizeof(cnt));
        for (int i = 1; i <= n; i++) cnt[rk[tmp[i]]]++;
        for (int i = 1; i <= m; i++) cnt[i] += cnt[i - 1];
        for (int i = n; i >= 1; i--) sa[cnt[rk[tmp[i]]]--] = tmp[i];
        p = 0;
        for (int i = 1; i <= n; i++)
        {
            if (i > 1 && rk[sa[i]] == rk[sa[i - 1]] && rk[sa[i] + w] == rk[sa[i - 1] + w]) tmp[sa[i]] = p;
            else tmp[sa[i]] = ++p;
        }
        for (int i = 1; i <= n; i++) rk[i] = tmp[i];
        m = p;
        if (m == n) break;
    }
    for (int i = 1; i <= n; i++) rk[sa[i]] = i;
}

void build_height()
{
    int k = 0;
    for (int i = 1; i <= n; i++)
    {
        if (rk[i] == 1)
        {
            k = 0;
            continue;
        }
        int j = sa[rk[i] - 1];
        while (i + k <= n && j + k <= n && s[i + k] == s[j + k])
        {
            k++;
        }
        ht[rk[i]] = k;
        if (k) k--;
    }
}
```

使用说明：
- `s[1..n]` 为字符串，调用 `build_sa()` 与 `build_height()`。
- `sa[i]`：排名 i 的后缀起点；`rk[i]`：起点 i 的后缀排名；`ht[i]`：排名 i 与 i-1 后缀的 LCP。
- `rk` 数组需保证下标越界访问为 0（后缀末尾补 0，代表空后缀排最前），本题数组已开足够大且多轮后 rk 其余位置为 0。
- 本质不同子串数：$n(n+1)/2 - \sum ht[i]$。

变体：
- 求任意两后缀 LCP：height 数组上 RMQ（ST 表）。
- 最长重复子串：$\max(ht[i])$。
- 可结合二分做"出现至少 k 次的最长子串"。

## 7. Z 函数 / 扩展 KMP

适用：求"每个后缀与原串的最长公共前缀"（`z[]`），或"主串每个后缀与模式串的最长公共前缀"（`ex[]`，即扩展 KMP）；字符串周期、匹配次数统计、字符串拼接 LCP 都用。

复杂度：$O(n)$。

约定：字符串存全局 `s[]`（下标从 **1** 开始，`s[0]` 留空），长度 `n`；`z[i]` 为 $s[i..n]$ 与 $s[1..n]$ 的 LCP 长度。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
char s[MAXN], t[MAXN];
int z[MAXN], ex[MAXN];
int n, tn;

void get_z()
{
    z[1] = n;
    for (int i = 2, l = 0, r = 0; i <= n; i++)
    {
        if (i <= r) z[i] = min(z[i - l + 1], r - i + 1);
        while (i + z[i] <= n && s[i + z[i]] == s[1 + z[i]]) z[i]++;
        if (i + z[i] - 1 > r)
        {
            l = i;
            r = i + z[i] - 1;
        }
    }
}

void get_ex()
{
    get_z();
    int l = 0, r = 0;
    for (int i = 1; i <= n; i++)
    {
        if (i <= r) ex[i] = min(z[i - l + 1], r - i + 1);
        while (i + ex[i] <= n && ex[i] < tn && s[i + ex[i]] == t[1 + ex[i]]) ex[i]++;
        if (i + ex[i] - 1 > r)
        {
            l = i;
            r = i + ex[i] - 1;
        }
    }
}
```

使用说明：
- `get_z()`：只依赖 `s[]` 与 `n`，得到 `z[1..n]`（`z[1] = n`）。
- `get_ex()`：求出主串 `s[]` 的每个位置与模式串 `t[]` 的 LCP，存 `ex[1..n]`；`ex[i] == tn` 表示 $t$ 在 $i$ 处出现。
- 与 KMP 的区别：KMP 求"模式串在哪些位置出现"，Z 函数求"每个位置能匹配多长"，处理"最长公共前后缀+公共前缀"混合问题时 Z 更好写。

变体：
- 求 $s$ 的最短循环节：最小的 $p$ 使 $z[p+1] = n - p$ 且 $p \mid n$。
- 求两串的最长公共子串的前缀性质：把 $t + \text{分隔符} + s$ 拼起来跑 Z，分隔符取未出现字符。
- 统计每个前缀出现次数：`z[i]` 结果的差分统计（`cnt[z[i]]++` 后从大到小累加到 `cnt[z[i]-1]` 上）。

## 8. 后缀自动机 SAM

适用：本质不同子串个数、子串出现次数、最长公共子串（多串）、字典序第 k 小子串、与树链/DP 结合的子串统计。

复杂度：构造 $O(n\cdot|\Sigma|)$（转移用数组），状态数 $\le 2n-1$。

约定：字符已映射为 $0..CH-1$；`st[0]` 为初始状态，`link` 为后缀链接（$-1$ 表示根）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
const int CH = 26;

struct State
{
    int len, link;
    int nxt[CH];
} st[MAXN * 2];
int sz_sam, last;
ll cnt[MAXN * 2];
int ord[MAXN * 2], buc[MAXN * 2];
char s[MAXN];
int n;

void sam_init()
{
    st[0].len = 0;
    st[0].link = -1;
    for (int c = 0; c < CH; c++) st[0].nxt[c] = 0;
    sz_sam = 1;
    last = 0;
}

void sam_extend(int c)
{
    int cur = sz_sam++;
    st[cur].len = st[last].len + 1;
    st[cur].link = 0;
    for (int i = 0; i < CH; i++) st[cur].nxt[i] = 0;
    cnt[cur] = 1;
    int p = last;
    while (p != -1 && !st[p].nxt[c])
    {
        st[p].nxt[c] = cur;
        p = st[p].link;
    }
    if (p == -1) st[cur].link = 0;
    else
    {
        int q = st[p].nxt[c];
        if (st[p].len + 1 == st[q].len) st[cur].link = q;
        else
        {
            int clone = sz_sam++;
            st[clone] = st[q];
            st[clone].len = st[p].len + 1;
            cnt[clone] = 0;
            while (p != -1 && st[p].nxt[c] == q)
            {
                st[p].nxt[c] = clone;
                p = st[p].link;
            }
            st[q].link = st[cur].link = clone;
        }
    }
    last = cur;
}

void sam_build()
{
    sam_init();
    for (int i = 1; i <= n; i++) sam_extend(s[i] - 'a');
    for (int i = 0; i < sz_sam; i++) buc[i] = 0;
    for (int i = 0; i < sz_sam; i++) buc[st[i].len]++;
    for (int i = 1; i <= n; i++) buc[i] += buc[i - 1];
    for (int i = sz_sam - 1; i >= 0; i--) ord[--buc[st[i].len]] = i;
    for (int i = sz_sam - 1; i >= 1; i--) cnt[st[ord[i]].link] += cnt[ord[i]];
}

ll distinct_substr()
{
    ll res = 0;
    for (int i = 1; i < sz_sam; i++) res += st[i].len - st[st[i].link].len;
    return res;
}
```

使用说明：
- 建机：先 `sam_build()`（内部含 `sam_init` 与按 `len` 桶排序求 `cnt`）。
- `cnt[v]` 是状态 $v$ 的 `endpos` 大小，即该状态代表的每个子串在母串中的出现次数（clone 结点初值 0，靠拓扑累加）。
- 本质不同子串数 $= \sum_v (\mathrm{len}_v - \mathrm{len}_{\mathrm{link}_v})$。
- 每个状态代表的子串长度区间是 $(\mathrm{len}_{\mathrm{link}_v}, \mathrm{len}_v]$。

变体：
- 求子串 $T$ 出现次数：从根沿转移走完 $T$，末状态的 `cnt` 即答案；走不动则出现 0 次。
- 字典序第 $k$ 小子串：在 DAG 上按转移 DP 求"从该状态出发能走出的子串数"，再逐位定位（重复算多次时用 `cnt` 加权）。
- 多串最长公共子串：对第一个串建 SAM，其余串在上面跑匹配并在失配时跳 `link`，每个状态取历史最小值后全局取最大。
- 广义后缀自动机（多串共用一个 SAM）：每次插入新串前 `last = 0`。
- 字符集较大（如所有 ASCII）时把 `nxt` 换成 `map`，状态数不变但省空间。

## 9. 字符串最小表示

适用：循环同构的字符串中找字典序最小的那一个（如判断两串是否循环同构、求最小字典序循环串）。

复杂度：$O(n)$。

约定：`s[]` 为全局字符数组（下标从 1 开始）；返回最小表示的起始位置（1-based）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
char s[MAXN];
int n;

int min_rep()
{
    int i = 1, j = 2, k = 0;
    while (i <= n && j <= n && k < n)
    {
        char a = s[i + k > n ? i + k - n : i + k];
        char b = s[j + k > n ? j + k - n : j + k];
        if (a == b) k++;
        else
        {
            if (a > b) i = i + k + 1;
            else j = j + k + 1;
            if (i == j) j++;
            k = 0;
        }
    }
    return i < j ? i : j;
}
```

使用说明：
- 返回最小表示的首字符位置，从该位置往后读 $n$ 个字符（循环取模）即为最小表示。
- 两串循环同构判定：各自求最小表示后比较是否相同。
- 求最大表示：把 `a > b` 与 `a < b` 的分支互换。

变体：
- 直接输出最小表示串：循环 $n$ 次取 `s[(pos + t - 2) % n + 1]`。
- 最小表示与 SAM / KMP 结合做"循环串匹配"：先求最小表示再套 KMP。
- 数组版（非字符）：把 `char` 换成整型比较即可，逻辑完全一致。

## 10. 回文自动机（PAM）

适用：回文串问题：本质不同回文子串个数、每个回文出现次数、以 i 结尾的最长回文、回文树上 DP。

复杂度：$O(n)$（均摊，字符集 O(1) 转移）。

约定：s 读入 `s[1..n]`（**1 下标**）；结点 0 = 偶回文根（长 0），结点 1 = 奇回文根（长 -1）；字符集小写字母。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int tot, last, len[MAXN], fail[MAXN], cnt[MAXN], ch[MAXN][26];
char s[MAXN];

void init()
{
    tot = 1;
    len[0] = 0;
    fail[0] = 1;
    len[1] = -1;
    fail[1] = 1;
    last = 0;
}

int getfail(int x, int i)
{
    while (s[i - len[x] - 1] != s[i]) x = fail[x];
    return x;
}

void extend(int i)
{
    int c = s[i] - 'a';
    int p = getfail(last, i);
    if (!ch[p][c])
    {
        int now = ++tot;
        len[now] = len[p] + 2;
        fail[now] = ch[getfail(fail[p], i)][c];
        ch[p][c] = now;
    }
    last = ch[p][c];
    cnt[last]++;
}
```

使用说明：
- 主流程：`init();` 读串到 `s[1..n]`，`for (i = 1..n) extend(i);`。
- 本质不同回文子串数 = `tot - 1`；第 i 个位置结尾的最长回文 = `len[last]`。
- `cnt[x]` 是"该回文以右端点出现的次数"；沿 `fail` 树从深到浅累加后 = 该回文完整出现次数（每个回文是其后缀回文的"出现"来源）。
- `len[fail[x]] < len[x]`，fail 树上跳就是后缀回文链。

变体：
- 序列自动机化（PAM 支持左右双端插入）：维护双端 last，赛场少用。
- 字符集扩大改 `ch` 第二维；大字符集用 `unordered_map` 存转移。
- 求每个本质不同回文第一次出现位置：新建结点时记录 i。

## 11. 广义后缀自动机

适用：多串后缀问题：不同串的公共子串、多串本质不同子串并集计数、多串匹配统计。在线逐串插入版（不需 trie）。

复杂度：$O(\sum |s| \cdot \Sigma)$（数组转移）。

约定：多串逐个插入，每串从根 1 开始；数组按**总长**开。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int tot, len[MAXN], fail[MAXN], ch[MAXN][26];

void init()
{
    tot = 1;
    len[1] = 0;
    fail[1] = 0;
}

int extend(int p, int c)
{
    if (ch[p][c] && len[ch[p][c]] == len[p] + 1) return ch[p][c];
    if (ch[p][c])
    {
        int q = ch[p][c];
        int nq = ++tot;
        len[nq] = len[p] + 1;
        fail[nq] = fail[q];
        memcpy(ch[nq], ch[q], sizeof(ch[q]));
        fail[q] = nq;
        while (p && ch[p][c] == q)
        {
            ch[p][c] = nq;
            p = fail[p];
        }
        return nq;
    }
    int np = ++tot;
    len[np] = len[p] + 1;
    while (p && !ch[p][c])
    {
        ch[p][c] = np;
        p = fail[p];
    }
    if (!p)
    {
        fail[np] = 1;
        return np;
    }
    int q = ch[p][c];
    if (len[q] == len[p] + 1)
    {
        fail[np] = q;
        return np;
    }
    int nq = ++tot;
    len[nq] = len[p] + 1;
    fail[nq] = fail[q];
    memcpy(ch[nq], ch[q], sizeof(ch[q]));
    fail[q] = fail[np] = nq;
    while (p && ch[p][c] == q)
    {
        ch[p][c] = nq;
        p = fail[p];
    }
    return np;
}
```

使用说明：
- 主流程：`init();` 后对每个串 `int p = 1; for (每个字符 c) p = extend(p, c);`。
- 单串版退化行为与普通 SAM（05 第 8 节）一致；本质不同子串数 = $\sum_i (len[i] - len[fail[i]])$。
- 多串标记 endpos：在**每串末尾**给对应状态打标记；统计时沿 fail 树自底向上累加，注意 clone 出的 `nq` **不继承标记**。
- 大字符集把 `ch` 换 `map`；总长 1e5 量级 26 数组约 26 MB，按内存限制调 MAXN。

变体：
- 离线 trie 版：先建 trie 再 BFS 插入，复杂度更优但代码长；在线版多数场景够用。
- 多串最长公共子串：在自动机上逐串匹配取 min，或 fail 树上 LCA。
