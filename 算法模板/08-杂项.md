# 08 · 杂项
## 1. SG 函数（公平组合博弈）

适用：多堆 / 多局组合博弈，判断先手胜负（Nim 类、图上走棋子等）。

复杂度：$O(n \times \text{移动数})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
int sg[MAXN];
bool vis[MAXN];
int f[MAXN];
int fn;

int get_sg(int x)
{
    if (sg[x] != -1) return sg[x];
    memset(vis, 0, sizeof(vis));
    for (int i = 1; i <= fn; i++) if (x >= f[i]) vis[get_sg(x - f[i])] = 1;
    for (int i = 0;; i++) if (!vis[i]) return sg[x] = i;
}

int xor_sum(int *a, int n)
{
    int res = 0;
    for (int i = 1; i <= n; i++) res ^= get_sg(a[i]);
    return res;
}
```

使用说明：
- `f[1..fn]` 为一次可取的步数集合，先 `memset(sg, -1, sizeof(sg))`。
- 单局 SG 值异或和 > 0 则先手必胜，= 0 必败。
- 求必胜策略（取走哪堆多少个）：枚举每堆取走后异或和为 0。

变体：
- 反 Nim / 有向图游戏：SG 通用。
- 阶梯博弈（Staircase Nim）：奇偶位异或。

## 2. 三分求极值

适用：单峰 / 单谷函数（凸函数）在区间上求极值（如最优角度、最优比例）。

复杂度：$O(\text{迭代次数})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

double f(double x)
{
    return -(x - 3) * (x - 3) + 5;
}

double ternary_max(double l, double r)
{
    for (int i = 0; i < 200; i++)
    {
        double m1 = l + (r - l) / 3;
        double m2 = r - (r - l) / 3;
        if (f(m1) < f(m2)) l = m1;
        else r = m2;
    }
    return f((l + r) / 2);
}
```

使用说明：
- 求最大值用上述写法；求最小值把 `f(m1) < f(m2)` 改为 `f(m1) > f(m2)`。
- 迭代 100~200 次即可达双精度收敛；也可用 `while (r - l > 1e-12)`。

变体：
- 整数域三分：`m1 = l + (r-l)/3` 取整，注意收敛条件 `l < r - 2`。
- 函数非严格单峰时结果不可靠，需先验证凸性。

## 3. bitset 优化

适用：0/1 背包可达和、传递闭包、子集关系判断等，常数级加速（÷64）。

复杂度：$O(n^2/64)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

bitset<100005> bs;

void subset_sum(int *a, int n, int maxsum)
{
    bs.reset();
    bs[0] = 1;
    for (int i = 1; i <= n; i++) bs |= bs << a[i];
}

bool reachable(int s)
{
    return bs.test(s);
}
```

使用说明：
- 经典 0/1 背包：选择若干 a[i] 能凑出的所有和，`bs[s]=1` 表示 s 可达。
- 多重背包（数量有限）：按二进制分组后仍用 bitset。
- 传递闭包 / 子集包含：`bs[i] |= bs[j]` 需要多行（按需扩展为 `bitset` 数组）。

变体：
- 求最小凑出数：bitset 无法回溯，改用 int 数组 DP。
- 大 n（>1e6）可用 `vector<bool>` / 手写 64 位块。

## 4. 德州扑克：五张牌判型 + 两副牌比大小（结构体版）

> 本模板按需求保留详细注释（与库内"纯净代码无注释"惯例不同），方便理解牌型判定逻辑；比赛提交时如嫌长可自行删注释。

适用：梭哈 / 德州扑克类比牌问题 —— 给定一副 5 张牌判出牌型，或两副 5 张牌比较大小。

复杂度：判型 $O(1)$，比较 $O(1)$。

约定：
- 五张牌用结构体 `Hand` 存：`r[0..4]` 点数（2..14，14=A），`c[0..4]` 花色（0..3，仅用于判同花），`lv` 牌型等级（9 最高 ~ 1 最低），`key[0..4]` 比大小用的关键点数（降序、多余位补 0）。
- 给五张牌赋初始值：`set_card(h, i, r, c)` 逐张赋值，或 `init_hand(h, r0,c0, r1,c1, ..., r4,c4)` 一次赋 5 张。
- 判型：`eval(h)` 填好 `h.lv` 与 `h.key[]`（比大小前先对每副牌各调一次）。
- 比大小：`cmp(a, b)` 返回 1（a 赢）/ -1（a 输）/ 0（打平），先比牌型 `lv`，相同再逐位比 `key[]`。

牌型等级表（`lv`）：
| lv | 牌型 | 示例 | 比较规则 |
|---|---|---|---|
| 9 | 同花顺（含皇家同花顺） | A♠K♠Q♠J♠T♠ | 比最大点数 |
| 8 | 四条 | 8♠8♥8♦8♣K | 比四条点数，再比单张 |
| 7 | 葫芦 | K♠K♥K♦2♠2♥ | 比三条点数，再比对子 |
| 6 | 同花 | A♠K♠9♠7♠3♠ | 5 张点数依次比 |
| 5 | 顺子 | 9♠8♥7♦6♣5♠ | 比最大点数（A2345 记 5） |
| 4 | 三条 | T♠T♥T♦K♠Q♥ | 比三条点数，再比两张单牌 |
| 3 | 两对 | Q♠Q♥9♠9♥A♦ | 大对、小对、单牌依次比 |
| 2 | 一对 | 7♠7♥A♠K♥Q♦ | 比对子，再比三张单牌 |
| 1 | 高牌 | A♠K♥9♦7♣3♠ | 5 张点数依次比 |

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int RANK = 15;   // 点数取值范围 [2,14]，数组开 15

// 五张牌结构体：r[] 点数(2..14)，c[] 花色(0..3)，lv/key[] 为判型结果
struct Hand
{
    int r[5];    // 5 张牌点数（2..14，14=A）
    int c[5];    // 5 张牌花色（0..3，仅用于判同花）
    int lv;      // 牌型等级（9 最高 ~ 1 最低，0 表示未判型/空）
    int key[5];  // 比大小用关键点数（降序，多余位补 0）
};

// 给第 i 张牌赋初始值（i = 0..4）
void set_card(Hand &h, int i, int r, int c)
{
    h.r[i] = r;
    h.c[i] = c;
}

// 给五张牌赋初始值：依次传 5 张牌的点数与花色（共 10 个参数）
void init_hand(Hand &h, int r0, int c0, int r1, int c1, int r2, int c2, int r3, int c3, int r4, int c4)
{
    h.r[0] = r0; h.c[0] = c0;
    h.r[1] = r1; h.c[1] = c1;
    h.r[2] = r2; h.c[2] = c2;
    h.r[3] = r3; h.c[3] = c3;
    h.r[4] = r4; h.c[4] = c4;
}

// 判定 h 的 5 张牌牌型：结果写入 h.lv（牌型等级）与 h.key[0..4]（比较用关键点数）
void eval(Hand &h)
{
    // 1) 统计各点数出现次数、各花色张数
    int cnt[RANK] = {0}, suit[4] = {0};
    for (int i = 0; i < 5; i++)
    {
        cnt[h.r[i]]++;
        suit[h.c[i]]++;
    }

    // 2) 把 5 张牌按「出现次数降序、点数降序」排成 key[0..4]。
    //    例：四条8888K → [8,8,8,8,K]；葫芦KKK22 → [K,K,K,2,2]；两对QQ99A → [Q,Q,9,9,A]
    //    好处：牌型只看 key 前缀相等关系即可判定，且 key 本身天然就是各牌型的关键点数顺序，
    //          后面直接把它抄进 h.key[] 即可用于比大小。
    int key[5], k = 0;
    for (int c = 5; c >= 1; c--)          // 出现次数从多到少
    {
        for (int r = 14; r >= 2; r--)     // 同次数内点数从大到小
        {
            if (cnt[r] == c)
            {
                for (int t = 0; t < c; t++) key[k++] = r;
            }
        }
    }

    // 3) 判顺子：5 个点数连续。特判 A2345（A 视作 1，为最小顺子）
    bool isStraight = false;
    int straightHigh = 0;                 // 顺子的最大点数（A2345 记 5）
    int mn = 15, mx = 0, distinct = 0;
    for (int r = 2; r <= 14; r++) if (cnt[r]) distinct++;
    if (distinct == 5)                    // 只有 5 个点数互不相同才可能成顺子
    {
        for (int r = 2; r <= 14; r++) if (cnt[r]) { mn = r; break; }
        for (int r = 14; r >= 2; r--) if (cnt[r]) { mx = r; break; }
        if (mx - mn == 4)                 // 正常顺子：max-min == 4
        {
            isStraight = true;
            straightHigh = mx;
        }
        else if (cnt[14] && cnt[2] && cnt[3] && cnt[4] && cnt[5])
        {
            isStraight = true;            // A2345 轮子：A 当 1 用
            straightHigh = 5;
        }
    }

    // 4) 判同花：5 张同花色
    bool isFlush = false;
    for (int s = 0; s < 4; s++) if (suit[s] == 5) isFlush = true;

    // 5) 从大到小依次判定牌型并填 h.key[]。
    //    注：同花/顺子要求 5 个点数互不相同，与对子/三条/葫芦/四条互斥，故分支顺序安全。
    if (isStraight && isFlush)
    {
        h.lv = 9;                         // 同花顺（10JQKA 同花即皇家同花顺，属最高同花顺）
        h.key[0] = straightHigh;
        h.key[1] = h.key[2] = h.key[3] = h.key[4] = 0;
    }
    else if (key[0] == key[3])
    {
        h.lv = 8;                         // 四条：key[0]=key[3] 四个相同，key[4] 为单张
        h.key[0] = key[0];
        h.key[1] = key[4];
        h.key[2] = h.key[3] = h.key[4] = 0;
    }
    else if (key[0] == key[2] && key[3] == key[4])
    {
        h.lv = 7;                         // 葫芦：key 按次数降序排，三条必在前，即 [三,三,三,对,对]
        h.key[0] = key[0];                // 三条点数（葫芦先比三条）
        h.key[1] = key[3];                // 对子点数
        h.key[2] = h.key[3] = h.key[4] = 0;
    }
    else if (isFlush)
    {
        h.lv = 6;                         // 同花：点数从大到小依次比（key 即降序）
        for (int i = 0; i < 5; i++) h.key[i] = key[i];
    }
    else if (isStraight)
    {
        h.lv = 5;                         // 顺子：只比最大点数
        h.key[0] = straightHigh;
        h.key[1] = h.key[2] = h.key[3] = h.key[4] = 0;
    }
    else if (key[0] == key[2])
    {
        h.lv = 4;                         // 三条：key[0]=key[2]，后两位为两张单牌
        h.key[0] = key[0];
        h.key[1] = key[3];
        h.key[2] = key[4];
        h.key[3] = h.key[4] = 0;
    }
    else if (key[0] == key[1] && key[2] == key[3])
    {
        h.lv = 3;                         // 两对：先比大对、再比小对、最后比单牌
        h.key[0] = key[0];
        h.key[1] = key[2];
        h.key[2] = key[4];
        h.key[3] = h.key[4] = 0;
    }
    else if (key[0] == key[1])
    {
        h.lv = 2;                         // 一对：先比对子，再依次比三张单牌
        h.key[0] = key[0];
        h.key[1] = key[2];
        h.key[2] = key[3];
        h.key[3] = key[4];
        h.key[4] = 0;
    }
    else
    {
        h.lv = 1;                         // 高牌：5 张点数降序
        for (int i = 0; i < 5; i++) h.key[i] = key[i];
    }
}

// 两副牌比大小：a 赢 b 返回 1，a 输 b 返回 -1，打平返回 0。
// 先比牌型等级 lv，相同再从左到右逐位比关键点数 key[]（降序）
int cmp(const Hand &a, const Hand &b)
{
    if (a.lv != b.lv) return a.lv > b.lv ? 1 : -1;
    for (int i = 0; i < 5; i++)
    {
        if (a.key[i] != b.key[i]) return a.key[i] > b.key[i] ? 1 : -1;
    }
    return 0;
}
```

使用说明：
- 判一副 5 张牌：`init_hand(h, ...)`（或逐张 `set_card`）赋好牌 → `eval(h)` → 读 `h.lv`（牌型）与 `h.key[]`（关键点数）。
- 两副牌比大小：各自 `eval` 后调 `cmp(a, b)`，返回 1（a 赢）/ -1（a 输）/ 0（打平）。
- 牌型转换：读入字符牌时映射 `2~9→2~9, T→10, J→11, Q→12, K→13, A→14`。
- 花色编号仅用于判同花，0~3 任意映射均可；注意牌面不存在重复（同点数同花色不会同时出现）。
- `cmp` 要求两副牌都已 `eval` 过。

变体：
- 多名玩家排序：把各玩家 Hand 存进数组，用 `cmp` 作为 sort 的比较函数。
- 需要从 7 张牌（2 底牌 + 5 公共牌）选最大 5 张牌型：枚举 C(7,5)=21 种组合，每种填 Hand → eval → 用 cmp 保留最大即可。
- 5 张牌内最大同花判定 / 最接近某牌的顺子：在 eval 里加特殊条件即可。

## 5. 高精度（压位大整数）

适用：超出 `long long` / `__int128` 的整数运算（大数加减乘、大数比较、大数除以小整数）；`n` 位十进制数用压位 $10^9$ 存储，常数极小。

复杂度：加减 $O(\text{位数})$，乘法 $O(n^2)$。

约定：压 9 位（`BASE = 1e9`），`d[1..len]` 低位在前；`sgn` 为符号。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int BASE = 1000000000;
const int BASE_DIG = 9;
const int MAXL = 2005;

char buf[MAXL * 10];

struct Big
{
    int d[MAXL];
    int len;
    int sgn;
};

void big_trim(Big &x)
{
    while (x.len > 1 && x.d[x.len] == 0) x.len--;
    if (x.len == 1 && x.d[1] == 0) x.sgn = 1;
}

Big big_from_str()
{
    Big x;
    memset(x.d, 0, sizeof(x.d));
    x.len = 0;
    x.sgn = 1;
    int i = 0;
    if (buf[0] == '-')
    {
        x.sgn = -1;
        i = 1;
    }
    int n = (int)strlen(buf);
    for (int j = n - 1; j >= i; j -= BASE_DIG)
    {
        int st = max(i, j - BASE_DIG + 1), v = 0;
        for (int k = st; k <= j; k++) v = v * 10 + (buf[k] - '0');
        x.d[++x.len] = v;
    }
    big_trim(x);
    return x;
}

void big_print(const Big &x)
{
    if (x.sgn < 0) putchar('-');
    printf("%d", x.d[x.len]);
    for (int i = x.len - 1; i >= 1; i--) printf("%09d", x.d[i]);
}

int big_cmp_abs(const Big &x, const Big &y)
{
    if (x.len != y.len) return x.len > y.len ? 1 : -1;
    for (int i = x.len; i >= 1; i--) if (x.d[i] != y.d[i]) return x.d[i] > y.d[i] ? 1 : -1;
    return 0;
}

Big big_add_abs(const Big &x, const Big &y)
{
    Big r;
    memset(r.d, 0, sizeof(r.d));
    r.sgn = 1;
    r.len = max(x.len, y.len) + 1;
    for (int i = 1; i <= r.len; i++)
    {
        r.d[i] += x.d[i] + y.d[i];
        if (r.d[i] >= BASE)
        {
            r.d[i] -= BASE;
            r.d[i + 1]++;
        }
    }
    big_trim(r);
    return r;
}

Big big_sub_abs(const Big &x, const Big &y)
{
    Big r;
    memset(r.d, 0, sizeof(r.d));
    r.sgn = 1;
    r.len = x.len;
    for (int i = 1; i <= r.len; i++)
    {
        r.d[i] += x.d[i] - y.d[i];
        if (r.d[i] < 0)
        {
            r.d[i] += BASE;
            r.d[i + 1]--;
        }
    }
    big_trim(r);
    return r;
}

Big big_add(const Big &x, const Big &y)
{
    if (x.sgn == y.sgn)
    {
        Big r = big_add_abs(x, y);
        r.sgn = x.sgn;
        return r;
    }
    int c = big_cmp_abs(x, y);
    if (c == 0)
    {
        Big r;
        memset(r.d, 0, sizeof(r.d));
        r.len = 1;
        r.sgn = 1;
        return r;
    }
    if (c > 0)
    {
        Big r = big_sub_abs(x, y);
        r.sgn = x.sgn;
        return r;
    }
    Big r = big_sub_abs(y, x);
    r.sgn = y.sgn;
    return r;
}

Big big_mul(const Big &x, const Big &y)
{
    Big r;
    memset(r.d, 0, sizeof(r.d));
    r.sgn = x.sgn * y.sgn;
    r.len = x.len + y.len;
    for (int i = 1; i <= x.len; i++)
    {
        ll carry = 0;
        for (int j = 1; j <= y.len || carry; j++)
        {
            ll cur = r.d[i + j - 1] + carry + (ll)x.d[i] * (j <= y.len ? y.d[j] : 0);
            r.d[i + j - 1] = (int)(cur % BASE);
            carry = cur / BASE;
        }
    }
    big_trim(r);
    return r;
}

Big big_div_small(const Big &x, ll v)
{
    Big r;
    memset(r.d, 0, sizeof(r.d));
    r.sgn = x.sgn * (v < 0 ? -1 : 1);
    if (v < 0) v = -v;
    r.len = x.len;
    ll rem = 0;
    for (int i = x.len; i >= 1; i--)
    {
        ll cur = rem * BASE + x.d[i];
        r.d[i] = (int)(cur / v);
        rem = cur % v;
    }
    big_trim(r);
    return r;
}

ll big_mod_small(const Big &x, ll v)
{
    if (v < 0) v = -v;
    ll rem = 0;
    for (int i = x.len; i >= 1; i--) rem = (rem * BASE + x.d[i]) % v;
    return x.sgn < 0 ? -rem : rem;
}
```

使用说明：
- 读入：把字符串读进全局 `buf[]`（支持前导负号），再 `Big a = big_from_str();` 转换；输出 `big_print(a)`（不换行）。
- 需要两个操作数时**先把各自的字符串分别读进 `buf` 再转换**，转换成 `Big` 以后 `buf` 可复用；`Big` 结构体可以同时存在多份，运算函数不会互相影响。
- 比较大小：同号用 `big_cmp_abs`，异号直接比符号。
- 减法内部不用负号结果，靠 `big_add` 判符号后再调 `big_sub_abs`，故减法只走 `big_add`。
- 除以大整数未提供（竞赛里极少需要），要的话用试商法或转 Python。

变体：
- 进制转换 / 大数开方：用二分 + `big_mul` 实现。
- 需要 `NTT` 加速超大数乘法（$10^5$ 位以上）：把大数看成多项式做卷积再进位。
- 时间紧时优先考虑 Python（`int` 原生大数）或 Java `BigInteger`，C++ 只在必须单文件提交时用。

## 6. 表达式求值（递归下降）

适用：解析并计算含 `+ - * / ( )` 与整数的中缀表达式，支持一元负号；也便于扩展位运算、幂、函数。

复杂度：$O(n)$。

约定：表达式存全局 `s[]`（下标从 0 开始），`p` 为当前读到的位置；除法为 C++ 整除（向零取整）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
char s[MAXN];
int p;

ll parse_expr();
ll parse_term();
ll parse_factor();

ll parse_factor()
{
    if (s[p] == '(')
    {
        p++;
        ll v = parse_expr();
        p++;
        return v;
    }
    if (s[p] == '-')
    {
        p++;
        return -parse_factor();
    }
    ll v = 0;
    while (s[p] >= '0' && s[p] <= '9') v = v * 10 + (s[p++] - '0');
    return v;
}

ll parse_term()
{
    ll v = parse_factor();
    while (s[p] == '*' || s[p] == '/')
    {
        char op = s[p++];
        ll w = parse_factor();
        if (op == '*') v *= w;
        else v /= w;
    }
    return v;
}

ll parse_expr()
{
    ll v = parse_term();
    while (s[p] == '+' || s[p] == '-')
    {
        char op = s[p++];
        ll w = parse_term();
        if (op == '+') v += w;
        else v -= w;
    }
    return v;
}
```

使用说明：
- 调用前把表达式读进 `s[]`（末尾留 `'\0'`），`p = 0`，然后 `ll ans = parse_expr();`。
- 优先级由函数层次体现：`expr`（加减）→ `term`（乘除）→ `factor`（括号 / 负号 / 数字）。
- 输入保证无空格；有空格时在读取处跳过空格（`while (s[p] == ' ') p++;`）。

变体：
- 加幂运算 `^`：插一层 `parse_power()`，右结合（`v = qpow(v, w)`）。
- 加取模：把所有运算改成模意义下（除法换乘逆元）。
- 加变量与函数（如 `max(a, b)`、`sin`）：在 `parse_factor` 里识别标识符后查表求值。
- 表达式带浮点 / 分数：把 `ll` 换成 `double` 或分数结构体。

## 7. 日期与时间计算

适用：日期差、星期几、闰年判定、日期枚举、把日期映射成整数序号。

复杂度：$O(1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MDAY[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};

bool is_leap(int y)
{
    return (y % 4 == 0 && y % 100 != 0) || y % 400 == 0;
}

int days_in_month(int y, int m)
{
    if (m == 2 && is_leap(y)) return 29;
    return MDAY[m];
}

// 把年月日映射为连续天数序号（把 3 月当作年首，避免闰日出现在末尾）
ll ymd_to_day(int y, int m, int d)
{
    if (m <= 2)
    {
        y--;
        m += 12;
    }
    return 365LL * y + y / 4 - y / 100 + y / 400 + (153LL * (m - 3) + 2) / 5 + d;
}

// 由序号反推日期（逆运算）
void day_to_ymd(ll n, int &y, int &m, int &d)
{
    ll lo = 1, hi = 4000000000LL;
    while (lo < hi)
    {
        ll mid = (lo + hi + 1) / 2;
        if (ymd_to_day((int)mid, 1, 1) <= n) lo = mid;
        else hi = mid - 1;
    }
    y = (int)lo;
    ll rest = n - ymd_to_day(y, 1, 1) + 1;
    m = 1;
    while (rest > days_in_month(y, m))
    {
        rest -= days_in_month(y, m);
        m++;
    }
    d = (int)rest;
}

// 星期几：0 = 星期日，1 = 星期一 …（以 1 年 1 月 1 日为参照，按格里高利历）
int weekday(int y, int m, int d)
{
    return (int)((ymd_to_day(y, m, d) + 5) % 7);
}
```

使用说明：
- `ymd_to_day` 与 `day_to_ymd` 使用的是"$m \le 2$ 时把年减一、月加 12"的调整法，闰日落在年尾，公式对格里高利历全区间成立。
- 日期差：两个日期各转成序号后相减；加 $k$ 天：序号加 $k$ 再反推。
- 星期几的偏移量 $+5$ 依赖起算点约定，**上机前用已知日期（如 2024-01-01 是星期一）自测一次**。
- `day_to_ymd` 的反推写法较绕，若只需"日期差 + 枚举若干天"，直接用 `ymd_to_day` 逐个加 1 更省心。

变体：
- 时间戳 / 秒转时分秒：$O(1)$ 取模即可，注意时区偏移。
- 枚举 $[y_1,m_1,d_1]$ 到 $[y_2,m_2,d_2]$ 的所有日期：转序号后循环，或按年月日三层循环（$O(\text{天数} \cdot 1)$）。
- Zeller 公式直接算星期：$w = \left(y + \lfloor y/4 \rfloor + \lfloor c/4 \rfloor - 2c + \lfloor 13(m+1)/5 \rfloor + d - 1\right) \bmod 7$，注意 1、2 月按上一年的 13、14 月处理。

## 8. 对拍与造数据（赛场工具）

适用：写完代码想验一遍、或者 WA 了找不到反例的时候。

> 本节是**工具**，不是提交代码，所以带中文注释。用法只有三步，不看原理。

### 怎么用（三步）

**第 1 步：建个文件夹，放齐文件**

```
temp/题目名/
    main.cpp     ← 你的代码（准备交的那份）
    brute.cpp    ← 暴力（慢但一定对）
    gen.cpp      ← 造数据，复制下面模板，只改标了「改这里」的几行
    对拍.bat     ← 复制 8a 的脚本（Windows 用）
    对拍.sh      ← 复制 8b 的脚本（Linux 用）
```

**第 2 步：开跑**

- Windows：**双击 `对拍.bat`**（脚本自己调 g++ 编译，不用管）
- Linux：`bash 对拍.sh`

它会一直造数据、比对答案，跑满 500 组没差异就自己停。

**第 3 步：看结果**

- 一路 `OK` → 没抓到反例，把生成器里的数据范围调大再压
- 出现 `[WA] case 7 mismatch, seed 7` → **反例已经存成 `wa-7.txt`**，拿它调试：

```
main < wa-7.txt        # Windows 下是 main.exe < wa-7.txt
brute < wa-7.txt       # 对照正确答案
```

改完代码重跑，循环往复。只想单独看一组数据：`gen 1`（Windows 下 `gen.exe 1`）。

**生成器模板**（只改「改这里」之间的内容，其余别动）：

```cpp
// ===== gen.cpp 数据生成器 =====
#include <bits/stdc++.h>
using namespace std;

mt19937_64 rng;                             // 随机数引擎，别动

long long rnd(long long l, long long r)     // 返回 [l, r] 内的随机整数
{
    return l + (long long)(rng() % (unsigned long long)(r - l + 1));
}

int main(int argc, char *argv[])
{
    rng.seed(atoll(argv[1]));               // 用组号当种子，保证反例可复现，别动

    // ↓↓↓↓ 改这里：照题目的输入格式输出 ↓↓↓↓
    int n = (int)rnd(1, 10);                // 数据规模范围
    printf("%d\n", n);
    for (int i = 1; i <= n; i++) printf("%lld ", rnd(-20, 20));   // 每个数的值域
    putchar('\n');
    // ↑↑↑↑ 改到这里 ↑↑↑↑

    return 0;
}
```

> 值域记得带上负数和边界（写 `rnd(-20, 20)` 而不是 `rnd(1, 20)`）：很多错只在"全是负数""全相等"的时候才暴露出来。

### 8a. 对拍脚本 · Windows（保存为 `temp\对拍-用途.bat`）

> **编码坑（实测踩过）**：cmd 按 ANSI 代码页解析批处理文件，如果 bat 存成 UTF-8 且带中文注释，`rem 中文……` 之后的行会被解析错乱（表现为下一行 `cd /d %~dp0` 被吞掉，报「不是内部或外部命令」）。所以**这个脚本保持纯 ASCII**，提示信息也用英文；一定要中文就用 `chcp 65001` + UTF-8 另存，但不如全英文省心。

三个程序（`main.cpp` 待测 / `brute.cpp` 暴力 / `gen.cpp` 造数据）和本脚本放同一目录，**双击即跑**，脚本自己负责编译。

```bat
@echo off
rem Diff test: put main.cpp / brute.cpp / gen.cpp in the same folder, then run this file.
cd /d %~dp0

g++ -std=c++17 -O2 -o main.exe main.cpp
g++ -std=c++17 -O2 -o brute.exe brute.cpp
g++ -std=c++17 -O2 -o gen.exe gen.cpp
if not exist main.exe goto buildfail
if not exist brute.exe goto buildfail
if not exist gen.exe goto buildfail

set cnt=0
:loop
set /a cnt+=1
gen.exe %cnt% > in.txt
main.exe < in.txt > out.txt
brute.exe < in.txt > ans.txt
fc out.txt ans.txt > nul
if errorlevel 1 goto found
if %cnt% geq 500 goto done
goto loop

:found
echo.
echo [WA] case %cnt% mismatch, seed %cnt%
copy in.txt wa-%cnt%.txt > nul
echo counter-example saved as wa-%cnt%.txt
echo --- input ---
type in.txt
echo --- got ---
type out.txt
echo --- expected ---
type ans.txt
pause
exit /b

:done
echo OK: %cnt% cases passed
pause
exit /b

:buildfail
echo build failed: check whether g++ is in PATH
pause
```

使用说明（只看这 4 条就够）：
- 反例**自动另存**成 `wa-<组号>.txt`，不用自己复制；重跑不会再覆盖。
- 只可能改一处：g++ 不在 PATH 时（比如用 Dev-C++ 自带的编译器），把开头三行换成 g++ 全路径，如 `D:\Dev-Cpp\MinGW64\bin\g++.exe`。
- Windows 测不了超时（没有可用的 timeout），要测时限用下面的 Linux 版。
- 文件保持纯 ASCII，别加中文注释（原因见上面那段编码坑）。

### 8b. 对拍脚本 · Linux（保存为 `temp/对拍-用途.sh`，用 `bash 对拍-用途.sh` 运行）

Linux 版多做了两件 Windows 版做不了的事：**超时判定（TLE）**和**异常退出判定（RE）**。

```bash
#!/bin/bash
# 用途：Linux / macOS 对拍。与 main.cpp / brute.cpp / gen.cpp 同目录，跑 bash 对拍-用途.sh

g++ -std=c++17 -O2 -o main main.cpp || exit 1
g++ -std=c++17 -O2 -o brute brute.cpp || exit 1
g++ -std=c++17 -O2 -o gen gen.cpp || exit 1

LIMIT=500      # 最多对拍组数
TL=2           # main 单组超时秒数（按题目时限留 2~3 倍余量）
cnt=0

while [ $cnt -lt $LIMIT ]; do
    cnt=$((cnt + 1))
    ./gen $cnt > in.txt

    timeout $TL ./main < in.txt > out.txt
    st=$?
    if [ $st -eq 124 ]; then
        echo "[TLE] 第 $cnt 组超过 ${TL}s，种子 $cnt，输入已存 in.txt"
        break
    fi
    if [ $st -ne 0 ]; then
        echo "[RE] 第 $cnt 组异常退出，退出码 $st（139=段错误 / 136=浮点异常 / 134=abort），种子 $cnt"
        break
    fi

    ./brute < in.txt > ans.txt
    if ! diff -q out.txt ans.txt > /dev/null; then
        cp in.txt "wa-$cnt.txt"
        echo "[WA] 第 $cnt 组答案不一致，种子 $cnt，反例已另存 wa-$cnt.txt"
        cat in.txt
        break
    fi
done

if [ $cnt -ge $LIMIT ]; then
    echo "对拍 $cnt 组，未发现差异"
fi
```

使用说明（看一眼就懂）：
- 跑法：`bash 对拍-用途.sh`（不用 chmod）。
- 反例自动另存成 `wa-<组号>.txt`。
- 它能顺便认出超时和崩溃，靠的是退出码：**124 = 超时、139 = 段错误、136 = 浮点异常（除零）、134 = abort（STL 越界）**，脚本会直接打印是哪种。
- **别在 Git Bash 下用它**：那里的 `timeout` 是 Windows 版（不认输入重定向）。非要用就去掉 `timeout $TL`，或者干脆用上面的 Windows 版。
- 想挂机一直跑到出反例为止：把 `while [ $cnt -lt $LIMIT ]` 改成 `while true`。

### 8c. 常见数据形态生成（随机树 / 链 / 菊花 / 图 / 排列）

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 100005;
mt19937_64 rng;

int par[MAXN];                  // 树：par[i] 是 i 的父亲（par[1] 不用管）
int eu[MAXN], ev[MAXN];         // 图：第 i 条边的两个端点
int perm[MAXN];                 // 排列
set<pair<int, int>> used_edge;  // 随机图去重用，防止生成重边

ll rnd(ll l, ll r)
{
    return l + (ll)(rng() % (unsigned long long)(r - l + 1));
}

void shuffle_perm(int n)        // 随机排列
{
    for (int i = 1; i <= n; i++) perm[i] = i;
    for (int i = n; i > 1; i--) swap(perm[i], perm[rnd(1, i)]);
}

void tree_random(int n)         // 随机树
{
    for (int i = 2; i <= n; i++) par[i] = (int)rnd(1, i - 1);
}

void tree_chain(int n)          // 链：卡递归深度、点分治退化
{
    for (int i = 2; i <= n; i++) par[i] = i - 1;
}

void tree_star(int n)           // 菊花：卡跟度数有关的写法
{
    for (int i = 2; i <= n; i++) par[i] = 1;
}

void tree_binary(int n)         // 完全二叉树：卡树剖 / 线段树
{
    for (int i = 2; i <= n; i++) par[i] = i / 2;
}

void graph_random(int n, int m) // 无重边、无自环的随机无向图
{
    used_edge.clear();
    int cnt = 0;
    while (cnt < m)
    {
        int u = (int)rnd(1, n), v = (int)rnd(1, n);
        if (u == v) continue;                           // 自环不要
        if (u > v) swap(u, v);                          // 小的放前面，方便判重边
        if (used_edge.count(make_pair(u, v))) continue; // 重边不要
        used_edge.insert(make_pair(u, v));
        eu[++cnt] = u;
        ev[cnt] = v;
    }
}
```

使用说明：
- 调一个生成函数，然后按题目格式打印。树（先输出 n，再输出 n-1 条边）：
  `printf("%d\n", n); for (int i = 2; i <= n; i++) printf("%d %d\n", par[i], i);`
- 图（先输出 n m，再输出 m 条边）：
  `printf("%d %d\n", n, m); for (int i = 1; i <= m; i++) printf("%d %d\n", eu[i], ev[i]);`
- 带边权就在每行末尾加一列 `rnd(1, 1000)`；要有向图就把 `if (u > v) swap(u, v);` 那行删掉。
- 排列题：`shuffle_perm(n)` 后 `for (int i = 1; i <= n; i++) printf("%d ", perm[i]);`
- 四种树各跑一遍基本能覆盖树上常见错：链卡深度、菊花卡度数、完全二叉树卡树剖、随机树兜底。

### 8d. 赛场编译与调试命令（Linux / Windows 对照）

```bash
# —— Linux（ICPC 赛场主流：g++ + bash）——
g++ -std=c++17 -O2 -o main main.cpp                    # 提交用的标准编译
g++ -std=c++17 -O2 -Wall -Wextra -o main main.cpp      # 开警告，抓未初始化变量、符号比较、少写 break
g++ -std=c++17 -g -fsanitize=address,undefined -o main main.cpp
                                                       # 抓数组越界 / 悬垂指针 / 有符号溢出 / 除零
                                                       # 慢 2~10 倍，只跑小数据
g++ -std=c++17 -g -D_GLIBCXX_DEBUG -o main main.cpp    # 抓 STL 越界（vector 下标、迭代器失效）
time ./main < in.txt > out.txt                         # 测单组用时
ulimit -s unlimited                                    # 解开栈上限（当前 shell 生效）
```

```bat
:: —— Windows（Dev-C++ / CodeBlocks 自带 MinGW）——
g++ -std=c++17 -O2 -o main.exe main.cpp
g++ -std=c++17 -O2 -Wall -Wextra -o main.exe main.cpp
g++ -std=c++17 -O2 -Wl,--stack=268435456 -o main.exe main.cpp   :: 栈扩到 256MB
:: 计时：PowerShell 里执行 Measure-Command { .\main.exe < in.txt > out.txt }
:: 注意：MinGW 没有 AddressSanitizer，-fsanitize 只能在 Linux 上用
```

使用说明：
- **调试版只是为了找 bug，最后必须用 `-O2` 重新编一遍再交**：`-fsanitize` 会拖慢速度、`_GLIBCXX_DEBUG` 会改变容器行为，二者都不要同时开。
- 只在本地排查用 `-Wall -Wextra`：赛场上警告刷屏容易盖掉真正的错误信息，但本地开发时非常值（尤其"变量未初始化""有符号 / 无符号比较"）。
- 超时排查顺序：先 `time` 看单组 → 再看多组是否该预处理好 → 最后才考虑常数优化（快读快写、`-O2` 已最大化）。
- Windows 上 `-Wl,--stack=` 只对 MinGW 有效；Linux 上用 `ulimit -s`，或者干脆按下一节手动扩栈。
- 赛场常见环境差异：Linux 的 `int` 是 4 字节、`long` 在 64 位 Linux 上是 8 字节而 Windows 上是 4 字节 —— **跨平台时一律用 `long long`**，别用 `long`。

### 8e. 手动扩栈

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    int size = 256 << 20;
    char *p = (char *)malloc(size) + size;
#if defined(__x86_64__) || defined(_M_X64)
    __asm__("movq %0, %%rsp\n" :: "r"(p));
#else
    __asm__("movl %0, %%esp\n" :: "r"(p));
#endif
    return 0;
}
```

使用说明：
- 只在 Linux + GCC 有效；Windows / MinGW 下改用编译选项 `-Wl,--stack=268435456`。
- Linux 默认栈通常 8MB（`ulimit -s` 查看），深递归 + 局部大数组很容易爆。
- 更保险的做法是把递归改成迭代，或把大数组开成全局（全局区不占栈）。
- 深递归（线段树 DFS、Tarjan、树形 DP）爆栈时优先检查是不是把大数组开在了函数里。

### 8f. 交互题输入输出

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

int ask(int l, int r)
{
    printf("? %d %d\n", l, r);
    fflush(stdout);
    int x;
    scanf("%d", &x);
    return x;
}

void answer(int v)
{
    printf("! %d\n", v);
    fflush(stdout);
}
```

使用说明：
- 每次输出后**必须** `fflush(stdout)`（用 `cout` 时写 `endl` 也有同样效果，但用 `'\n'` 就必须配 `flush`）。
- 交互次数通常有上限，二分 / 倍增类交互要把询问次数控在限制内。
- 交互题不能用快读 `getchar()` 混用（`scanf` 与 `getchar` 缓冲区会打架），全程统一用 `scanf/printf` 或统一用 `cin/cout`。
