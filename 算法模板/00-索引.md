## 合并注意（重要）

各模板为独立编译设计，**全局变量按需可能重名**，把多个模板合并进同一份提交时需检查以下高频重名并改名：

| 重名变量 | 出现在 |
|---|---|
| `nxt` | KMP（失配表） vs 图论残留前向星（Dinic/MCMF/Tarjan桥） |
| `head / to / ecnt` | 图论残留前向星（Dinic/MCMF/Tarjan桥） |
| `g` | 图论所有 vector 邻接表（Dijkstra/SPFA/LCA/树剖/SCC/割点/拓扑/匈牙利等） |
| `dis` | SPFA/Dijkstra vs Dinic/MCMF |
| `cnt` | 后缀数组计数 vs 莫队计数 vs SPFA 判负环 |
| `tmp` | 后缀数组辅助 vs 矩阵快速幂临时 |
| `match` | 匈牙利 vs KMP 匹配位置 |
| `vis` | 多模板（Dijkstra/匈牙利/SG） |
| `dp` | 各 DP 模板同名全局数组（数位 / 斜率 / 状压 / LCS / 背包 / 区间 / 树形） |
| `dfs` | 记忆化搜索 / 数位DP / 树上背包 / 换根，树形模板内部还共用 `e` / `sz` |
| `add_num` / `get_mid` | 09 对顶堆函数名（与其他自写函数冲突时改名） |
| `custom_hash` / `pair_hash` | 09 附录防卡哈希结构体名 |

- 09 片段里的 a / n / x / s 都是**示例变量**（局部），复制进题解时换成自己的变量即可，一般不会造成全局重名。

建议合并策略：**按题只复制需要的 1~3 个模板**，复制后把冲突的全局数组整体改名（如 `nxt`→`nxt_sa`），或把不冲突的部分（快读、qpow、exgcd）作为公共头。
