# 07 · 动态规划

## 1. 记忆化搜索（状态递归 + 判重）

适用：递推顺序不直观、转移要"回头"访问更大状态的 DP（区间分割、树上、博弈取数等），用递归函数直接表达状态转移，比手动定拓扑序不易错。

复杂度：$O(\text{状态数} \times \text{每状态转移数})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
ll a[MAXN], f[MAXN][MAXN];
bool vis[MAXN][MAXN];

ll dfs(int i, int j)
{
    if (vis[i][j]) return f[i][j];
    vis[i][j] = true;
    if (i == j) return f[i][j] = a[i];
    f[i][j] = max(a[i] - dfs(i + 1, j), a[j] - dfs(i, j - 1));
    return f[i][j];
}
```

使用说明：
- 示例为"两端取数博弈"：两人轮流从 a[1..n] 两端取，都取最优，`dfs(1, n)` 返回 先手得分 $-$ 后手得分；设总和 pre，则先手得分 = $(pre + dfs(1,n))/2$。
- 判重用独立 `vis` 数组而不是 f 初值：结果可能本身是 0 或负数，用初值判重会误判。
- 记忆表开全局大数组；转移必须无环（去往更小/更大状态都行，只要不绕圈）。

变体：
- 状态高维：数组维数对应状态维数；值域大、状态稀疏用 `unordered_map` 哈希（比赛注意自定义 hash 防被卡）。
- 期望 / 概率 DP 也能记忆化，但成环的期望（如博弈平局）要先解方程或转图上 DP。
- 递推方向明确时优先写循环省栈；深链状态（如树形递归）注意递归深度。

## 2. LIS：最长上升子序列（$O(n\log n)$）

适用：单数组求最长严格上升子序列长度；改一个函数可求最长不下降子序列。

复杂度：$O(n\log n)$，空间 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
int a[MAXN], d[MAXN];
int len;

int lis(int n)
{
    len = 0;
    for (int i = 1; i <= n; i++)
    {
        int p = lower_bound(d + 1, d + len + 1, a[i]) - d;
        d[p] = a[i];
        if (p > len) len = p;
    }
    return len;
}
```

使用说明：
- d[p] 维护"长度为 p 的上升子序列的最小末尾值"；对每个 a[i] 找第一个 $\ge$ 它的位置替换。
- 最长不下降子序列：把 `lower_bound` 换成 `upper_bound`（允许相等接上）。
- 只返回长度，d 数组内容不是原 LIS。

变体：
- 输出一条 LIS：过程中记录 pos[i]（a[i] 落到的位置）与链上 pre[i]，结束后从末尾往前倒推；$n \le 5000$ 直接用 $O(n^2)$ dp + pre 数组回溯更省事。
- 求 LIS 方案数 / 长度计数：树状数组 / 线段树按值域维护"以该值为结尾的最大长度与个数"。
- 值域大（a[i] 到 1e9）不影响本模板，d 只存值。

## 3. LCS：最长公共子序列（$O(nm)$）

适用：两序列 / 字符串求最长公共子序列长度。

复杂度：$O(nm)$，空间 $O(nm)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
char s[MAXN], t[MAXN];
int dp[MAXN][MAXN];

int lcs(int n, int m)
{
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= m; j++)
        {
            if (s[i] == t[j]) dp[i][j] = dp[i - 1][j - 1] + 1;
            else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[n][m];
}
```

使用说明：
- s / t 从下标 1 存（如 `scanf("%s", s + 1)`），n、m 为实际长度。
- 全矩阵适合 $n, m \le 5000$ 以内（MAXN 按需放大）；超内存时只留两行滚动：算 dp[i][j] 前先用变量存好 dp[i-1][j-1]（斜对角会被覆盖）。

变体：
- LCIS（最长公共上升子序列）：dp[j] 记以 t[j] 结尾的 LCIS，同时维护"以 s[i] 结尾能接上的最大值"，$O(nm)$。
- 编辑距离：改转移加删 / 改三种代价，边界 $dp[i][0] = i$、$dp[0][j] = j$。
- 输出方案：算完从 dp[n][m] 按来源回退，相等字符斜向收集。

## 4. 背包 DP

适用：容量 V + 物品集合（体积 vol、价值 val）的最优化选择，按每组约束分为 0-1 / 完全 / 多重 / 分组。

复杂度：0-1 / 完全 $O(nV)$；多重二进制拆分 $O(nV\log cnt)$；分组 $O(\sum \text{组数} \times V \times \text{组内个数})$。

### 4a. 0-1 背包

每件最多取一次；容量倒序枚举防止同一件被重复取。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXV = 100005;
int vol[MAXN], val[MAXN];
ll dp[MAXV];

void zero_one(int n, int V)
{
    for (int i = 1; i <= n; i++)
    {
        for (int j = V; j >= vol[i]; j--)
        {
            dp[j] = max(dp[j], dp[j - vol[i]] + val[i]);
        }
    }
}
```

使用说明：
- 调用前 `memset(dp, 0, sizeof(dp))`：表示"容量不超过 V"的最大价值，答案 dp[V]。
- "恰好装满 V"：dp[0] = 0，dp[1..V] 赋 -INF，最后看 dp[V] 是否仍为 -INF。

变体：
- 求最小代价（费用型）：max 改 min，初值相反。
- 方案数：dp 存方案数、转移用加；再开 rec[i][j] 记选否可回溯方案。

### 4b. 完全背包

每件可取无限次；容量正序枚举即为"可重复取"。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXV = 100005;
int vol[MAXN], val[MAXN];
ll dp[MAXV];

void complete(int n, int V)
{
    for (int i = 1; i <= n; i++)
    {
        for (int j = vol[i]; j <= V; j++)
        {
            dp[j] = max(dp[j], dp[j - vol[i]] + val[i]);
        }
    }
}
```

使用说明：
- 与 0-1 唯一区别是 j 正序；"恰好装满"初始化同 4a。

变体：
- 物品体积为 0 时完全背包会死循环式重复（正序 0 体积永远能加）：特判 0 体积物品。
- 零钱 / 无限资源类问题同框架，容量换成目标值。

### 4c. 多重背包（二进制拆分）

每种物品限 cnt 个；把 cnt 个拆成 1、2、4… 的若干组，使任意 0..cnt 都能由子集凑出，再按 0-1 处理。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXV = 100005;
int vol[MAXN], val[MAXN], num[MAXN];
int cv[MAXN], cw[MAXN];
int m;
ll dp[MAXV];

void add_item(int x, int y, int cnt)
{
    for (int k = 1; cnt > 0; k <<= 1)
    {
        int t = min(k, cnt);
        cv[++m] = x * t;
        cw[m] = y * t;
        cnt -= t;
    }
}

void multi_pack(int n, int V)
{
    m = 0;
    for (int i = 1; i <= n; i++) add_item(vol[i], val[i], num[i]);
    for (int i = 1; i <= m; i++)
    {
        for (int j = V; j >= cv[i]; j--)
        {
            dp[j] = max(dp[j], dp[j - cv[i]] + cw[i]);
        }
    }
}
```

使用说明：
- num[i] 为第 i 种物品个数；拆完直接在拆分数组 cv / cw 上跑 0-1。
- 拆分正确性示例：cnt = 5 拆成 1、2、2（不是 1、2、4，会超量）。

变体：
- cnt 极大、V 较小（$\le 10^4$）时用单调队列优化可到 $O(nV)$。
- 每组限取奇 / 偶数个等改约束：先转成对应 0-1 模型。

### 4d. 分组背包

若干组，每组内至多选一个物品；容量倒序 + 组内枚举物品。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
const int MAXV = 100005;
int gn[MAXN];
int gv[MAXN][MAXN], gw[MAXN][MAXN];
ll dp[MAXV];

void group_pack(int G, int V)
{
    for (int g = 1; g <= G; g++)
    {
        for (int j = V; j >= 0; j--)
        {
            for (int k = 1; k <= gn[g]; k++)
            {
                if (j >= gv[g][k]) dp[j] = max(dp[j], dp[j - gv[g][k]] + gw[g][k]);
            }
        }
    }
}
```

使用说明：
- gn[g]：第 g 组物品数；gv[g][1..gn[g]] 体积、gw[g][1..gn[g]] 价值。
- 倒序保证 dp[j] 只由"上一组结果"转移，同组物品互斥。
- "每组恰好选一个"：把上一组结果存 tmp，只从 tmp 加本组物品转移（dp[0] = 0，其余 -INF）。
- "每组至少选一个"：新开 ndp 数组，允许同组内连续取（ndp[j] = max(ndp[j-vol]+val, 上一组 dp[j-vol]+val)）。

变体：
- 二维费用：dp 加一维容量。
- 依赖背包：物品依赖关系成树时转树上背包，见模板 6a。
- 输出方案：另开 rec[g][j] 记录第 g 组在容量 j 时选了组内第几个。

## 5. 区间 DP

适用：状态是连续区间 [i, j]，转移按断点拆分或两端收缩合并。

复杂度：朴素 $O(n^3)$；满足四边形不等式可用决策点优化到 $O(n^2)$。

### 5a. 石子合并（min 类，含四边形不等式优化）

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 2005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
int n;
ll a[MAXN], sum[MAXN];
ll dp[MAXN][MAXN];
int mk[MAXN][MAXN];

ll linear_naive(int n)
{
    for (int i = 1; i <= n; i++) dp[i][i] = 0;
    for (int len = 2; len <= n; len++)
    {
        for (int i = 1; i + len - 1 <= n; i++)
        {
            int j = i + len - 1;
            dp[i][j] = INF;
            for (int k = i; k < j; k++) dp[i][j] = min(dp[i][j], dp[i][k] + dp[k + 1][j]);
            dp[i][j] += sum[j] - sum[i - 1];
        }
    }
    return dp[1][n];
}

ll interval_min(int total)
{
    for (int i = 1; i <= total; i++)
    {
        dp[i][i] = 0;
        mk[i][i] = i;
    }
    for (int len = 2; len <= total; len++)
    {
        for (int i = 1; i + len - 1 <= total; i++)
        {
            int j = i + len - 1;
            dp[i][j] = INF;
            for (int k = mk[i][j - 1]; k <= mk[i + 1][j]; k++)
            {
                if (dp[i][k] + dp[k + 1][j] < dp[i][j])
                {
                    dp[i][j] = dp[i][k] + dp[k + 1][j];
                    mk[i][j] = k;
                }
            }
            dp[i][j] += sum[j] - sum[i - 1];
        }
    }
    return dp[1][total];
}

ll ring_min(int n)
{
    for (int i = 1; i <= n; i++) a[i + n] = a[i];
    for (int i = 1; i <= 2 * n; i++) sum[i] = sum[i - 1] + a[i];
    interval_min(2 * n);
    ll ans = INF;
    for (int i = 1; i <= n; i++) ans = min(ans, dp[i][i + n - 1]);
    return ans;
}
```

使用说明：
- 线性：读入 a[1..n] 后先算 `sum[i] = sum[i-1] + a[i]`；石子非负、代价为前缀和型（满足四边形不等式且单调）时用 interval_min(n)，$O(n^2)$；否则（石子可为负）用 linear_naive(n)，$O(n^3)$。
- 环形（破环成链）：直接 ring_min(n)，函数内部自动复制 a[n+1..2n]；MAXN 需 $\ge 2n$（本模板 $n \le 1000$）。
- dp[i][j] 为把区间 [i, j] 合并成一堆的最小代价；mk[i][j] 记最优断点。

变体：
- 环形朴素版：链复制后跑 linear_naive(2n)，扫长度为 n 的最小窗口。
- 取 max 类（括号 / 回文删除）不满足四边形不等式，见 5b。
- 矩阵链乘同框架：代价 w(i, j) 换成 p[i-1]p[k]p[j]。

### 5b. 括号匹配（max 类区间 DP）

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1005;
char s[MAXN];
int dp[MAXN][MAXN];

int brackets(int n)
{
    for (int len = 2; len <= n; len++)
    {
        for (int i = 1; i + len - 1 <= n; i++)
        {
            int j = i + len - 1;
            dp[i][j] = max(dp[i + 1][j], dp[i][j - 1]);
            if ((s[i] == '(' && s[j] == ')') || (s[i] == '[' && s[j] == ']'))
            {
                dp[i][j] = max(dp[i][j], dp[i + 1][j - 1] + 2);
            }
            for (int k = i; k < j; k++) dp[i][j] = max(dp[i][j], dp[i][k] + dp[k + 1][j]);
        }
    }
    return dp[1][n];
}
```

使用说明：
- 求 s[1..n] 中能组成"合法括号子序列"的最多字符数（如 POJ2955），返回值即匹配字符数。
- 转移三来源：丢左端 / 丢右端 / 两端恰好配对（外配 + 内部），再枚举断点拼接（删单字符已被 k 分割覆盖）。
- 只判"整串能否完全匹配"用栈即可，不用 DP。

变体：
- 删最少字符使成为合法括号序列 = $n - \text{brackets}(n)$。
- 回文串删除（删最少使成回文 / 最长回文子序列）同 max 框架。

## 6. 树形 DP

### 6a. 树上依赖背包（选课型）

适用：树 / 森林选点，选了子必须先选父（依赖关系），容量是选点数，求最大权值和，如 P2014 选课。

复杂度：$O(nm^2)$；合并时用子树大小限制 j、k 上界可降为 $O(nm)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 305;
const ll NEG = -0x3f3f3f3f3f3f3f3fLL;
int n, m;
int w[MAXN];
vector<int> e[MAXN];
ll dp[MAXN][MAXN];

void dfs(int u, int cap)
{
    dp[u][1] = w[u];
    for (auto &tv : e[u])
    {
        dfs(tv, cap);
        for (int j = cap; j >= 2; j--)
        {
            for (int k = 1; k < j; k++) dp[u][j] = max(dp[u][j], dp[u][j - k] + dp[tv][k]);
        }
    }
}

ll solve()
{
    int cap = m + 1;
    for (int u = 0; u <= n; u++)
    {
        dp[u][0] = 0;
        for (int j = 1; j <= cap; j++) dp[u][j] = NEG;
    }
    dfs(0, cap);
    return dp[0][cap];
}
```

使用说明：
- 建虚根 0（w[0] = 0）：i 的先修课是 p 就 `e[p].push_back(i)`，无先修连到 0。
- dp[u][j]：u 子树内"必含 u、共占 j 个名额"的合法闭集最大权；j = 0 恒为 0（空集）。
- 名额把虚根也算 1 个：答案 = dp[0][m+1]，即 m 门课。
- 依赖方向相反（要选父须先选够子，如技能树）把边反向再跑。
- n、m 到 1000+ 时先一次 dfs 求 sz[u]，合并循环 j、k 只枚举到子树容量，避免 $O(nm^2)$ 超时。

变体：
- 权可为负：答案取 $\max_{j \le m+1} dp[0][j]$。
- 只求"最大权连通块"（不限额）：树上 0-1 合并，j 上限 = 子树大小。

### 6b. 换根 DP（二次扫描）

适用：以每个点为根求全树性质（典型：所有点到每个点的距离和）；先以 1 为根自底向上算一遍，再自顶向下 $O(1)$ 转移给儿子。

复杂度：$O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
int n;
vector<int> e[MAXN];
int sz[MAXN];
ll dep[MAXN], f[MAXN];

void dfs_size(int u, int fa)
{
    sz[u] = 1;
    for (auto &tv : e[u])
    {
        if (tv == fa) continue;
        dep[tv] = dep[u] + 1;
        dfs_size(tv, u);
        sz[u] += sz[tv];
    }
}

void dfs_reroot(int u, int fa)
{
    for (auto &tv : e[u])
    {
        if (tv == fa) continue;
        f[tv] = f[u] + n - 2LL * sz[tv];
        dfs_reroot(tv, u);
    }
}

void build()
{
    dfs_size(1, 0);
    ll tot = 0;
    for (int i = 1; i <= n; i++) tot += dep[i];
    f[1] = tot;
    dfs_reroot(1, 0);
}
```

使用说明：
- f[u]：所有点到 u 的距离和；sz[u] 为"以 1 为根"时 u 的子树大小（第一次 dfs 求出）。
- 转移含义：根从 u 换到儿子 v，v 一侧 $sz[v]$ 个点距离各 $-1$，其余 $n - sz[v]$ 个点各 $+1$。
- 带边权 $w(u, v)$：$f[v] = f[u] + (n - 2\cdot sz[v])\cdot w$。
- 求距离和最小的根：算完扫 f 取最小值下标（如 P3478）。

变体：
- 到每个点的最远距离：换根 + 子树内 down 最大/次大值两遍 dfs。
- 换根维护"去掉子树"信息（乘法 / 除法）：模意义下注意 0 无逆元，用前缀后缀积。

## 7. 数位 DP

适用：统计区间 [L, R] 内满足某数位条件（不含某数字、不含连续某模式、数位和等）的数的个数。

复杂度：$O(\text{位数} \times \text{状态})$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

ll dp[20][10];
int digit[20];

ll dfs(int pos, int pre, bool lead, bool limit)
{
    if (pos == 0) return 1;
    if (!lead && !limit && dp[pos][pre] != -1) return dp[pos][pre];
    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int i = 0; i <= up; i++)
    {
        if (i == 4) continue;
        if (pre == 6 && i == 2) continue;
        res += dfs(pos - 1, i, lead && i == 0, limit && i == up);
    }
    if (!lead && !limit) dp[pos][pre] = res;
    return res;
}

ll solve(ll x)
{
    if (x < 0) return 0;
    int len = 0;
    while (x)
    {
        digit[++len] = x % 10;
        x /= 10;
    }
    memset(dp, -1, sizeof(dp));
    return dfs(len, 0, true, true);
}
```

使用说明：
- 示例条件为"不含 4 且不含连续 62"；`solve(R) - solve(L-1)` 为区间答案。
- `lead` 处理前导零，`limit` 处理数位上界，`pre` 传上一位数字（初始 0）。
- 改条件只需改循环内 if 判断与 dp 维度（如数位和限制加一维 sum）。

变体：
- 数位和整除 / 同余类：dp 加一维取模。
- 统计满足条件的数之和 / 乘积：dp 记录 {个数, 和} 结构（用两个数组）。

## 8. 斜率优化 DP（凸包维护）

适用：$dp[i] = \min_{j<i}(dp[j] + \text{cost}(j, i))$，cost 含 $sum[i]\cdot sum[j]$ 这类乘积项，可用斜率优化到 $O(n)$。

复杂度：$O(n)$（决策单调、横坐标单增时）。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 500005;
ll sum[MAXN], dp[MAXN];
int q[MAXN];

ll X(int i)
{
    return sum[i];
}

ll Y(int i)
{
    return dp[i] + sum[i] * sum[i];
}

ll up(int a, int b)
{
    return Y(a) - Y(b);
}

ll down(int a, int b)
{
    return X(a) - X(b);
}

ll slope_opt(int n, ll C)
{
    int head = 0, tail = 0;
    q[tail++] = 0;
    for (int i = 1; i <= n; i++)
    {
        while (head + 1 < tail && up(q[head + 1], q[head]) <= 2 * sum[i] * down(q[head + 1], q[head]))
        {
            head++;
        }
        int j = q[head];
        dp[i] = dp[j] + (sum[i] - sum[j]) * (sum[i] - sum[j]) + C;
        while (head + 1 < tail && up(q[tail - 1], q[tail - 2]) * down(i, q[tail - 1]) >= up(i, q[tail - 1]) * down(q[tail - 1], q[tail - 2]))
        {
            tail--;
        }
        q[tail++] = i;
    }
    return dp[n];
}
```

使用说明：
- 示例为经典式 $dp[i] = \min(dp[j] + (sum[i]-sum[j])^2) + C$（如 HDU3507）。
- X 单调增、斜率判断为下凸包。横坐标 / 斜率不单调时改用李超线段树或 CDQ 分治。
- 乘法比较可能溢出，必要时用 `__int128` 或交叉乘法化浮点。

变体：
- 四边形不等式优化：同类但用二分找决策点（适用横坐标不单调）。
- 决策单调性（分治优化）：`dp[i][j]` 二维时常用，$O(n\log n)$。

## 9. 状态压缩 DP

适用：$n \le 20$ 的集合类问题（TSP、子集划分、覆盖）。

复杂度：$O(n^2 \cdot 2^n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 20;
const int MAXS = 1 << 20;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
ll dp[MAXS][MAXN];
ll w[MAXN][MAXN];

ll hamilton(int n)
{
    memset(dp, 0x3f, sizeof(dp));
    dp[1][0] = 0;
    for (int s = 1; s < (1 << n); s++)
    {
        for (int i = 0; i < n; i++)
        {
            if (!(s & (1 << i)) || dp[s][i] == INF) continue;
            for (int j = 0; j < n; j++)
            {
                if (s & (1 << j)) continue;
                dp[s | (1 << j)][j] = min(dp[s | (1 << j)][j], dp[s][i] + w[i][j]);
            }
        }
    }
    return dp[(1 << n) - 1][n - 1];
}
```

使用说明：
- 示例为哈密顿回路（从 0 到 n-1 经过所有点一次的最短路），w 为边权矩阵。
- 状态 `s` 为已访问点集，`dp[s][i]` 为"已访问 s 且当前在 i"的最小代价。
- 起点终点、无向/有向按题意调整。

变体：
- 枚举子集 `for (int sub = s; sub; sub = (sub - 1) & s)`，用于集合划分 DP。
- 高维前缀和（SOS DP）：`for i: for s: if(s>>i&1) f[s] += f[s^(1<<i)]`。

## 10. 最大子段和（Kadane / 前缀和）

适用：单数组（可含负数）求连续非空子段和的最大值；含全为负数、环形可跨首尾、长度下限等变体。n 可达 1e6。

复杂度：线性 / 长度受限 / 环形版均 $O(n)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

#define ll long long

const int MAXN = 1000005;
const ll INF = 0x3f3f3f3f3f3f3f3fLL;
ll a[MAXN], pre[MAXN];
int lp, rp;

ll max_sub(int n)
{
    ll cur = 0, ans = a[1];
    for (int i = 1; i <= n; i++)
    {
        cur += a[i];
        if (cur > ans) ans = cur;
        if (cur < 0) cur = 0;
    }
    return ans;
}

ll max_sub_seg(int n)
{
    ll cur = 0, ans = a[1];
    int l = 1;
    lp = rp = 1;
    for (int i = 1; i <= n; i++)
    {
        if (cur < 0)
        {
            cur = 0;
            l = i;
        }
        cur += a[i];
        if (cur > ans)
        {
            ans = cur;
            lp = l;
            rp = i;
        }
    }
    return ans;
}

ll max_sub_ring(int n)
{
    ll total = 0, mn = INF, cur = 0;
    for (int i = 1; i <= n; i++) total += a[i];
    for (int i = 1; i <= n; i++)
    {
        cur += a[i];
        if (cur < mn) mn = cur;
        if (cur > 0) cur = 0;
    }
    if (total == mn) return max_sub(n);
    return max(max_sub(n), total - mn);
}

ll max_sub_ge(int n, int L)
{
    pre[0] = 0;
    for (int i = 1; i <= n; i++) pre[i] = pre[i - 1] + a[i];
    ll mn = 0, ans = -INF;
    for (int i = L; i <= n; i++)
    {
        if (pre[i - L] < mn) mn = pre[i - L];
        if (pre[i] - mn > ans) ans = pre[i] - mn;
    }
    return ans;
}
```

使用说明：
- a 存 1..n。`max_sub(n)` 不允许空段：cur 为当前累计段和，小于 0 就丢弃重开；全为负数时返回最大单元素。
- `max_sub_seg(n)` 额外把答案段端点写入全局 lp / rp（1-based，取"最早达到最大"的段）。
- `max_sub_ring(n)` 环形：答案 = max(线性最大, 总和 $-$ 最小子段和)；特判 $total = mn$（全非正，最小子段和就是整个数组），否则补集会变成空段、错误返回 0。
- `max_sub_ge(n, L)` 子段长度 $\ge L$：$pre[i] - $ 历史最小 $pre[j]$（$j \le i - L$）。因 j 下界随 i 单调右移、只增不减，一个变量维护即可，不需要单调队列。
- 允许取空段（答案可为 0）：`max_sub(n)` 后与 0 取 max，或把初值 ans 改 0。

变体：
- 长度恰好 L：$pre[i] - pre[i-L]$ 固定窗口扫一遍，$O(n)$。
- 长度在 [L, R]：j 有上下界，需单调队列维护窗口内最小 pre，$O(n)$。
- 二维最大子矩阵和：枚举行上 / 下界（两重循环），把该范围内每列求和压成一维数组再跑 max_sub，$O(n^2 m)$；$n, m \le 200$ 量级直接做，更大配合前缀和列优化。
- 字典序最小端点 / 计数等：在更新处改判定（如"更小左端点才替换"）。
- 树状数组 / 线段树维护区间最大子段和（带修改）是另一套路，见数据结构模板。
